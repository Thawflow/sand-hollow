# 🔤 英语音标速成课 · 课程设计（沙坑新增第二课程线）

> **定位**：为「听说读写已达标、只缺 IPA 符号体系」的学员设计的一套速成课 —— 9 单元（P00 导入 + P01-P08）。
> **考纲口径**：PEP 五上 Let's spell + 国内教材 48 音标分类。
> 学员个人背景与家庭内部评审记录**不在本公开仓**；完整规划见家族私仓。

---

## 一、定位：为什么是「速成」而不是「系统学」

| 学员现状 | 决定 |
|---|---|
| 听说读写已达标 | **不教**听力输入、词汇量、语法体系 —— 那些已有 |
| 缺的是音标**体系本身**（48 个 IPA 符号 + 发音口型 + 拼读） | 核心只教音标 |
| 考点是音标 | 考点直接对齐 |
| 时间紧 | **压缩成 9 单元**（不是 21 天完整课） |

> **关键判断**：这类学员不需要"学英语"，需要"补一门考试要考、没上过的课"。速成 = **跳过所有已有基础，直接进缺口**。

## 二、⭐ 关键澄清：国际音标 ≠ 自然拼读（别搞混）

考的是 **国际音标（IPA, 48 个）**，不是自然拼读（Phonics）。

| | 自然拼读 Phonics | 国际音标 IPA |
|---|---|---|
| 逻辑 | 字母/字母组合 → 推测读音 | **符号 → 精确标注读音** |
| 用途 | 读**陌生词**（70-80% 规则词） | **查词、纠音、区分近音** |
| 这类学员缺这个吗？ | ❌ 不缺（能读能听） | ✅ **缺** |

> ⚠️ 市面上大量"音标课"实际是自然拼读（Phonics）课 —— **不能买错**。判据：
> 课程表里必须有「48 个音标符号 / 口型舌位 / 单元音·双元音·清浊辅音分类」。

## 三、考纲（PEP 五上 Let's spell + 国内教材口径）

### 48 个音标 = 20 元音 + 28 辅音

**元音 20 个**
- 单元音 12：`/iː/ /ɪ/ /e/ /æ/ /ɜː/ /ə/ /ʌ/ /ɑː/ /ɒ/ /ɔː/ /uː/ /ʊ/`
- 双元音 8：`/eɪ/ /aɪ/ /ɔɪ/ /ɪə/ /eə/ /ʊə/ /aʊ/ /əʊ/`

**辅音 28 个**（国内教材口径：爆破 6 + 摩擦 10 + 破擦 6 + 鼻音 3 + 舌侧 1 + 半元音 2 = 28）
- 爆破音 6：`/p/ /b/ /t/ /d/ /k/ /g/`
- 摩擦音 10：`/f/ /v/ /s/ /z/ /θ/ /ð/ /ʃ/ /ʒ/ /h/ /r/`
- 破擦音 6：`/ts/ /dz/ /tʃ/ /dʒ/ /tr/ /dr/`
- 鼻音 3：`/m/ /n/ /ŋ/`
- 舌侧音 1：`/l/`
- 半元音 2：`/w/ /j/`

> 注：`/r/` 按国内教材口径计入摩擦音 10（英式另有 `/r/` 之分）；`/tr/ /dr/` 计入破擦音 —— 凑不满 28 个就是漏了这一对。
> 验算：单元音 12 + 双元音 8 + 辅音 28 = **48**。

### 必须掌握的 5 类技能（比背符号更重要）

1. **发音部位分类** —— 按发音部位分组记（唇音/齿音/龈音/舌位…）
2. **口型舌位** —— 长元音拉长、短元音短促、双元音滑动
3. **清浊对照** —— `/p/-/b/ /t/-/d/ /k/-/g/ /f/-/v/ /s/-/z/ /θ/-/ð/ /ʃ/-/ʒ/`（手摸喉咙感受声带震动）
4. **音节与重音** —— 元音是音节核心；辅音不能独立成音节（`/m/ /n/ /l/` 除外）
   - 单音节 1 元音 · 双音节 2 元音 · 多音节 3+ 元音
   - 重音位置错了 → 词读音跑偏
5. **连读 / 失去爆破 / 弱读** —— 贴合真实听力朗读

### 高频易错（重点预警）

| 易错 | 说明 |
|---|---|
| `/θ/ /ð/` | 咬舌音 —— 舌尖轻放上下齿中间，**中国学生最常错** |
| `/æ/` | 大口元音 —— 中国学生常读成 `/e/` |
| `/ŋ/` | 后鼻音 —— 常读成 `/n/` |
| `/iː/ vs /ɪ/` | 长短对立 |
| `/ɑː/ vs /ʌ/` | 口型差 |
| `/ʃ/ vs /s/` | 翘唇 vs 平唇 |
| 清浊辅音对 | `/p/-/b/` 等 7 组 |

## 四、课程设计：9 单元速成（P00 导入 + P01-P08）

> 参照 PEP 五上 Let's spell 的分组逻辑，但**压缩**。每单元 = 3-5 个音标 + 1 个练习组。

| 单元 | 内容 | 音标 | 技能重点 | 预计耗时 |
|---|---|---|---|---|
| **P00 导入** | 什么是音标 / 48 个总表 / 发音部位 | — | 建立框架 | 20 min |
| **P01** | 前元音 | `/iː/ /ɪ/ /e/ /æ/` | 口型 + 长短 | 30 min |
| **P02** | 中元音 | `/ɜː/ /ə/ /ʌ/` | 弱读 `/ə/`（最高频） | 30 min |
| **P03** | 后元音 | `/ɑː/ /ɒ/ /ɔː/ /uː/ /ʊ/` | 圆唇 + 长短 | 35 min |
| **P04** | 双元音（合口组） | `/eɪ/ /aɪ/ /ɔɪ/ /aʊ/ /əʊ/` | 滑动不断开 | 35 min |
| **P05** | 双元音（集中组） | `/ɪə/ /eə/ /ʊə/` | 以 `/ə/` 收尾，口型由开变合 | 30 min |
| **P06** | 爆破音 + 摩擦音 | `/p b t d k g/` + `/f v s z θ ð ʃ ʒ h r/` | **清浊对照** + 咬舌音 | 45 min |
| **P07** | 破擦音 + 鼻音 + 舌侧 + 半元音 | `/ts dz tʃ dʒ tr dr/` + `/m n ŋ/` + `/l/` + `/w j/` | 收尾音 + 后鼻音 | 40 min |
| **P08** | 综合实战 | — | 音节划分 + 重音 + 连读 + 查词实战 | 45 min |

**总时长 = 310 分钟 ≈ 5.2 小时**（9 个单元）

**节奏建议**：每天 30-40 分钟 → **需 8-11 天**（每天 40min 约 8 天；每天 30min 约 11 天）。
> ⚠️ 口径订正：按「每天 30-40 分钟」推进，9 单元 **310min** 需要 **8-11 天**，**一周（7 天）不够**（7 天上限 280min < 310min）。

### P08 实战设计（最关键 —— 练"用"而不是"认"）

1. **看词读音**：给生词 → 用音标拆读
2. **听音写词**：录音 → 写音标
3. **音节划分 + 重音标记**：`beautiful /ˈbjuːtɪfəl/`、`population /ˌpɒpjuˈleɪʃn/`
4. **近音辨析**：`light/night/right`、`ship/sheep`、`full/fool`
5. **连读朗读**：真实短文朗读（素材现成）

## 五、教材与工具（不要买错课）

### 教材（按优先级）
1. **PEP 五上 Let's spell 单元** —— 对齐国内教材口径，**最优先**
2. **人教版七上 48 音标讲义**（学科网/二一教育网有完整 PDF）—— 更系统
3. **《英语语音学》/《新概念英语》第一册 Lesson 1-40**（语音专项）—— 经典
4. 参考：**《赖世雄美语音标》**（美音）、**BBC Learning English - Pronunciation**（免费视频）

### ⚠️ 避坑（检索发现）
- 市面"音标课"大量是自然拼读课 → **判据：课程表必须出现"48 个音标符号 / 单元音 / 双元音 / 清浊辅音"**
- B 站"21 天/48 集音标课"多为**免费公开**，可作补充但非主线（自学能力强可自选）

### 工具
- **音频**：手机录音 + 对比标准音（Forvo.com 免费真人发音库 / 有道词典）
- **发音检测**：手机上装 **ELSA Speak**（英语流利度 AI 发音教练）或 **Speechling**（免费版）—— **ELSA 对中国学生的中式发音特别有效**
- **词典**：欧路词典 / 有道（都有音标显示）—— 查词时顺手巩固
- **书写**：音标要**手写**记忆（不是只认）—— 纸笔练 48 个符号

## 六、站点形态：双课程线（多邻国式）

首页从"单课程列表"改成 **两大课程入口**，点进去各自独立：

```
🏖️ 沙坑训练场
┌─────────────────┐  ┌─────────────────┐
│ 🐍 编程课程      │  │ 🔤 英语音标      │
│ 17 周 · Python   │  │ 9 单元 · 音标    │
│ [进入 →]        │  │ [进入 →]        │
└─────────────────┘  └─────────────────┘
```

**实现要点**
- 课时 markdown：`mentors-den/course/WXX-SY.md`（编程轨）/ `mentors-den/phonics/PXX-SY.md`（音标轨），前端 fetch
- 课时文件名加前缀 → 前端按前缀分轨（`W` = 编程 / `P` = 音标）
- **前端**加课程切换 tab + 周列表按轨过滤 + **进度隔离**（`progress_code_*` / `progress_phonics_*`）
- **publish 脚本**按轨选目录 + 放宽周号校验（`W*` / `P*`）+ 标题来源按轨取大纲文件
- **后端 API**：`/learning/week/<week_id>` 的 week_id 是自由字符串 → 音标轨传 `P01` 即可，**后端零改动**
- **共享同一套账号** —— 登录一次，两个课程都能看
