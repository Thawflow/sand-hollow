## 一、概念：搬家式的写法（2 分钟）

昨天骨架通电 + 第一块完工。今天接着搬剩下 2-3 块，节奏是铁打的四步循环：

**填一块 → 运行 → 测一条路 → 再下一块**

每块功能就这四步，块与块之间绝不连写。听起来慢——实际最快：报错永远只出在**刚写的那块**，两分钟定位；连写三块再测，报错藏在三块里翻半天。

## 二、示例：add_pet 这块怎么搬（5 分钟）

以图鉴 v2 的「加宠物」为例（你的项目对应你的功能）：

```python
def add_pet(codex):
    """问名字和属性，安检后加进 codex"""
    name = input("Pet name: ").strip()
    if name == "":
        print("Name cannot be empty")
        return
    if name in codex:
        print(f"{name} already exists")
        return
    species = input("Species: ").strip()
    codex[name] = {"species": species, "skills": []}
    print(f"Added {name}!")
```

三层安检全是老朋友叠罗汉：**空名检查**——直接回车想混进来？拦住；**重名检查**——`in codex` 防整宠覆盖（W10-S5 的坑）；空技能列表先立着——**数据结构一次到位**，之后 add_skill 直接往里 append。

## 三、示例：show_pet 接着搬（3 分钟）

```python
def show_pet(codex):
    """打印指定宠物全部档案"""
    name = input("Pet name: ").strip()
    if name not in codex:
        print(f"{name} not in codex")
        return
    pet = codex[name]
    print(f"=== {name} ({pet['species']}) ===")
    print(f"Skills: {', '.join(pet['skills']) or 'none'}")
```

`or 'none'` 小技巧：空列表 join 出空串，`空串 or 'none'` 取后者，屏幕显示 `Skills: none` 不干瞪眼——玩家感大不同。

别忘了把新函数**接进菜单**：菜单加一行 `3. Show pet`，while 里加 `elif choice == "3": show_pet(codex)`。功能做完不接菜单 = 搬了家具没开门。

## 四、卡住了怎么办（1 分钟）

逐块写一定会撞报错，三步自救（W12 毕业标准之一就是「报错自己修」）：读报错**最后一行**（错误类型 + 原因）→ 看报错**行号**（先怀疑刚写的那块）→ 印不出就 print（变量前后各 print 一次）。三步无解再求助 mentor——带上报错原文 + 你猜的原因。会猜错也比不猜强。

**今日口诀：** 填一块测一块、安检叠罗汉、功能必须接菜单。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
void data_module() { std::cout << "load data" << std::endl; }
void model_module() { std::cout << "build model" << std::endl; }
int main() {
    data_module();
    model_module();
    return 0;
}
```

三个认脸：

1. 分模块函数
2. main 调用各模块
3. Python 一样：def data_module(): ...
