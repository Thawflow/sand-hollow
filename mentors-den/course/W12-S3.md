## 一、核心想法：每次找最小的放前面（3 分钟）

```
[3, 1, 4, 1, 5, 9, 2, 6]  -> find min: 1 -> swap
[1, 3, 4, 1, 5, 9, 2, 6]  -> find min: 1 -> swap
[1, 1, 3, 4, 5, 9, 2, 6]  -> find min: 2 -> swap
... 7 DONE ...
[1, 1, 2, 3, 4, 5, 6, 9]  DONE
```

7 步（n-1 = 8-1 = 7）。每步"找最小 + 交换"。

## 二、Python 代码（5 分钟）

```python
def selection_sort(arr):
    '''Sort arr in place using selection sort.'''
    n = len(arr)
    for i in range(n - 1):           # i is the position to fill
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        if min_idx != i:
            arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr

nums = [3, 1, 4, 1, 5, 9, 2, 6]
print(selection_sort(nums))   # [1, 1, 2, 3, 4, 5, 6, 9]
```

## 三、复杂度（3 分钟）

N 个元素：外层 N 次 + 内层 N/2 次 + 每次 O(1) = **N²/2 = O(N²)**。

10 元素 ~50 比较；100 元素 ~5000；10000 元素 ~5000 万。

## 四、排序算法全家福（3 分钟）

| 排序 | 时间 | 空间 | 稳定性 | 何时用 |
|---|---|---|---|---|
| 选择排序 | O(N²) | O(1) | ✗ | 教学 |
| 冒泡排序 | O(N²) | O(1) | ✓ | 教学 |
| 插入排序 | O(N²) | O(1) | ✓ | 小数据 |
| **快排** | **O(N log N)** | O(log N) | ✗ | **生产默认** |
| 归并排序 | O(N log N) | O(N) | ✓ | 大数据 / 链表 |
| Timsort (Python) | O(N log N) | O(N) | ✓ | **Python 默认** |

**AI 工程师用什么**：训练数据预处理用归并，实时推荐用堆，一般业务用 Timsort。
