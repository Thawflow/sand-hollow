## 一、问题：选最多不重叠（3 分钟）

```
Activities: A(1-4)  B(3-5)  C(0-6)  D(5-7)  E(8-9)  F(5-9)
```

**目标**：选最多活动，互不重叠。

## 二、贪心策略：选最早结束（5 分钟）

**算法**：
1. 按结束时间排序所有活动
2. 选第一个（最早结束）
3. 跳过所有跟它重叠的
4. 重复选下一个

```python
def activity_selection(activities):
    '''Greedy: pick earliest-finishing activity.'''
    # Sort by end time
    sorted_acts = sorted(activities, key=lambda a: a[1])
    selected = [sorted_acts[0]]
    last_end = sorted_acts[0][1]

    for activity in sorted_acts[1:]:
        start, end = activity
        if start >= last_end:    # no overlap
            selected.append(activity)
            last_end = end

    return selected
```

## 三、示例演算：6 个活动（3 分钟）

| 步 | 候选 | 选 | 跳过 | 选集 |
|---|---|---|---|---|
| 1 | A(1-4), B(3-5), C(0-6), D(5-7), E(8-9), F(5-9) | **A(1-4)** | C(0-6 重叠) | [A] |
| 2 | 跳过 C | **D(5-7)** | F(5-9 重叠) | [A, D] |
| 3 | 跳过 F | **E(8-9)** | — | [A, D, E] |

**结果**：[A, D, E] = 3 个活动。

## 四、深入了解：为什么"选最早结束"最优（3 分钟）

**数学证明思路**（简化）：
- 假设选活动 a 结束时间最早 = t
- 任何最优解都可以替换成"选 a + 剩下的最优解"
- 剩下的最优解"剩下的活动里" = 选 a 之后的子问题
- **递归最优 = 全局最优**（动态规划思想）

**反例**："选最早开始"会失败：
- A(1-4) 选 → 跳过 B(3-5) 重叠
- 失去 B(2-3) + C(3-5) = 2 个

## 五、何时用：活动选择 4 个变种（3 分钟）

| 场景 | 策略 |
|---|---|
| 选最多不重叠活动 | 贪心（最早结束）|
| 选最多 k 个活动 | 动态规划 |
| 加权活动选择 | 动态规划 |
| 带代价活动选择 | 线性规划 |

**AI 工程师原则**：先贪心，不对再升级。
