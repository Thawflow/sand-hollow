## 一、把战斗接进地图（3 分钟）

battle 是积木，地图是骨架，今天拼上。贴进主循环的 forest 分支：

```python
while room != "quit":
    if room == "forest":
        choice = input("(fight/run): ")
        if choice == "fight":
            won = battle(player, enemies["wolf"])
            if not won:
                room = "game_over"
            else:
                print("Forest cleared!")
                room = "shrine"
```

关键两行：`won = battle(...)` 接住胜负；输了就把 `room` 改成 `"game_over"`——主循环下一圈自动跳进结局分支。**改 room 就是游戏的万能开关。**

## 二、game_over 房间：输了也有结局（2 分钟）

```python
if room == "game_over":
    print("=== GAME OVER ===")
    print("You have fallen. The island keeps your legend.")
    room = "quit"
```

`room = "quit"` 让 while 条件不成立，游戏安静退出。game_over 也只是地图上一个方块——这就是 S1「先想后写」的红利。

## 三、Boss 房：巨鹰巢穴（4 分钟）

S1 地图终点站今天启用。Boss 房加一道**钥匙检查**：

```python
while room != "quit":
    if room == "bossnest":
        if "feather" in player["inventory"]:
            won = battle(player, enemies["eagle"])
            if won:
                print("VICTORY! The island sings your name!")
                room = "quit"
            else:
                room = "game_over"
        else:
            print("The eagle ignores you. Need the feather.")
            room = "bridge"
```

`"feather" in player["inventory"]`——W06 的 `in` 检查：道具栏里有羽毛才开打。**道具从此变成钥匙。** 没羽毛？巨鹰看都不看你。打赢，通关分支打印胜利并 `room = "quit"` 收场。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
int main() {
    int player_hp = 30, boss_hp = 0;
    if (player_hp <= 0) std::cout << "lose" << std::endl;
    else if (boss_hp <= 0) std::cout << "win" << std::endl;
    else std::cout << "continue" << std::endl;
    return 0;
}
```

三个认脸：

1. `if-else if-else` 三分支判定
2. 判定结束直接 return/print
3. Python 一样用 if-elif-else
