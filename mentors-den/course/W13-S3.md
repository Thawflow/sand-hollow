## 一、for 遍历字典：默认发钥匙（3 分钟）

列表遍历给你**元素**，字典遍历给你**键**：

```python
cat = {"name": "Whiskers", "age": 3, "color": "tabby"}

for key in cat:
    print(key)
```

输出三行：`name`、`age`、`color`——只发钥匙（键），不发东西。想要值？拿钥匙再开一次门：`cat[key]`。

## 二、键值一起拿（4 分钟）

f-string（W02 老朋友）和循环合体，档案表一行行打出来：

```python
for key in cat:
    print(f"{key} -> {cat[key]}")
```

输出：

```text
name -> Whiskers
age -> 3
color -> tabby
```

套路拆解：

- `for key in cat:` → 钥匙一把把轮流传
- `cat[key]` → 拿当前钥匙开当前门（key 是变量，**不加引号**）
- `f"{key} -> {cat[key]}"` → 一行排版，箭头看着清爽

**高频小坑：** `cat["key"]`（手滑加引号）→ 找叫 "key" 的键 → KeyError。引号一加，变量变字符串——W02 的种族铁律又来了。

## 三、实战：全班点名器（4 分钟）

字典 + 遍历 + 判断（W03），三周武功合体：

```python
scores = {"Alice": 92, "Bob": 78, "Cathy": 85}

for name in scores:
    score = scores[name]
    if score >= 90:
        mark = "A"
    elif score >= 80:
        mark = "B"
    else:
        mark = "C"
    print(f"{name}: {score} -> {mark}")
```

输出三行成绩单，每人自动定级。看懂这段 = 列表周学的「累加器 + 遍历」思想完整搬进了字典世界：**遍历 → 每项加工 → 输出**。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
#include <map>
int main() {
    std::map<std::string, int> d = {{"a", 1}, {"b", 2}};
    for (auto& [k, v] : d) {
        std::cout << k << "=" << v << std::endl;
    }
    return 0;
}
```

三个认脸：

1. C++17 结构化绑定 `[k, v]`
2. `for (auto& [k, v] : d)` 遍历
3. Python 一样：for k, v in d.items():
