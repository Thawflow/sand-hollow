## 一、贪心函数实战（5 分钟）

```python
def greedy_change(amount, coins):
    '''Greedy. coins sorted largest to smallest.'''
    result = []
    for coin in coins:
        while amount >= coin:
            result.append(coin)
            amount -= coin
    return result

# Test
print(greedy_change(870, [100, 50, 10]))    # 8 coins
print(greedy_change(60, [40, 30, 10]))      # 3 coins (NOT optimal)
```

## 二、暴力函数（5 分钟）

```python
def brute_change(amount, coins):
    '''Try every combination, return shortest.'''
    best = None
    def try_combos(remaining, coins, current):
        nonlocal best
        if remaining == 0:
            if best is None or len(current) < len(best):
                best = list(current)
            return
        if remaining < 0:
            return
        if best is not None and len(current) >= len(best):
            return
        for i, coin in enumerate(coins):
            current.append(coin)
            try_combos(remaining - coin, coins[i:], current)
            current.pop()
    try_combos(amount, coins, [])
    return best if best is not None else []
```

**关键**：先 sort coins + `coins[i:]` 让后面只看更小硬币，避免重复。

## 三、示例演算：amount=60, coins=[40, 30, 10]（3 分钟）

**贪心**：40 + 10 + 10 = 60 (3 枚)
**暴力**：30 + 30 = 60 (2 枚) ✓ 最优

**暴力赢**——贪心用了 3 枚，最优 2 枚。

## 四、深入了解：暴力为什么"慢"（3 分钟）

暴力 = 遍历所有组合 = O(2^n)。

| 金额 | 硬币数 | 组合数（最坏）|
|---|---|---|
| 60 | 3 | 2³ = 8 |
| 100 | 3 | 2³ = 8 |
| 1000 | 5 | 2⁵ = 32 |
| 100 万 | 5 | 2⁵ = 32（但 amount 大）|

**amount 比 coin 数更影响**——所以暴力适合小 amount 测试贪心对错。

## 五、何时用：算法选择决策树（3 分钟）

```
data small (< 1000)?
  yes -> brute (gold standard)
  no -> greedy
       counter-example?
            yes -> dynamic programming
            no -> greedy ✓
```

## 七、答案

```python
import random

def test_greedy_vs_brute():
    '''Random test: greedy vs brute.'''
    for _ in range(10):
        amount = random.randint(10, 100)
        coins = sorted([random.choice([1, 5, 10, 25, 50, 100]) for _ in range(3)], reverse=True)
        g = len(greedy_change(amount, coins))
        b = len(brute_change(amount, coins))
        status = 'OK' if g == b else f'DIFF (g={g}, b={b})'
        print(f'amount={amount:3d} coins={coins} greedy={g} brute={b} {status}')

test_greedy_vs_brute()
```
