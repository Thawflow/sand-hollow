## 一、一个观察值千金（3 分钟）

正方形：4 条边，每次转 90°。算一算：`4 × 90 = 360`。

等边三角形：3 条边，每次转 120°。`3 × 120 = 360`。

五边形：5 条边，每次转 72°。`5 × 72 = 360`。

**秘密揭晓：** 不管几边形，海龟画完一圈**总共转了 360 度**——转回出发方向，图形才能闭合。这叫**外角和定理**：任何正多边形的外角和都是 360°。

所以每次转的角度 = **360 ÷ 边数**：

| 形状 | 边数 | 每次左转 |
|---|---|---|
| 三角形 | 3 | 360/3 = 120° |
| 正方形 | 4 | 360/4 = 90° |
| 五边形 | 5 | 360/5 = 72° |
| 六边形 | 6 | 360/6 = 60° |

## 二、一个函数画遍全家（4 分钟）

把公式塞进函数（W08 老朋友），一个积木画所有形状：

```python
import turtle

t = turtle.Turtle()
t.speed(0)

def polygon(sides, length):
    angle = 360 / sides
    for i in range(sides):
        t.forward(length)
        t.left(angle)

polygon(3, 100)    # 三角形
polygon(6, 60)     # 六边形
polygon(8, 50)     # 八边形

turtle.done()
```

逐行拆解：

| 部件 | 作用 |
|---|---|
| `def polygon(sides, length):` | 积木的两个凹槽：边数 + 边长 |
| `angle = 360 / sides` | 公式本体：360 ÷ 边数 |
| `for i in range(sides):` | 有几条边循环几次 |

（三个形状会叠在一起——S3 的 penup 挪窝正好用来把它们摆开，作业里试。）

## 三、多边形家族合影（3 分钟）

让 for 循环**套在外面**，边数从 3 涨到 7：

```python
for sides in range(3, 8):
    polygon(sides, 70)
    t.penup()
    t.forward(120)
    t.pendown()
```

跑出来一排：三角形、正方形、五边形、六边形、七边形——边数越多越像圆。W04 的嵌套循环在画纸上活了。

## 四、坑：为什么 144 不是 72（1 分钟）

五角星每次转 **144°**，不是 72°——因为五角星画的是**星形路径**，不是绕一圈的普通五边形。记住区分：普通多边形 360/边数；五角星这种「跨着画」的另有角度。猜角度前先想清楚海龟走的是什么路线。

**今日口诀：** 360 除以边数，外角和定天下。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
int main() {
    int n = 6;
    for (int i = 0; i < n; i++) {
        std::cout << "forward 100, turn " << 360 / n << std::endl;
    }
    return 0;
}
```

三个认脸：

1. `n = 6` 画六边形
2. `360 / n` 算外角
3. Python 一样：for i in range(6): t.forward(100); t.left(60)
