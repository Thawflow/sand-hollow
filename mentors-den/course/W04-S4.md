## 一、第三招：找最大——擂台赛（5 分钟）

不是把所有数加起来，而是**留住最大的那个**：

```python
nums = [3, 7, 2, 9, 4]
biggest = nums[0]
for n in nums:
    if n > biggest:
        biggest = n
print("The biggest is:", biggest)
```

得 `The biggest is: 9`。

### 擂台赛规则

- `nums = [3, 7, 2, 9, 4]`：一个列表（W06 正式学，今天先借用）
- `biggest = nums[0]`：**第一个数先当擂主**（`nums[0]` 是列表第 1 个——Python 从 0 数起）
- `if n > biggest`：有人比擂主强？
- `biggest = n`：是的话，换人当擂主

## 二、初值口诀（2 分钟）

| 目标 | 箱子初值 |
|---|---|
| 求和 | `0` |
| 计数 | `0` |
| 找最大 / 找最小 | **第一个数**（不是 0！） |

为什么找最大不能从 0 起手？想象列表全是负数 `[-5, -2, -9]`——0 谁都赢不了，最后打印 0，可 0 根本不在列表里。**擂主必须从选手里产生。**

## 三、⚠️ 累加器三坑（4 分钟）

1. **忘建箱子**：循环里 `total += i` 但 total 没先建 → `NameError: name 'total' is not defined`。累加器必须**先建再循环**。
2. **建错初值**：找最大却 `biggest = 0` → 全负数列表全军覆没（见上）。
3. **`=` 与 `==` 混淆**：`if n = biggest:` → SyntaxError。比较用 `==`（W03-S3 踩过的坑，穿越而来）。

**今日口诀：** 擂主从选手里产生——初值选错，满盘皆输。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
#include <vector>
int main() {
    std::vector<int> nums = {3, 7, 2, 9, 5};
    int max_val = nums[0];
    for (int x : nums) {
        if (x > max_val) max_val = x;
    }
    std::cout << max_val << std::endl;
    return 0;
}
```

三个认脸：

1. `std::vector<int>` 跟 Python list 类似
2. `for (int x : nums)` range-based for（C++11+）
3. Python `max(nums)` 一行解决
