## 一、拼接到底哪里痛（3 分钟）

W01 你用过 `+` 拼字符串：

```python
print("认识你太开心了，" + name + "！")
print(name + " 喜欢 " + food + "，还爱玩 " + game + "。")
```

痛在三点：引号多到眼花、数字必须 `str()` 转一圈、忘了转就 TypeError（翻车现场见 S2）。

## 二、f-string 三步上手法（5 分钟）

引号前加个 `f`，花括号里直接放变量：

```python
print(f"认识你太开心了，{name}！")
print(f"{name} 喜欢 {food}，还爱玩 {game}。")
```

三步：① 引号前写 `f` ② 要填空的地方写 `{}` ③ 花括号里放变量名。完事。

## 三、花括号 = 小型计算器（5 分钟）

花括号里不止能放变量，还能**直接写算式**：

```python
a = 10
b = 3
print(f"{a} + {b} = {a + b}")       # 10 + 3 = 13
print(f"{a} 除以 {b} 约等于 {a / b:.2f}")   # 10 除以 3 约等于 3.33
```

`{a + b}` 会先算好再填进去。`: .2f` 是「保留两位小数」——账单神器。

**这正是它的杀手锏**：以前的写法要 `str(a) + " + " + str(b) + " = " + str(a+b)`，现在一行全包。

## 四、格式化魔法速览（2 分钟）

```python
f"{3.14159:.1f}"    # "3.1"     —— 一位小数
f"{0.25:.0%}"       # "25%"     —— 百分比
f"{1234567:,}"      # "1,234,567" —— 千分位
```

今天作业用不到，但知道它们存在——将来做成绩单/账单时回来抄。

## 五、什么时候不用 f-string

- 打印一个单独的变量：`print(name)` 就行，不必 `print(f"{name}")`
- 拼接超长的纯文字（没变量）：普通字符串即可

**口诀：** 有变量/算式要填 → f-string；没有 → 普通引号。
