## 一、为什么要限次数（2 分钟）

基础版可以无限猜——1 到 100 猜 100 次总能蒙中，游戏没了紧张感。真实游戏都有规则：**限 5 次，猜不中就揭底**。

## 二、第二版：限 5 次（4 分钟）

```python
secret = random.randint(1, 100)
guess = 0
tries = 0
max_tries = 5

while guess != secret and tries < max_tries:
    guess = int(input(f"Tries {tries+1}/{max_tries} - guess: "))
    tries += 1
    if guess > secret:
        print("Too high!")
    elif guess < secret:
        print("Too low!")
    else:
        print(f"Correct! You got it in {tries} tries")
        break
else:
    if guess != secret:
        print(f"Game over! The answer was {secret}")
```

关键改动三条：条件用 and 组了两个维度（W03-S5 老朋友）；`tries += 1` 每轮记账；else 揭底——没被 break（5 次用完还没中）才执行。

（文件开头照旧 `import random`，别再 NameError 了。）

## 三、第三版：再来一局（4 分钟）

外层再套一个 while，管「玩不玩下一局」：

```python
play_again = "yes"
while play_again == "yes":
    secret = random.randint(1, 100)
    guess = 0
    tries = 0
    while guess != secret and tries < 5:
        # 内层跟第二版一模一样，整段搬进来
        pass
    play_again = input("Play again? (yes/no): ")
print("Thanks for playing!")
```

两个要点：**嵌套循环**（W04 学的内层外层，今天实战）；**每局重置**——secret / guess / tries 必须在外层循环里重新赋值，不然第二局带着上一局的旧账开打，直接翻车。

## 四、坑 + 加分预告（2 分钟）

**坑：else 缩进。** while 的 else 要跟 while 对齐，不是跟里面的 if 对齐——错了的现象是「猜对了也揭底」。

**周末加分方向：** 难度选择（easy 猜 1-50 给 8 次 / hard 猜 1-200 给 5 次）、计分（猜中得 `100 - 10 * tries` 分）——周末项目「猜数字计分版」正等你。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
int main() {
    int target = 7, guess, tries = 0;
    while (tries < 5) {
        std::cin >> guess;
        tries++;
        if (guess > target) std::cout << "smaller" << std::endl;
        else if (guess < target) std::cout << "bigger" << std::endl;
        else { std::cout << "win!" << std::endl; break; }
    }
    return 0;
}
```

三个认脸：

1. `std::cin` 输入（Python 的 input）
2. `tries++` 累加尝试次数
3. 限 5 次 + 提示 = 打磨用户体验
