# P08-S1 · 双系统 4 步法：拼读 → 音标 → 例外 → 查证

> 🔤 英语音标速成课 · 单元 P08 · 第 1 节 · 约 30 分钟

---

## 今天学什么

最后这个单元不学新符号，只练**两个系统互相对账**：

- **拼读系统**：字母怎么拼出一个词（你早就会）
- **音标系统**：声音怎么写成一个词（你现在会了）

两个系统各有各的强项，也会各有各的错。4 步法就是让它们互相抓错。

---

## 一、4 步法走一遍 `teacher`

| 步骤 | 做什么 | `teacher` |
|---|---|---|
| 1 拼读 | 用你已有的拼读把词念出来 | t + each + r → ˈtiːtʃə(r) |
| 2 换符号 | 每个音换成英式符号 | /t/ /iː/ /tʃ/ /ə/ /r/ = /ˈtiːtʃə(r)/ |
| 3 查例外 | 看拼读有没有骗你 | `each` 里 ea 是 /iː/，不是 /e/ |
| 4 回读核对 | 念音标，对上耳朵 | 你念 /ˈtiːtʃə(r)/ 吗？→ 是，收工 |

第 4 步是整套法的核心：**读得出 + 写得准 + 对得上**。

---

## 二、什么时候拼读会骗你（先有个印象）

1. **一个字母组合 = 一个符号**：`ch` → /tʃ/、`sh` → /ʃ/、`th` → /θ/ 或 /ð/、`ng` → /ŋ/
2. **同一个字母有多种符号**：`a` 可以是 /eɪ/ /æ/ /ɑː/ /ə/（`name` `cat` `car` `about`）
3. **结尾的 e 不发音**：`like` /laɪk/、`have` /hæv/ —— 拼读和音标在这里分家

第 3 类最麻烦，下一节专门开一张例外词表。

> **拼读对照**：`teacher` → t + each + r → /t/ + /iː/ + /tʃ/ + /ə/ + /r/ = /ˈtiːtʃə(r)/
> 拼读给你「读得出」，IPA 给你「说得准」

> **拼读对照**：`like` → l + i + k + e → /l/ + /aɪ/ + /k/ = /laɪk/
> 拼读给你「读得出」，IPA 给你「说得准」
