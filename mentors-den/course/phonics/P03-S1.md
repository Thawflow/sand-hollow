# P03-S1 · 后元音入门：圆唇与非圆唇的位置

> 🔤 英语音标速成课 · 单元 P03 · 第 1 节 · 约 35 分钟

---

## 今天学什么

后元音的共同点是**舌根往后退**，抬向软腭，舌尖完全不参与。
这一节只干一件事：把五个后元音 **/ɑː/ /ɒ/ /ɔː/ /uː/ /ʊ/** 按「圆唇 / 不圆唇」和「长 / 短」两条线摆好。

---

## 一、不圆唇派：/ɑː/ 和 /ɒ/

### 1️⃣ /ɑː/ —— 嘴最大，唇不圆

- **写法**：`/ɑː/`，大写 a + 冒号 `ː`（长音）
- **要领**：嘴**大大张开**说「啊——」，但**嘴唇完全不噘**，嘴角向两边拉开
- **例词**：car /kɑː/、park /pɑːk/、heart /hɑːt/

> **拼读对照**：`car` → c + ar → /k/ + /ɑː/ + /r/ = /kɑː/
> 那个 `ar` 是**嘴大、唇不圆**的 /ɑː/，不是随便一声「啊」

### 2️⃣ /ɒ/ —— 嘴大，唇稍收

- **写法**：`/ɒ/`，大写 o，**没有冒号**（短音）
- **要领**：嘴同样张得很大，但**嘴唇往回收一点**；音短促
- **例词**：hot /hɒt/、dog /dɒɡ/、box /bɒks/

> **拼读对照**：`hot` → h + o + t → /h/ + /ɒ/ + /t/ = /hɒt/
> 拼读表里的「短元音 o」不是 /ɑː/ 的短版 —— 唇型收一点，音也短得多

---

## 二、圆唇派：/ɔː/ /uː/ /ʊ/

### 3️⃣ /ɔː/ —— 吹小喇叭

- **要领**：双唇**用力收圆并向前突**，舌头后部抬高；声音从圆唇缝送出
- **例词**：walk /wɔːk/、talk /tɔːk/、short /ʃɔːt/

### 4️⃣ /uː/ —— 收得最小最圆

- **要领**：嘴唇比 /ɔː/ **收得更圆更小**，几乎挤成小圆孔；舌根抬到最高
- **例词**：food /fuːd/、moon /muːn/、school /skuːl/

> **拼读对照**：`food` → f + oo + d → /f/ + /uː/ + /d/ = /fuːd/
> 拼读给你「读得出」，IPA 给你「说得准」—— 那个 `oo` 要把嘴唇收到多小，才算 /uː/

### 5️⃣ /ʊ/ —— 喇叭放松了

- **要领**：嘴唇只是**松松地圆一下**，不前突；开口比 /uː/ 大一点，音懒洋洋的
- **例词**：book /bʊk/、good /ɡʊd/、look /lʊk/

> **拼读对照**：`book` → b + oo + k → /b/ + /ʊ/ + /k/ = /bʊk/
> 同样是 `oo`，这里嘴**没**收到 /uː/ 那么小 —— 下一节 `fool` / `full` 就讲这个

### 五音速查表

| 音 | 时长 | 嘴唇 |
|---|---|---|
| /ɑː/ | 长 | 不圆，嘴角拉开 |
| /ɒ/ | 短 | 稍收一点 |
| /ɔː/ | 长 | **用力圆唇前突** |
| /ʊ/ | 短 | 松松地圆 |
| /uː/ | 长 | **收到最小最圆** |

开口从大到小：**/ɑː/ → /ɒ/ → /ɔː/ → /ʊ/ → /uː/**。
