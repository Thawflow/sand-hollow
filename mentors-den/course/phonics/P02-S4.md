# P02-S4 · 拼读对照实战：拼读推读音 + IPA 标注 + 找出词里的 /ə/

> 🔤 英语音标速成课 · 单元 P02 · 第 4 节 · 约 40 分钟

---

## 今天学什么

这一节是**双系统合流**：左边是拼读（你早就会的地基），右边是音标（这几天学的）。
三步走：**① 用拼读推读音 → ② 写完整 IPA → ③ 圈出每个 /ə/**。
推的时候大胆推 —— 对不上的地方正是例外词，那才是 IPA 真正派上用场的地方。

---

## 一、三步法演示：`comfortable`

**第 1 步 · 拼读推读音**
c-o-m-f-or-ta-ble → /k/ + /ʌ/ + /m/ + /f/ + /ɔː/ + /t/ + /ə/ + /b/ + /l/？

**第 2 步 · 写完整 IPA**
comfortable /ˈkʌmfərtəbl/

**第 3 步 · 圈 /ə/**
两个：`/ˈkʌmf**ə**rt**ə**bl/` —— 一个在 for 后面，一个在 ta 后面。

**对不上的地方**：`or` 在这里既不是 /ɔː/ 也不是 /ɜː/，而是 /ər/，因为它不重读。
这就是为什么你需要 IPA：拼读给你「大概」，IPA 给你「答案」。

---

## 二、实战词表（8 个词）

| 单词 | 拼读推读音（自己先推） | 完整 IPA |
|---|---|---|
| `sister` | s + i + s + ter | /ˈsɪstə/ |
| `doctor` | d + o + c + tor | /ˈdɒktə/ |
| `water` | w + a + ter | /ˈwɔːtə/ |
| `sugar` | s + u + g + ar | /ˈʃʊɡə/ |
| `hungry` | h + u + n + gr + y | /ˈhʌŋɡri/ |
| `number` | n + u + m + ber | /ˈnʌmbə/ |
| `tomorrow` | t + o + m + or + row | /təˈmɒrəʊ/ |
| `machine` | m + a + ch + in + e | /məˈʃiːn/ |

**三个观察**：
1. `-er` 结尾几乎都是 /ə/（sister / doctor / water / number）
2. 第一个音节常常弱化：sugar /ˈʃʊɡə/、machine /məˈʃiːn/、tomorrow /təˈmɒrəʊ/
3. `ar` 不总是 /ɑː/ —— `sugar` 是 /ʃʊɡə/，`car` 才是 /kɑː/。**这就是例外词**

> **拼读对照**：`sister` → s + i + s + ter → /s/ + /ɪ/ + /s/ + /t/ + /ə/ = /ˈsɪstə/
> 拼读给你「s-i-s-ter」，IPA 告诉你「er 是 /ə/，不是 /ɜː/」

> **拼读对照**：`hungry` → h + u + n + gr + y → /h/ + /ʌ/ + /ŋ/ + /ɡ/ + /ri/ = /ˈhʌŋɡri/
> 拼读给你「短元音 u」，IPA 告诉你「是 /ʌ/；而且 n 后面多了一个 /ŋ/」

> **拼读对照**：`machine` → m + a + ch + in + e → /m/ + /ə/ + /ʃ/ + /iː/ + /n/ = /məˈʃiːn/
> 拼读给你「m-a-ch-i-n-e」，IPA 告诉你「a 读 /ə/、结尾 e 不发音」

## 三、今天要练的
