# P02-S4 · 拼读对照实战：四步跑中元音

> 🔤 英语音标速成课 · 单元 P02 · 第 4 节 · 约 40 分钟

---

## 今天学什么

今天把前元音学过的四步法升级：**同样的四步，换上中元音的符号。**

1. **圈元音**：一个音节一个元音。
2. **配符号**：前元音那套不够用了，今天从 /ɜː/ /ə/ /ʌ/ 里挑。
3. **配辅音**。
4. **加外壳**：前后加 `/`，多音节词标重音 `ˈ`。

---

## 二、跑五个词

**`cup`** —— 元音 `u` → /ʌ/ → c→/k/、p→/p/ → **/kʌp/**

**`work`** —— 元音 `or` → /ɜː/ → w→/w/、k→/k/ → **/wɜːk/**

**`sun`** —— 元音 `u` → /ʌ/ → s→/s/、n→/n/ → **/sʌn/**

**`teacher`** —— 元音两个：`ea` 重读 → /iː/，`er` 弱读 → /ə/ → t→/t/、ch→/tʃ/ → 重音在第一音节 → **/ˈtiːtʃə/**

**`problem`** —— 元音两个：`o` 重读 → /ɒ/，`e` 弱读 → /ə/ → **/ˈprɒbləm/**

**写不出来的音标，就是还没配上的符号——回 P02-S3 查。**

---

## 三、拼读对照：四步压成一行

> **拼读对照**：`sun` → s + u + n → /s/ + /ʌ/ + /n/ = /sʌn/
> 拼读给你「读得出」，IPA 给你「说得准」

> **拼读对照**：`work` → w + or + k → /w/ + /ɜː/ + /k/ = /wɜːk/
> 拼读给你「读得出」，IPA 给你「说得准」

> **拼读对照**：`teacher` → t + ea + ch + er → /t/ + /iː/ + /tʃ/ + /ə/ = /ˈtiːtʃə/
> 拼读给你「读得出」，IPA 给你「说得准」

> **拼读对照**：`problem` → pr + o + bl + e + m → /p/ + /r/ + /ɒ/ + /b/ + /l/ + /ə/ + /m/ = /ˈprɒbləm/
> 拼读给你「读得出」，IPA 给你「说得准」

## 五、今天要练的

1. **默写四步法**：圈元音 → 配符号 → 配辅音 → 加外壳。
2. **批量实战**：上面八个词先自己写，再对答案。
3. **数一数**：八个词里，一共有几个 /ə/？
4. **出声核对**：每个词写完念一遍，念的那一声和符号对不上就重配。

## 六、今天不用管的

- ❌ 不用改你的声音——四步法只动笔。
- ❌ 不用追求写得快，先写对。
- ❌ 不用管 /ɑː/ /aʊ/ 这些还没正式学的符号。
- ❌ 不用管连读和失爆（很高级的东西，等符号熟了再说）。
