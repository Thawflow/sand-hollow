## 一、认音热身 + 三组辨析

看符号，念出来（30 秒）：

`/eɪ/`　`/aɪ/`　`/ɔɪ/`　`/eɪ/`　`/ɔɪ/`　`/aɪ/`

**窍门**：全部收在 /ɪ/，只有起点不同 —— 半开 / 大张 / 撅圆。

| 对比 | IPA | 差别在哪 |
|---|---|---|
| `cap` / `cape` | /kæp/ / /keɪp/ | 短 a（单元音） vs a_e（滑动） |
| `bay` / `boy` | /beɪ/ / /bɔɪ/ | 起点半开 vs 撅圆 |
| `tie` / `toy` | /taɪ/ / /tɔɪ/ | 起点大张 vs 撅圆 |

> **拼读对照**：`cap` → c + a + p → /k/ + /æ/ + /p/ = /kæp/
> `cape` → c + a_e + p → /k/ + /eɪ/ + /p/ = /keɪp/
> 同一个 a，加一个 e 就从「单元音」变成「滑动音」 —— 这就是 a_e 规则的全部秘密。
> 拼读给你「读得出」，IPA 给你「说得准」

## 二、标注冲刺 + 例外词清扫

标出每个词里**双元音的那一段**：

| 单词 | 完整 IPA | 目标音 |
|---|---|---|
| `name` | /neɪm/ | /eɪ/ |
| `kite` | /kaɪt/ | /aɪ/ |
| `boil` | /bɔɪl/ | /ɔɪ/ |
| `face` | /feɪs/ | /eɪ/ |
| `night` | /naɪt/ | /aɪ/ |
| `joy` | /dʒɔɪ/ | /ɔɪ/ |
| `plate` | /pleɪt/ | /eɪ/ |
| `spoil` | /spɔɪl/ | /ɔɪ/ |

**规律**：a_e → /eɪ/ ｜ i_e、igh → /aɪ/ ｜ oi、oy → /ɔɪ/

**例外词**（对不上的都算收获）：

| 单词 | 拼读会推成 | 实际是 |
|---|---|---|
| `height` | /heɪt/ | /haɪt/ |
| `said` | /seɪd/ | /sed/ |
| `have` | /heɪv/ | /hæv/ |
| `give` | /ɡaɪv/ | /ɡɪv/ |
| `friend` | /friːnd/ | /frend/ |
| `says` | /seɪz/ | /sez/ |

> **拼读对照**：`give` → g + i + v + e → 你会推成 /ɡ/ + /aɪ/ + /v/ = /ɡaɪv/
> 实际是 /ɡɪv/。**对不上的那一刻，就是 IPA 存在的理由** —— 拼读给你「读得出」，IPA 给你「说得准」

**六条全部不按拼读走** —— 这就是为什么光会拼读不够，IPA 是纠错工具 🔍
