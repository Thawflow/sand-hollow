# P01-S3 · /e/ vs /æ/：中国学生最常混的一对

> 🔤 英语音标速成课 · 单元 P01 · 第 3 节 · 约 35 分钟

---

## 今天学什么

`bed` 和 `bad` 你当然读得对，但换成 `pen` / `pan`、`said` / `sad` 就容易糊。
这一节专治这一对。核心只有一句：**/æ/ 要把下巴放下来，/e/ 不放。**
学完你能靠嘴型、而不是靠背单词表，稳定分清这两个音。

---

## 一、嘴型的分水岭

| | /e/ | /æ/ |
|---|---|---|
| 舌位 | 中等偏高 | 最低，几乎压到下颚底 |
| 口型 | 半开，嘴自然张开 | 张到最大，下巴明显下掉 |
| 下巴 | 基本不动 | 会掉下去，看得见 |
| 时长 | 中等，收得干脆 | 短而「闷」，带一点爆破感 |
| 拼读 | 短音 `e` | 短音 `a` |
| 例词 | bed /bed/ · ten /ten/ · head /hed/ | bad /bæd/ · cat /kæt/ · hand /hænd/ |

**要领**：/e/ 舌尖抵下齿、声音靠前；/æ/ 嘴开得更大、舌头压得更低。
最省事的自测：**下巴顶住手指** —— 明显撞到的那个就是 /æ/。

---

## 二、最小对立对 + 一个大坑

| /e/ | /æ/ | 意思差别 |
|---|---|---|
| bed /bed/ | bad /bæd/ | 床 / 坏 |
| pen /pen/ | pan /pæn/ | 钢笔 / 平底锅 |
| pet /pet/ | pat /pæt/ | 宠物 / 轻拍 |
| men /men/ | man /mæn/ | 男人们 / 男人 |
| said /sed/ | sad /sæd/ | 说过 / 悲伤 |
| head /hed/ | had /hæd/ | 头 / 有（过去式） |
| ten /ten/ | tan /tæn/ | 十 / 棕褐色 |

> **拼读对照**：`bad` → b + a + d → /b/ + /æ/ + /d/ = /bæd/
> 拼读给你「读得出」，IPA 给你「说得准」

> **拼读对照**：`said` → s + ai + d → /s/ + /e/ + /d/ = /sed/
> 拼读给你「读得出」，IPA 给你「说得准」
> 注意！`ai` 在这里**不读 /eɪ/** —— 拼读规则失手了，IPA 一眼就看穿

### ⚠️ 大坑：短音 `a` 也有例外

拼读规则说「短音 a = /æ/」，但这些词要读别的音：
`give` /ɡɪv/、`live` /lɪv/、`some` /sʌm/、`love` /lʌv/、`come` /kʌm/、`blood` /blʌd/。
**别背单词表** —— 遇到不认识的词，先用拼读推一个音，再用 IPA 回头核对。

还有个特别的：`have` 重读时是 /hæv/，轻读时变成 /həv/ —— 同一个词两种音，
这在 IPA 里一眼就能看出来，光靠拼读你可猜不到。

## 三、今天要练的

1. **手写 + 镜前**：/e/ /æ/ 各抄 5 遍；对镜子读 `bed` 再读 `bad`，盯住下巴
2. **最小对立对**：抄 7 组，盖住右边那一列，自己填回去
3. **下巴测试**：下巴顶手指，连续读 `bed bad bed bad`，只有 /æ/ 该撞手指
4. **例外词表**：给 `give live some love come` 各标一个音标，记住「短 a ≠ 总是 /æ/」；
   再给 `have` 标出重读 /hæv/ 和轻读 /həv/ 两种

## 四、今天不用管的

- ❌ 不用管字母 `a` 的所有读法（`a_e` 是双元音 /eɪ/，P04 讲）
- ❌ 不用现在分 /e/ 和 /ɪ/（近音辨析在 S05 统一做）
- ❌ 不用背长串例外词（记住「例外存在」这件事就够了）
