## 二、实战清单

1. **正向**：看到词写符号 —— `chair` `beds` `nine` `dream` `school` `yes`
2. **反向**：看到符号找词 —— /tʃ/ /dz/ /ŋ/ /l/ /w/ /j/ 各写一个
3. **例外词**：`water` /ˈwɔːtə/ · `two` /tuː/
4. **音节重音**：`computer` /kəmˈpjuːtə/ 三拍，重音第 2
5. **连读弱读**：`go to bed` /ˈɡəʊtəbed/ · `a lot of` /əˈlɒtəv/

> **拼读对照**：`teacher` → t + each + r → /t/ + /iː/ + /tʃ/ + /ə/ + /r/ = /ˈtiːtʃə(r)/
> 拼读给你「读得出」，IPA 给你「说得准」

> **拼读对照**：`music` → m + u + sic → /m/ + /juː/ + /z/ + /ɪ/ + /k/ = /ˈmjuːzɪk/
> 拼读给你「读得出」，IPA 给你「说得准」
