> **拼读对照**：`think` → th + i + nk → /θ/ + /ɪ/ + /ŋ/ + /k/ = /θɪŋk/ → 落在总表「摩擦音 /θ/」+「鼻音 /ŋ/」
> 拼读给你「读得出」，IPA 给你「说得准」

> **拼读对照**：`beautiful` → beau + ti + ful → /b/ + /juː/ + /t/ + /ɪ/ + /f/ + /ə/ + /l/ = /ˈbjuːtɪf(ə)l/ → 元音 /juː/ /ɪ/ /ə/ + 辅音 /b/ /t/ /f/ /l/，一次用掉 7 个音标

## 二、随身清单：4 步法 + 3 个附加动作

**核心 4 步**
1. 拼读切词，推出读音
2. 写出 IPA 标注
3. 对不上 → 标记「例外词」
4. 查带音标的词典确认

**附加 3 步（进阶）**
5. 数元音核心 → 数音节
6. 在重读音节前标 /ˈ/
7. 放进句子里读一遍 → 检查弱读与连读

**自查用的 30 个词**（每个都走一遍 7 步，纸上写音标）：
`beautiful` `computer` `population` `one` `island` `colonel` `though` `come` `says` `woman` `rocket` `think` `light` `apple` `water` `idea` `difficult` `information` `celebrate` `family` `table` `want` `little` `sugar` `doctor` `nature` `picture` `music` `coffee` `career`

## 三、今天要练的
