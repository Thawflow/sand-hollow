单元 P01 到最后一节了。这一节把四个前元音拉到一起：

---

## 一、近音辨析：最容易打架的 5 组

| 易混 | 差别一句话 | 测试词对 |
|---|---|---|
| /iː/ ↔ /ɪ/ | 长紧 vs 短松 | ship /ʃɪp/ — sheep /ʃiːp/ |
| /e/ ↔ /æ/ | 嘴半开 vs 嘴张最大 | pen /pen/ — pan /pæn/ |
| /iː/ ↔ /e/ | 嘴扁舌高 vs 嘴半开 | seat /siːt/ — set /set/ |
| /ɪ/ ↔ /e/ | 短而松 vs 短但嘴更开 | sit /sɪt/ — set /set/ |
| /ɪ/ ↔ /æ/ | 短而松 vs 短而大 | bit /bɪt/ — bat /bæt/ |

**读法**：先读左边那个音，再读右边那个音，**只换嘴型，不换词**。
`bit` → `bat` 只差下巴掉没掉；`sit` → `set` 只差嘴张没张。

> ⚠️ 陷阱词：`fall` 是 /fɔːl/（长 o），不是 /æ/。
> **遇到拿不准的音，先标出来，别硬套。**

## 二、综合练习

> **拼读对照**：`green` → gr + ee + n → /ɡ/ + /r/ + /iː/ + /n/ = /ɡriːn/
> 拼读给你「读得出」，IPA 给你「说得准」

> **拼读对照**：`head` → h + ea + d → /h/ + /e/ + /d/ = /hed/
> 拼读给你「读得出」，IPA 给你「说得准」
> `ea` 在这里读短音 /e/ —— 又一个例外，记进你的例外表

### A. 标音（10 个词）

```
see, sit, bed, bad, green, ten, hat, eat, head, man
```

### B. 选音（选一个前元音，**注意有陷阱**）

| 单词 | 选 /iː/ /ɪ/ /e/ /æ/ |
|---|---|
| `rain` | ? |
| `red` | ? |
| `bit` | ? |
| `sand` | ? |

> ⚠️ `rain` 可能没有正确答案 —— 那就写下你实际听到的音。

### C. 找同音（下面 6 个词里，哪两个的元音是同一个音？）

`sheep, ship, step, stop, dad, bad` —— 注意 `stop` 是 /ɒ/（不是本单元的音）。

### 参考答案

A. /siː/ /sɪt/ /bed/ /bæd/ /ɡriːn/ /ten/ /hæt/ /iːt/ /hed/ /mæn/
B. rain /reɪn/ —— /eɪ/ 是双元音，**不在本单元的四个音里**（陷阱）· red /e/ · bit /ɪ/ · sand /æ/
C. 同音的是 `dad` /dæd/ 和 `bad` /bæd/ —— 元音都是 /æ/。
   其余：sheep /iː/、ship /ɪ/、step /e/、stop /ɒ/（本单元之外）
