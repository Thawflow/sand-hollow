# P06-S1 · 辅音两大类总览：16 个符号 + 词锚点

> 🔤 英语音标速成课 · 单元 P06 · 第 1 节 · 约 30 分钟

---

## 今天学什么

辅音 **16 个符号**：/p b t d k g/ + /f v s z θ ð ʃ ʒ h r/。
**你的发音不用改。** 这是门「写字课」：听到词，知道辅音写哪个符号。

---

## 一、两大类：先看牌子

| 类别 | 符号 |
|---|---|
| 爆破音（6 个） | /p/ /b/ /t/ /d/ /k/ /g/ |
| 摩擦音（10 个） | /f/ /v/ /s/ /z/ /θ/ /ð/ /ʃ/ /ʒ/ /h/ /r/ |

名字只是**分类标签**。S2 前 6 个 · S3 /f v s z h/ · S4 最后 5 个。

---

## 二、16 个符号的词锚点总表

每个符号先绑 3 个你早就认识的词。

| 符号 | 你早就认识的词 + 完整音标 |
|---|---|
| /p/ | `pink` 粉 /pɪŋk/ · `park` 公园 /pɑːk/ · `map` 地图 /mæp/ |
| /b/ | `big` 大的 /bɪɡ/ · `book` 书 /bʊk/ · `job` 工作 /dʒɒb/ |
| /t/ | `ten` 十 /ten/ · `time` 时间 /taɪm/ · `water` 水 /ˈwɔːtə/ |
| /d/ | `dog` 狗 /dɒɡ/ · `red` 红色的 /red/ · `bed` 床 /bed/ |
| /k/ | `cat` 猫 /kæt/ · `key` 钥匙 /kiː/ · `black` 黑色的 /blæk/ |
| /g/ | `go` 去 /ɡəʊ/ · `good` 好的 /ɡʊd/ · `girl` 女孩 /ɡɜːl/ |
| /f/ | `four` 四 /fɔː/ · `fish` 鱼 /fɪʃ/ · `leaf` 叶子 /liːf/ |
| /v/ | `very` 非常 /ˈveri/ · `love` 爱 /lʌv/ · `give` 给 /ɡɪv/ |
| /θ/ | `think` 想 /θɪŋk/ · `three` 三 /θriː/ · `thank` 谢谢 /θæŋk/ |
| /ð/ | `this` 这个 /ðɪs/ · `that` 那个 /ðæt/ · `they` 他们 /ðeɪ/ |
| /s/ | `sun` 太阳 /sʌn/ · `see` 看见 /siː/ · `city` 城市 /ˈsɪti/ |
| /z/ | `zoo` 动物园 /zuː/ · `zero` 零 /ˈzɪərəʊ/ · `is` 是 /ɪz/ |
| /ʃ/ | `she` 她 /ʃiː/ · `shop` 商店 /ʃɒp/ · `wash` 洗 /wɒʃ/ |
| /ʒ/ | `usually` 通常 /ˈjuːʒuəli/ · `television` 电视 /ˈtelɪvɪʒn/ · `measure` 测量 /ˈmeʒə/ |
| /h/ | `hat` 帽子 /hæt/ · `house` 房子 /haʊs/ · `high` 高的 /haɪ/ |
| /r/ | `red` 红色的 /red/ · `run` 跑 /rʌn/ · `room` 房间 /ruːm/ |

> **拼读对照**：`cat` → c + a + t → /k/ + /æ/ + /t/ = /kæt/
> 拼读给你「读得出」，IPA 给你「说得准」

> **拼读对照**：`think` → th + i + nk → /θ/ + /ɪ/ + /ŋ/ + /k/ = /θɪŋk/
> 拼读给你「读得出」，IPA 给你「说得准」

## 三、7 对长得像的牌子：只比词

/p/–/b/：`pig`–`big`　/t/–/d/：`ten`–`den`　/k/–/g/：`coat`–`goat`
/f/–/v/：`fan`–`van`　/s/–/z/：`sip`–`zip`　/θ/–/ð/：`think`–`this`　/ʃ/–/ʒ/：`wash`–`measure`
/h/ 没搭档 · /r/ 自成一格
