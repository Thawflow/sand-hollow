## 一、7 组清浊对照总表

| 部位 | 清音 | 浊音 | 例词对 |
|---|---|---|---|
| 双唇 | /p/ | /b/ | pig /pɪg/ – big /bɪg/ |
| 齿龈 | /t/ | /d/ | ten /ten/ – den /den/ |
| 舌根 | /k/ | /g/ | cat /kæt/ – got /gɑːt/ |
| 唇齿 | /f/ | /v/ | fan /fæn/ – van /væn/ |
| 齿龈 | /s/ | /z/ | sip /sɪp/ – zip /zɪp/ |
| 齿间 | /θ/ | /ð/ | think /θɪŋk/ – this /ðɪs/ |
| 舌面 | /ʃ/ | /ʒ/ | she /ʃiː/ – measure /ˈmeʒə/ |

**另外两个成员**：
- **/h/** —— 没有浊音搭档，单独一类（喉部摩擦）
- **/r/** —— 美音里是浊音，但位置独立（卷舌），不算进配对表

**清音 7 个**：/p t k f s θ ʃ/　**浊音 7 个**：/b d g v z ð ʒ/

> 记忆法：**清音气流多，浊音喉咙动**。手放喉咙，震动 = 右边那一列。

## 二、综合练习

### A · 听音辨位

听录音（自己念也可以），在括号里填音标：

1. ( ) three　2. ( ) zoo　3. ( ) very　4. ( ) shirt　5. ( ) bike
6. ( ) those　7. ( ) big　8. ( ) face　9. ( ) this　10. ( ) zoo

**答案**：/θriː/ /zuː/ /ˈveri/ /ʃɜːt/ /baɪk/ /ðəʊz/ /bɪg/ /feɪs/ /ðɪs/ /zuː/

### B · 拼读 → 音标

先拼读，再写音标。这是你已经会的事，只是贴上标签：

| 单词 | 拼读拆分 | 完整音标 |
|---|---|---|
| `think` | th + i + nk | |
| `shop` | sh + o + p | |
| `mother` | m + o + ther | |
| `doctor` | d + o + c + tor | |
| `dark` | d + ar + k | |
| `living` | l + i + v + i + ng | |

**答案**：/θɪŋk/ /ʃɑːp/ /ˈmʌðə/ /ˈdɒktə/ /dɑːk/ /ˈlɪvɪŋ/

> **拼读对照**：`living` → l + i + v + i + ng → /l/ + /ɪ/ + /v/ + /ɪ/ + /ŋ/ = /ˈlɪvɪŋ/
> 拼读给你「读得出」，IPA 给你「说得准」

### C · 找出清浊错配

下面每一组有一处**不是**最小对立对，找出来：

1. `pen` / `Ben`　2. `sip` / `tip`　3. `fan` / `van`　4. `think` / `sink`

**答案**：第 2 组。/s/ 和 /t/ 不是清浊配对（/t/ 的搭档是 /d/）。
