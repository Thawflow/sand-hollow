# P01-S2 · /iː/ vs /ɪ/：长音与短音的对立

> 🔤 英语音标速成课 · 单元 P01 · 第 2 节 · 约 35 分钟

---

## 今天学什么

同一个字母 `i`，为什么有时读「衣——」，有时读「衣」？这一节把这件事钉死。
你会拿到一张**对照表**和一批**最小对立对**（只差一个音的词对），
然后发现：英语里「长度」和「松紧」是一套系统 —— 长音紧，短音松。

---

## 一、两张脸：/iː/ 与 /ɪ/ 对照

| | /iː/ | /ɪ/ |
|---|---|---|
| 写法 | 后面带长音符号 **ː** | 短音，**没有**符号 |
| 时长 | 长，拖住一拍半 | 短，一拍收住 |
| 舌位 | 高且**紧**，舌面贴上颚 | 高但**松**，到位即可 |
| 口型 | 扁，嘴角向两边咧 | 微扁，几乎不咧嘴 |
| 肌肉 | 喉咙紧绷 | 放松 |
| 拼读 | `ee` / `ea` | 短音 `i` |
| 例词 | see /siː/ · eat /iːt/ · green /ɡriːn/ | sit /sɪt/ · ship /ʃɪp/ · city /ˈsɪti/ |

**要领一句话**：/iː/ 是「摆好姿势再发声」，/ɪ/ 是「随手就发声」。

---

## 二、最小对立对：只换一个音，意思全变

| 长音 /iː/ | 短音 /ɪ/ | 意思差别 |
|---|---|---|
| sheep /ʃiːp/ | ship /ʃɪp/ | 绵羊 / 船 |
| eat /iːt/ | it /ɪt/ | 吃 / 它 |
| leave /liːv/ | live /lɪv/ | 离开 / 居住 |
| seat /siːt/ | sit /sɪt/ | 座位 / 坐 |
| feel /fiːl/ | fill /fɪl/ | 感觉 / 装满 |
| green /ɡriːn/ | grin /ɡrɪn/ | 绿色 / 咧嘴笑 |
| deal /diːl/ | dill /dɪl/ | 交易 / 莳萝 |

> **拼读对照**：`sheep` → sh + ee + p → /ʃ/ + /iː/ + /p/ = /ʃiːp/
> 拼读给你「读得出」，IPA 给你「说得准」

> **拼读对照**：`ship` → sh + i + p → /ʃ/ + /ɪ/ + /p/ = /ʃɪp/
> 拼读给你「读得出」，IPA 给你「说得准」
> 同一个 `sh`，拼读救不了你 —— 只有 IPA 能把「松紧长短」写出来

**别背规则，去做对比**：这 7 组各读 3 遍。第一遍正常，第二遍**故意把长音压短**，
第三遍**故意把短音拉长** —— 你会立刻听出哪边不对劲。

## 三、今天要练的

1. **手写对照表**：把第一节那张表抄一遍，每个音标自己写 5 遍
2. **最小对立对**：把上面 7 组抄到本子上，盖住音标，自己标回去
3. **录音自查**：录 30 秒，读 7 组词对。回放时问自己：长音真的拖住了吗？短音真的短吗？
4. **翻找**：在身边找 5 个含 /iː/ 的词、5 个含 /ɪ/ 的词，标上音标

## 四、今天不用管的

- ❌ 不用管 /iː/ 和 /ɪ/ 的历史来源
- ❌ 不用纠结「标准英音 vs 美音」差异（美音里 /ɪ/ 更松，够用）
- ❌ 不用提前学 /e/ /æ/（下一节处理）
