# P04-S3 · /aɪ/ 与 /ɔɪ/：i_e 和 oi 拼读

> 🔤 英语音标速成课 · 单元 P04 · 第 3 节 · 约 35 分钟

---

## 今天学什么

上节课拿下了 /eɪ/，今天一次拿下它的两个兄弟：/aɪ/ 和 /ɔɪ/。
它们跟你拼读表里的 `i_e` 和 `oi` 直接挂钩 —— 学会读法，也学会怎么判断哪个词走哪条路。
重点：**/ɔɪ/ 看着像 /ɔː/ 加 /ɪ/，但它不是，它是一个滑动整体** 🎯

---

## 一、/aɪ/ 与 /ɔɪ/：两个兄弟，两种起点

### /aɪ/ —— 嘴大张，滑向「伊」

**写法**：`/aɪ/` —— **a** 和 **ɪ** 并排：前面标起点口型，后面标滑向哪里。**滑动方向**：/a/ → /ɪ/

- 起点 /a/：**嘴张到最大**，舌位低平靠后，像看医生说「啊——」
- 终点 /ɪ/：嘴微微收窄，舌前部抬起
- **易错**：起点不够开，听起来像 /eɪ/。记住「张大嘴」

| 拼读 | 单词 | IPA |
|---|---|---|
| i_e | `time` | /taɪm/ |
| i_e | `light` | /laɪt/ |
| i_e | `kite` | /kaɪt/ |
| i_e | `nice` | /naɪs/ |
| i_e | `five` | /faɪv/ |

> **拼读对照**：`time` → t + i_e + m → /t/ + /aɪ/ + /m/ = /taɪm/
> `tim`（去掉 e）读 /tɪm/ —— 那个 e 就是「拉开嘴、启动滑动」的那张开关。
> 拼读给你「读得出」，IPA 给你「说得准」

### /ɔɪ/ —— 撅圆嘴，滑向「伊」

**写法**：`/ɔɪ/` —— **o** 和 **ɪ** 并排。**滑动方向**：/ɔ/ → /ɪ/

- 起点 /ɔ/：**双唇撅圆前突**，像吹 /ɔː/，但别噘太久
- 终点 /ɪ/：唇立刻放开，舌前抬起
- **易错**：起点不圆唇 → 像 /aɪ/。圆唇是 /ɔɪ/ 的身份证

| 拼读 | 单词 | IPA |
|---|---|---|
| oi | `oil` | /ɔɪl/ |
| oi | `coin` | /kɔɪn/ |
| oi | `boil` | /bɔɪl/ |
| oy | `boy` | /bɔɪ/ |
| oy | `toy` | /tɔɪ/ |

> **拼读对照**：`coin` → c + oi + n → /k/ + /ɔɪ/ + /n/ = /kɔɪn/
> `oy` 是 `oi` 的变体（多在词尾），都读 /ɔɪ/。
> 拼读给你「读得出」，IPA 给你「说得准」

## 二、三个音怎么分？

| | /eɪ/ | /aɪ/ | /ɔɪ/ |
|---|---|---|---|
| 起点 | /e/ 半开 | /a/ **大张** | /ɔ/ **撅圆** |
| 终点 | /ɪ/ | /ɪ/ | /ɪ/ |
| 拼读线索 | a_e | i_e | oi / oy |
| 例词 | `name` | `time` | `boy` |

**秒判法**：先看起点 —— 半开 /eɪ/，大张 /aɪ/，撅圆 /ɔɪ/。三个都收在同一个 /ɪ/ 上。

| 词 | IPA | 注意 |
|---|---|---|
| `boy` | /bɔɪ/ | 不是 /bɔ/ + /ɪ/ 两个音，是一个滑动 |
| `boil` | /bɔɪl/ | 词尾那个 l 单独读 /l/，别带出多余音 |
