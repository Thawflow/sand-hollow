# P02-S1 · 中元音入门：三个符号，三组你认识的词

> 🔤 英语音标速成课 · 单元 P02 · 第 1 节 · 约 35 分钟

---

## 今天学什么

不学发音。你的 `cup`、`bird`、`about` 读得比很多大人准。

今天只做一件事：**给三个中元音符号 /ɜː/ /ə/ /ʌ/ 贴词签。**

| 符号 | 你早就认识的词 | 中文 |
|---|---|---|
| /ɜː/ | `bird` `girl` `work` `nurse` `turn` | 鸟 / 女孩 / 工作 / 护士 / 转弯 |
| /ə/ | `about` `teacher` `banana` `sister` `problem` | 关于 / 老师 / 香蕉 / 姐妹 / 问题 |
| /ʌ/ | `cup` `bus` `sun` `run` `mother` | 杯子 / 公交车 / 太阳 / 跑 / 妈妈 |

十五个词，全是你会读、会背、知道意思的。今天只加名字，不加声音。

---

## 一、为什么这三个要一起学

它们有一个共同点：**声音都是从嘴巴中间出来的**，不像前元音那样靠前，也不像后元音那样靠后。

所以48 音标把它们三个放在一起，叫**中元音**。

前元音那一单元你用的是「前」，这一单元用的是「中」——**这是分类方式变了，不是你的读法变了。**

---

## 二、三组词签

- **/ɜː/** —— `bird` 鸟、`girl` 女孩、`work` 工作、`nurse` 护士、`turn` 转弯：长长的、稳稳的一声。
- **/ə/** —— `about` 关于、`teacher` 老师、`banana` 香蕉、`sister` 姐妹、`problem` 问题：轻轻的、短短的一声，英语里出现得最多的音。
- **/ʌ/** —— `cup` 杯子、`bus` 公交车、`sun` 太阳、`run` 跑、`mother` 妈妈：短短的一声，往上兜一下。

三个符号，长的、弱的、兜的，各有各的词签。

---

## 三、拼读对照：左边拼法，右边符号

> **拼读对照**：`bird` → b + ir + d → /b/ + /ɜː/ + /d/ = /bɜːd/
> 拼读给你「读得出」，IPA 给你「说得准」

> **拼读对照**：`cup` → c + u + p → /k/ + /ʌ/ + /p/ = /kʌp/
> 拼读给你「读得出」，IPA 给你「说得准」

> **拼读对照**：`sister` → s + i + s + t + er → /s/ + /ɪ/ + /s/ + /t/ + /ə/ = /ˈsɪstə/
> 拼读给你「读得出」，IPA 给你「说得准」

**发现了吗？** `sister` 结尾的 `er` 写作 /ə/，`bird` 中间的 `ir` 却写作 /ɜː/。拼写相似，符号不同——这就是必须记符号的理由。

## 四、反向练：给词写符号

`cup` `girl` `bus` `teacher` `sun` `work` `mother` `sister`

逐个写出完整音标，写完念一遍核对。

## 五、今天要练的

1. **抄词卡**：三个符号，每个配四个词，写在符号旁边。
2. **反向练**：上面八个词逐个写音标。
3. **朗读**：十五个词读三遍，每个词读的时候在脑子里喊它的符号。
4. **找一找**：在课外书里找三个含 /ə/ 的词，抄下来。
