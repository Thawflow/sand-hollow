## 二、综合练习

### A · 看词写符号

1. `chair` 2. `beds` 3. `nine` 4. `dream` 5. `school` 6. `yes` 7. `sing` 8. `tree`

**答案**：/tʃeər/ /bedz/ /naɪn/ /driːm/ /skuːl/ /jes/ /sɪŋ/ /triː/

### B · 三组最小对撞

1. `bets` / `beds` 2. `light` / `night` 3. `sin` / `sing`

**答案**：/bets/–/bedz/（/ts/ vs /dz/）· /laɪt/–/naɪt/（/l/ vs /n/）· /sɪn/–/sɪŋ/（/n/ vs /ŋ/）

> **拼读对照**：`children` → child + ren → /tʃ/ + /ɪ/ + /l/ + /d/ + /r/ + /ə/ + /n/ = /ˈtʃɪldrən/
> 拼读给你「读得出」，IPA 给你「说得准」

> **拼读对照**：`school` → s + ch + oo + l → /s/ + /k/ + /uː/ + /l/ = /skuːl/
> 拼读给你「读得出」，IPA 给你「说得准」
