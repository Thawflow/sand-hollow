## 一、概念：循环真正的威力（3 分钟）

打 5 行 Hello 像玩具。for 循环真正的威力是「**累加**」——把一堆数压成一个数：

- 算这个月花了多少钱（10 笔加一起）
- 算全班平均分（30 个分数加完除以 30）
- 盘点库存（50 件商品数件数）

记住四个字：**先建箱子，再往里扔**。

## 二、第一招：求和（5 分钟）

```python
total = 0
for i in range(1, 11):
    total = total + i
print("Sum 1-10 =", total)
```

运行得 `Sum 1-10 = 55`（高斯 7 岁就算出来过，你也不差）。

### 累加器四件套

| 部件 | 作用 |
|---|---|
| `total = 0` | **建箱子**：起手归零 |
| `for i in range(...)` | 循环：逐个取数 |
| `total = total + i` | **往里扔**：把当前数加进箱子 |
| `print(...)` | **出箱子**：循环结束看结果 |

`total = total + i` 看着像"自己等于自己"，其实是**先算右边、再装进左边**：右边的 total 是老总和，左边是装上新值的箱子。每轮循环，箱子长大一圈。

**简短写法：** `total += i` 等价于 `total = total + i`，以后常用。

## 三、第二招：计数（4 分钟）

计数 = 每看到目标，箱子 +1：

```python
count = 0
for i in range(1, 21):
    if i % 2 == 0:
        count += 1
print("Even numbers in 1-20:", count)
```

- `count = 0`：建空计数器
- `if i % 2 == 0`：是偶数吗（W03 的 if 在循环里上班了！）
- `count += 1`：是的话计数器 +1

**for 循环里放 if**——两个老朋友合体，这是本周最重要的形态。

**今日口诀：** 建箱子、进循环、往里扔、出箱子。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
int main() {
    int sum = 0;
    for (int i = 1; i <= 10; i++) {
        sum += i;
    }
    std::cout << "sum = " << sum << std::endl;
    return 0;
}
```

三个认脸：

1. `int sum = 0;` 初始化累加器
2. `sum += i;` 累加（Python 一样）
3. `sum` 默认 int，C++ 必须声明类型
