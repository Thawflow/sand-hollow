## 一、概念：条件还没失败，我就要停（2 分钟）

while 老老实实看条件。但有时候：密码对了何必再问？找到目标了何必再翻？

**break = 喊停**——立刻跳出循环，不管条件还成不成立。

## 二、break：立刻跳出（4 分钟）

```python
for i in range(1, 11):
    if i == 6:
        print("Found 6, stop!")
        break
    print(i)
```

运行：1 2 3 4 5，然后 "Found 6, stop!"——6 没打印，7-10 全跳过。break 是循环的紧急出口，只跳出**所在的那一层**循环。

**缩进警报：** break 必须缩进在 if 手下。忘了缩进 → 第一轮就 break，循环一次活儿都没干。

## 三、continue：跳过这一轮（3 分钟）

跟 break 相反——**continue = 这轮不玩了，下一轮继续**：

```python
for i in range(1, 11):
    if i == 6:
        continue
    print(i)
```

打印 1-10 但唯独没有 6。口诀：**break 是全退，continue 是轮休**。

## 四、while...else：没被 break 才执行（3 分钟）

```python
password = "tiger"
tries = 0
while tries < 3:
    guess = input("Password: ")
    if guess == password:
        print("Welcome!")
        break
    tries += 1
    print(f"Wrong! {3 - tries} tries left")
else:
    print("Account locked")
```

这个 else 属于 **while** 不是 if：循环正常走完（没被 break）才执行它 → 三次全错，锁号。Python 独家语法，初见觉得怪，混个脸熟就好。

**今日口诀：** break 全退，continue 轮休；while 的 else，没被 break 才兑现。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
int main() {
    for (int i = 1; i <= 100; i++) {
        if (i > 5) break;
        std::cout << i << std::endl;
    }
    return 0;
}
```

三个认脸：

1. `break` 跳出最近一层 for
2. AI 训练 `if loss > prev: break`
3. Python 一样：`if x > 5: break`
