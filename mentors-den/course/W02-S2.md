## 一、数字运算符全家福（5 分钟）

数学课的老朋友们（注意最后两位是新面孔）：

| 运算符 | 作用 | 例子 | 结果 |
|---|---|---|---|
| `+` `-` `*` | 加减乘 | `10 * 3` | `30` |
| `/` | 除（永远得 float！） | `10 / 3` | `3.3333...` |
| `//` | 整除（砍掉小数） | `10 // 3` | `3` |
| `%` | 取余数（剩下的） | `10 % 3` | `1` |

**`//` 和 `%` 是一对好搭档**——一个数可以拆成「几整份 + 零头」：

```python
3661 // 3600  # 1      —— 3661 秒里有 1 个完整小时
3661 % 3600   # 61     —— 去掉整小时，剩 61 秒
```

S5 的加速挑战（秒数换算）全靠这两位。**记住：一小时是 3600 秒**，不是 360（某位学徒在这里栽过 😼）。

## 二、⚠️ 转换翻车现场合集（5 分钟）

新手三大翻车，全读一遍（今天的作业就是绕开它们）：

**翻车 1：str + int 拼接**

```python
age = 11
print("我" + age + "岁")   # ❌ TypeError
# 修法：print(f"我{age}岁")  或  print("我" + str(age) + "岁")
```

**翻车 2：input 直接做数学**

```python
price = input("多少钱？")   # 收到 "5"（str！）
print(price * 3)           # "555" —— 复读机，不是 15！
```

**翻车 3：该用 float 的地方用了 int**

```python
price = int(input("单价？"))  # 输入 12.5 → 当场 ValueError
```

**规则一句话：** 答案可能带小数的问题用 `float()` 收，纯整数（个数、次数）用 `int()` 收。
