## 一、概念：if 只管晴天（3 分钟）

上次的年龄闸机有个尴尬：条件不满足时，屏幕一片安静，用户以为程序死了。真实世界要有 B 计划：

- 满了 18 → 欢迎入座
- 不满 18 → 「再等等，先去看猫武士」

今天两位新成员：**else**（否则）和 **elif**（否则如果）。

## 二、else：B 计划（4 分钟）

```python
n = int(input("Give me a whole number: "))

if n % 2 == 0:
    print(n, "is even")
else:
    print(n, "is odd")
```

输入 8 → 偶数；输入 7 → 奇数。**必有其一，只走其一。**

else 语法三件事：

- 行尾也要冒号
- 下面的行也要缩进 4 格
- **else 后面不接条件**——if 已经问过了，剩下的全归它

（还记得 `%` 吗？W02 说的"判断奇偶天天用"，今天兑现了。）

## 三、elif：多岔路口（5 分钟）

只有两条路不够用？**elif** = else + if 合体：

```python
height = int(input("Your height in cm? "))

if height >= 140:
    print("Any roller coaster you like!")
elif height >= 120:
    print("You can ride the small coaster")
else:
    print("Try the carousel first, build some courage")
```

身高 150 → 大过山车；125 → 小过山车；100 → 旋转木马。

## 四、命中即止：elif 链的灵魂（3 分钟）

Python 的走法：**从上往下扫描，命中一条，其余全部跳过。**

用 150 验证：150 >= 140 成立，150 >= 120 其实也成立——但只打印大过山车。命中第一条后，整串直接跳过，绝不回头。

| 身高 | >= 140？ | >= 120？ | 实际输出 |
|---|---|---|---|
| 150 | 真（命中） | 不再看 | 大过山车 |
| 125 | 假 | 真（命中） | 小过山车 |
| 100 | 假 | 假 | 落入 else：旋转木马 |

## 五、顺序陷阱（1 分钟）

把 `>= 120` 放在 `>= 140` **前面**会怎样？150 一进门就命中 120，永远坐不上大过山车。

**规矩：门槛从高到低排**（大的条件放前面）。

**今日口诀：** 从上往下，命中即止；门槛高的，站在前排。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
int main() {
    int score = 75;
    if (score >= 90) {
        std::cout << "A" << std::endl;
    } else if (score >= 60) {
        std::cout << "pass" << std::endl;
    } else {
        std::cout << "fail" << std::endl;
    }
    return 0;
}
```

三个认脸：

1. C++ 用 `else if`（Python 用 `elif`）
2. 大括号 `{}` 包代码块（Python 用缩进）
3. 多分支从上到下匹配，命中即停
