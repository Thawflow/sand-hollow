## 一、3 种 fib 实现（5 分钟）

```python
import time
from functools import lru_cache

# 1. Naive (O(2^n))
def fib_naive(n):
    if n < 2:
        return n
    return fib_naive(n - 1) + fib_naive(n - 2)

# 2. Manual memo (O(n))
def fib_memo(n, memo={}):
    if n in memo:
        return memo[n]
    if n < 2:
        return n
    memo[n] = fib_memo(n - 1, memo) + fib_memo(n - 2, memo)
    return memo[n]

# 3. @lru_cache (O(n), 1-line)
@lru_cache(maxsize=None)
def fib_cache(n):
    if n < 2:
        return n
    return fib_cache(n - 1) + fib_cache(n - 2)
```

## 二、对比：跑 fib(35)（3 分钟）

```python
for name, fn in [('naive', fib_naive), ('memo', fib_memo), ('cache', fib_cache)]:
    if name == 'cache':
        fib_cache.cache_clear()   # reset
    start = time.time()
    result = fn(35)
    print(f'{name:6s}: {time.time()-start:.4f}s  result={result}')
```

**结果**：
- naive: ~5.0s
- memo: ~0.0001s
- cache: ~0.0001s

**5 万倍加速**。

## 四、深入了解：@lru_cache 怎么工作（3 分钟）

```python
# equivalent
def fib_cache(n):
    if n in cache:    # check dict
        return cache[n]
    if n < 2:
        return n
    result = fib_cache(n - 1) + fib_cache(n - 2)
    cache[n] = result
    return result
cache = {}
```

**cache = dict**。`maxsize` 是 LRU 缓存大小（`None` = 无限）。

## 五、何时用：3 个 lru_cache 场景（3 分钟）

| 场景 | 用 lru_cache |
|---|---|
| 递归 fib | ✓ 必备 |
| 递归阶乘 | ✗ 单次调用无重复 |
| 递归爬楼梯 | ✓ 必备 |
| Web 缓存 API | ✓ 不同 |
| 缓存大对象 | ✗ 内存紧张 |

**AI 工程师原则**：递归 + 重叠子问题 = 加 cache。

## 七、答案

```python
import time
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    if n < 2: return n
    return fib(n - 1) + fib(n - 2)

# 1
start = time.time(); print(fib(35)); print(f'fib(35): {time.time()-start:.4f}s')

# 2
start = time.time(); print(fib(50)); print(f'fib(50): {time.time()-start:.4f}s')
# 12586269025
# fib(50): 0.0001s

# 3
@lru_cache(maxsize=None)
def factorial(n):
    if n == 0: return 1
    return n * factorial(n - 1)
```
