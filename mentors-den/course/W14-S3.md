## 一、核心想法（3 分钟）

fib(5) 调用栈展开：

```
fib(5)
├── fib(4)
│   ├── fib(3)
│   │   ├── fib(2)
│   │   │   ├── fib(1) = 1
│   │   │   └── fib(0) = 0
│   │   └── fib(1) = 1
│   └── fib(2)
│       ├── fib(1) = 1
│       └── fib(0) = 0
└── fib(3)
    ├── fib(2)
    │   ├── fib(1) = 1
    │   └── fib(0) = 0
    └── fib(1) = 1
```

数一下：fib(5) 调用 **15 次**。fib(10) 调用 **177 次**。fib(40) 调用 **1.65 亿次**。

**为什么这么多？** fib(3) 算了 2 次，fib(2) 算了 3 次——**重复**。

## 二、示例演算：fib(5) 调用次数（3 分钟）

| 节点 | 次数 | 节点 | 次数 |
|---|---|---|---|
| fib(5) | 1 | fib(1) | 8 |
| fib(4) | 1 | fib(0) | 5 |
| fib(3) | 2 | **总计** | **15** |
| fib(2) | 3 | | |

加缓存后：每个 fib(k) 只算 1 次 → 6 次（fib(0) 到 fib(5)）。

## 三、记忆化：算一次存起来（5 分钟）

```python
def fib_memo(n, memo=None):
    '''Fibonacci with memoization.'''
    if memo is None:
        memo = {}
    if n in memo:                 # cache hit
        return memo[n]
    if n == 0 or n == 1:          # base case
        memo[n] = n
        return memo[n]
    memo[n] = fib_memo(n - 1, memo) + fib_memo(n - 2, memo)
    return memo[n]
```

**关键**：算过的存 `memo[n]`，下次直接拿。

## 四、对比：朴素 vs 记忆化（5 分钟）

```python
import time

def fib_naive(n):
    if n == 0 or n == 1: return n
    return fib_naive(n - 1) + fib_naive(n - 2)

def fib_memo(n, memo=None):
    if memo is None: memo = {}
    if n in memo: return memo[n]
    if n == 0 or n == 1:
        memo[n] = n
        return n
    memo[n] = fib_memo(n - 1, memo) + fib_memo(n - 2, memo)
    return memo[n]

# Test: fib(35)
n = 35
start = time.time(); fib_naive(n); t1 = time.time() - start
start = time.time(); fib_memo(n); t2 = time.time() - start
print(f'fib_naive({n}): {t1:.2f}s')
print(f'fib_memo({n}): {t2:.4f}s')
print(f'Memo is {t1/t2:.0f}x faster')
```

跑一下。`fib(35)` 朴素要 ~5 秒，记忆化要 0.0001 秒。**几万倍**。

## 六、何时用：加缓存 vs 不加（3 分钟）

| 场景 | 加缓存 | 不加 |
|---|---|---|
| 重复子问题（递归树）| ✓ 必加 | 太慢 |
| 一次性计算 | ✗ 浪费内存 | ✓ |
| 输入空间大 | ✓（dict 索引 O(1)）| ✗ 重新算 |
| 内存紧张 | ✗（占空间）| ✓ |

**Python 内置**：`functools.lru_cache` —— 一行加缓存：

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    if n == 0 or n == 1: return n
    return fib(n - 1) + fib(n - 2)
```

比手动 `memo` dict 更简洁。
