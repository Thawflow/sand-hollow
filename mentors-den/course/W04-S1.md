## 一、概念：程序终于学会「重复」（3 分钟）

前三周的程序都是"直线剧本"——每行只做一次。但很多事是重复的：

- 战士训练每天做 100 个俯卧撑
- 商店货架每天补 30 件商品
- 记账要数 12 个月的开销

**for 循环**让程序「把同一件事做 N 遍」。这一招是后面所有自动化程序的起点。

## 二、for 的样子（4 分钟）

```python
for i in range(5):
    print("Hello,", i)
```

输出：

```
Hello, 0
Hello, 1
Hello, 2
Hello, 3
Hello, 4
```

**关键观察：** `i` 从 **0** 开始，不是 1；到 4 结束，一共 5 次。程序员的传统，记住就好。

## 三、逐字拆解：for 四件套（3 分钟）

| 部件 | 作用 |
|---|---|
| `for` | 「为了」每个值，做下面的事 |
| `i` | 临时变量，每次循环换一个新值 |
| `in range(5)` | 从 0、1、2、3、4 里逐个取 |
| `:` + 缩进 | 冒号 =「那么」，缩进的行每次循环都跑 |

发现没有？四件套跟 if 一模一样——**for 只是换了种"手下干活"的方式**：if 是"看情况干一次"，for 是"挨个干 N 次"。

**今日口诀：** for、变量、in range、冒号缩进——重复从此不费手。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
int main() {
    for (int i = 0; i < 5; i++) {
        std::cout << "hello" << std::endl;
    }
    return 0;
}
```

三个认脸：

1. `for (int i = 0; i < 5; i++)` 三段式：起点/条件/步长
2. C++ `i++` = i = i + 1
3. Python `for i in range(5):` 更简洁
