## 一、列表的日常四件事（2 分钟）

列表创建之后，99% 的时间在做四件事——**增删改查**：

- **增**：往里加（今天的主角 append / insert）
- **删**：拿出来（明天讲）
- **改**：换掉（明天讲）
- **查**：找一找（后天讲）

这是所有数据结构的通用口诀，先混个脸熟。

## 二、append：排队加尾巴（4 分钟）

```python
pets = ["cat", "dog"]
print("Start:", pets)

pets.append("rabbit")
print("After append:", pets)

pets.append("hamster")
print("After append 2:", pets)
```

运行：

```text
Start: ['cat', 'dog']
After append: ['cat', 'dog', 'rabbit']
After append 2: ['cat', 'dog', 'rabbit', 'hamster']
```

**append(x) 把 x 加到末尾**——像排队，新来的站最后。

## 三、insert：插队（3 分钟）

```python
pets.insert(1, "fish")
print("After insert at 1:", pets)
# ['cat', 'fish', 'dog', 'rabbit', 'hamster']
```

**insert(i, x) 把 x 插到第 i 个位置**，原来的元素往后挤一位——fish 插队站到 1 号位，dog 它们全体后移。

记忆：**append 排尾巴，insert 会插队**。

**注意：** `append()` 括号里必须传东西，忘了传会加进去一个空空如也的 None——列表看着没事，其实埋雷。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
#include <vector>
int main() {
    std::vector<int> nums = {1, 2, 3};
    nums.push_back(4);    // 增
    nums.erase(nums.begin() + 1);  // 删
    nums[0] = 99;         // 改
    return 0;
}
```

三个认脸：

1. `push_back` 增（Python `append`）
2. `erase(begin+1)` 删索引 1
3. `nums[0] = 99` 改（跟 Python list 一致）
