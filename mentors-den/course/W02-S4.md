## 一、索引：取单颗珠子（4 分钟）

```python
name = "ThawPaw"

name[0]    # "T" —— 0 号珠子（第一颗！）
name[1]    # "h"
name[6]    # "w" —— 最后一颗
```

**负数索引 = 从右往倒数**：

```python
name[-1]   # "w" —— 最后一颗
name[-2]   # "a" —— 倒数第二
```

`[-1]` 取最后一个，超常用，记住它。

## 二、切片：剪一段珠子（6 分钟）

```python
name = "ThawPaw"

name[0:4]    # "Thaw" —— 取 0 到 3 号（4 号不算！）
name[4:]     # "Paw"  —— 从 4 号取到结尾
name[:3]     # "Tha"  —— 从头取到 2 号
name[-3:]    # "Paw"  —— 最后三颗
```

**规则一句话：** `起点:终点`，**含头不含尾**（终点那颗不算）。这个规则全世界程序员都背过——今天你也是了。

**为什么编号从 0 开始？** 因为 `name[0:4]` 的长度正好是 4-0=4 颗。从 0 开始，减法就是长度——这是设计者的私心 😼

## 三、in：一秒侦探（3 分钟）

```python
"cat" in "concatenate"     # True  —— 找得到
"cat" in "dog park"        # False —— 找不到
"PAW" in "ThawPaw"         # False —— 大小写敏感！侦探很严格
```

返回 True / False（布尔值，W03 的主角之一，先混个脸熟）。
