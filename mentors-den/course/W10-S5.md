## 一、use_item：return 交出「成没成功」（4 分钟）

W07 的道具系统升级版——函数用 return 告诉调用方结果：

```python
def use_item(player, item_name):
    if item_name not in player["inventory"]:
        print(f"You don't have {item_name}")
        return False
    player["inventory"].remove(item_name)
    print(f"Used {item_name}!")
    return True

if use_item(player, "herb"):
    print("Healing done!")
else:
    print("No herb left")
```

调用方拿到 True/False，就能接着写 if——**函数之间用 return 递话**，主循环只管提问和分支，逻辑全住进函数里。

## 二、提前退出：return 是传送门（3 分钟）

```python
def divide(a, b):
    if b == 0:
        print("Cannot divide by zero")
        return None
    return a / b
```

`return None` 一执行，函数**立刻结束**，后面一行都不跑——像传送门，碰到就回城。这就是「提前退出」：先处理异常（除零），正常逻辑再往下写，主路径不缩进、读着清爽。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
// 改造前：3 处重复代码
// 改造后：抽成函数
void print_score(int s) {
    std::cout << "score = " << s << std::endl;
}
int main() {
    print_score(85);
    print_score(92);
    return 0;
}
```

三个认脸：

1. 抽函数消除重复
2. `print_score` 复用于两个分数
3. Python 一样：def print_score(s): print(s)
