## 二、第一版：能一直猜（5 分钟）

```python
import random

print("=== Number Guess ===")
secret = random.randint(1, 100)
guess = 0

while guess != secret:
    guess = int(input("Your guess (1-100): "))
    if guess > secret:
        print("Too high!")
    elif guess < secret:
        print("Too low!")
    else:
        print(f"Correct! The answer was {secret}")
```

跑一局体会：猜错会继续问，猜中才停。

## 三、逐行拆解（3 分钟）

| 部件 | 作用 |
|---|---|
| `import random` | 借随机数工具（W03 周末老朋友） |
| `random.randint(1, 100)` | 电脑偷偷想一个 1-100 的数 |
| `guess = 0` | 起手值：先给个猜不中的数，保证进得了循环 |
| `while guess != secret:` | 灵魂条件：没猜对就继续 |
| if / elif / else | 三分支：大了 / 小了 / 中了 |

W03 写一次就完，W05 写一次就一直问——**while 是灵魂**。

secret = random.randint(1, 100)   # NameError: name 'random' is not defined

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
int main() {
    int target = 7;
    for (int guess = 1; guess <= 10; guess++) {
        if (guess == target) {
            std::cout << "found!" << std::endl;
            break;
        }
    }
    return 0;
}
```

三个认脸：

1. 循环里套 if 判断
2. 找到目标就 break
3. Python 一样：`for guess in range(1, 11): if guess == target: print("found!"); break`
