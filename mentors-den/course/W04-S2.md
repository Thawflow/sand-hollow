## 一、三种姿势一次看全（6 分钟）

```python
# 姿势一：range(5) → 0,1,2,3,4（从 0 开始，到 N-1 收）
for i in range(5):
    print(i)

# 姿势二：range(2, 7) → 2,3,4,5,6（从 2 开始，到 7 之前收）
for i in range(2, 7):
    print(i)

# 姿势三：range(0, 10, 2) → 0,2,4,6,8（步长 2，跳着走）
for i in range(0, 10, 2):
    print(i)
```

想偷看 range 里装了什么？用 `list()` 照一照：

```python
print(list(range(1, 6)))     # [1, 2, 3, 4, 5]
print(list(range(0, 20, 5))) # [0, 5, 10, 15]
```

## 二、含头不含尾：range 唯一铁律（3 分钟）

- `range(5)` 给 0-4，**不含 5**
- `range(2, 7)` 给 2-6，**不含 7**

**记忆口诀：含头不含尾，永远差一个。**

想数 1 到 10？`range(1, 11)`——尾巴多写一个，就是诀窍。

## 三、循环做点有用的（2 分钟）

9 的乘法表前 9 项，三行搞定：

```python
for n in range(1, 10):
    print(f"9 x {n} = {9 * n}")
```

f-string（W02 的老朋友）+ for（本周新朋友）= 自动化第一步。循环体里还能放 if——下一题作业你会用到。

## 四、步长为负：倒着走（2 分钟）

步长还能写**负数**——range 不光往前走，也能往回走。

```python
for n in range(5, 0, -1):
    print(n)        # 5,4,3,2,1
```

**诀窍：** 步长是 -1 时，range 从第一个参数**往下数**到第二个参数之前。第三个 -1 决定方向，正数往上、负数往下。想从 10 倒到 1？`range(10, 0, -1)`——含头不含尾的规矩没变，只是倒着数。

**今日口诀：** 一个 N 数到 N-1，两个数含头不含尾，三个数跳着走，步长为负是倒档。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
int main() {
    for (int i = 1; i <= 10; i++) {
        std::cout << i << std::endl;
    }
    return 0;
}
```

三个认脸：

1. C++ 是 `i <= 10`（含头含尾）
2. Python `range(1, 11)` 是 `i < 11`（含头不含尾）
3. C++ 没有 range，得手写三段式
