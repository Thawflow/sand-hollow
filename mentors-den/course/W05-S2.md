## 一、死循环解剖（4 分钟）

昨天的死循环再看一眼：

```python
n = 1
while n <= 5:
    print(n)
    # 忘了写 n += 1
```

程序疯狂打印 1 停不下来。急救键：**Ctrl + C**（Mac 也是它）强制停止。

病根只有一个：**循环里没有任何动作让条件走向失败**。条件永远真，循环永远转——就像猫追自己尾巴，永远差一口。

## 二、避免死循环三件套（3 分钟）

写 while 前自查三件事：

1. **起手值有**：循环变量先给起手（`n = 1`）
2. **条件会变**：循环体里有让条件慢慢变假的步骤（`n += 1`）
3. **测试有上限**：写完先跑 5 秒，看会不会自己停

三件套缺一件，程序就可能变成永动机。

## 三、另外两个坑（2 分钟）

**坑①：条件一开始就是假。** `n = 5` 却写 `while n < 0:` → 一次都不跑。这不是 bug——while 跑 0 次也合法，别慌。

**坑②：`=` 与 `==` 老朋友。**

```text
while guess = password:   # ❌ SyntaxError！
```

比较永远用两个等号 `==`——W03 踩过一次，这里再踩一次更牢。

## 四、while 干正事：密码门卫（2 分钟）

```python
password = "tiger"
guess = input("Password: ")
while guess != password:
    print("Wrong, try again")
    guess = input("Password: ")
print("Welcome!")
```

看懂了吗？`guess` 在循环里被重新赋值——这就是「条件更新」的活样例：错就一直问，对了条件变假，Welcome 登场。

**今日口诀：** 起手值、条件、更新，三件套防死循环；Ctrl + C 是最后的急停闸。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
int main() {
    int i = 0;
    while (i < 10) {
        std::cout << "stuck" << std::endl;
        // 忘记 i++ → 死循环！
    }
    return 0;
}
```

三个认脸：

1. 注释 `// 忘记 i++` 提醒死循环
2. 生产中用 `Ctrl+C` 强制中断
3. Python 一样忘改 i 会卡住

> AI 营笔试的编程题用 C++ 出。不用会写，**认得脸**就行。
