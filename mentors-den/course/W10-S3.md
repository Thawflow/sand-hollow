## 一、给凹槽预设一个值（3 分钟）

参数可以带**默认值**——调用时不传，就自动用默认：

```python
def greet(name, greeting="Hello"):
    print(f"{greeting}, {name}!")

greet("Alice")
greet("Alice", "Hi")
greet("Bob", greeting="Hey")
```

三次调用：第一次 greeting 用默认 Hello；第二次位置传 Hi；第三次按名传 Hey。**一个函数，三种口味**——常用值不用每次写。

## 二、咖啡机实战（4 分钟）

```python
def make_coffee(size="medium", sugar=0):
    print(f"Coffee: {size}, sugar: {sugar} spoons")

make_coffee()
make_coffee("large")
make_coffee(sugar=2)
make_coffee("small", sugar=1)
```

读懂四种点单方式：全默认 / 只传第一个 / 只传第二个（必须带名字）/ 混着传。**只改后面参数、跳过前面参数时，必须用名字**——`make_coffee(sugar=2)` 不能写成 `make_coffee(2)`（那会把 2 当成 size）。

## 三、默认值放最后（2 分钟）

规矩：**有默认值的参数必须排在没默认值的后面**。想想为什么——按位置传参时 Python 从左往右填槽，如果中间的槽有默认值，后面的必传参数就永远收不到值了。

```text
def greet(greeting="Hello", name):
```

SyntaxError。改成 `def greet(name, greeting="Hello")` 才合法。

## 四、实战：print_scores 升级（3 分钟）

W06 的统计代码 + 默认值 = 专业味十足的报表函数：

```python
def print_scores(scores, label="Scores", show_total=True):
    print(f"--- {label} ---")
    for s in scores:
        print(f"- {s}")
    if show_total:
        print(f"Total: {sum(scores)}, Avg: {sum(scores)/len(scores):.1f}")

print_scores([85, 92, 78])
print_scores([85, 92, 78], label="Math Test", show_total=False)
```

**今日口诀：** 不传用默认，传了就覆盖；默认排最后，跳着传要带名。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
void greet(std::string name = "World") {
    std::cout << "hi, " << name << std::endl;
}
int main() {
    greet();          // 不传，用默认
    greet("Alice");   // 传，覆盖默认
    return 0;
}
```

三个认脸：

1. C++ 默认参数 `std::string name = "World"`
2. 调用 `greet()` 不传 = 默认
3. Python `def greet(name="World"):` 一样
