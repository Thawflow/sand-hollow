## 一、概念：写代码前先画图（2 分钟）

W07 冒险岛你干过一件事：**先画房间地图，再写代码**——结果三房间一次跑通。毕业项目同理：**先画设计图，再动键盘**。

W07 地图画的是房间和连线；今天设计图画四样：**功能、数据、函数、界面**。设计图不用漂亮，纸上或注释里歪歪扭扭都行——想清楚最重要。

## 二、四格设计图（5 分钟）

以「宠物图鉴 v2」为例，一张设计图长这样（作业里换成你自己的项目）：

```text
# === 我的设计图 ===
# 功能：1.看全家福  2.加宠物  3.查详情  4.退出
# 数据：codex 字典（宠物名 -> {species, stats, skills}）
# 函数：list_all(codex) / add_pet(codex) / show_pet(codex)
# 界面：菜单循环，输入数字选功能
```

逐格拆解：

| 格子 | 回答的问题 | 老朋友 |
|---|---|---|
| 功能 | 玩家能做哪几件事？ | 就是昨天的功能清单 |
| 数据 | 用什么变量装？ | 字典/列表/嵌套（W10） |
| 函数 | 每件事对应哪个函数？ | def + 参数 + return（W08） |
| 界面 | 玩家怎么选？ | 菜单 + input + while（W04/W05） |

## 三、函数小传单（3 分钟）

每个函数写一行「小传单」，S3 动工时照单开工：

```python
def list_all(codex):
    """打印所有宠物的一行摘要"""
```

```python
def add_pet(codex):
    """问名字和属性，安检后加进 codex"""
```

```python
def show_pet(codex):
    """问名字，打印该宠物全部档案"""
```

三引号字符串叫 **docstring**——函数说明书，写在 def 第一行。现在只需写名字 + 一句说明，**身体 S3 再填**。

## 四、界面先画草稿（2 分钟）

菜单循环的骨架（W11-weekend 见过同款）：

```python
while True:
    print("1. List all   2. Add pet   3. Show pet   4. Quit")
    choice = input("> ").strip()
    if choice == "1":
        list_all(codex)
    elif choice == "4":
        break
```

设计图上画到这一步就够——每个数字接哪个函数，一眼看清。

**今日口诀：** 功能定范围、数据定地基、函数定分工、界面定通道。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

```cpp
#include <iostream>
// 设计图：需要什么模块？
// 1. 数据模块
// 2. 逻辑模块
// 3. 界面模块
int main() { return 0; }
```

三个认脸：

1. 注释 = 设计图
2. 3 个模块拆开
3. Python 一样：注释说明模块
