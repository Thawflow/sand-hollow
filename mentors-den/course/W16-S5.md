## 一、程序一关，数据就没了？（3 分钟）

你的游戏、图鉴、对战记录——全住在内存里。程序一关，内存清空，一切归零。让数据活过关机的办法：**写进文件**。

```python
scores = {"paw": 3, "win": 2}
file = open("save.txt", "w", encoding="utf-8")
file.write(str(scores))
file.close()
print("Saved!")
```

三步曲：`open`（开文件，`"w"` = 写模式）→ `write`（写入）→ `close`（关门）。**忘了 close，数据可能还悬在半路**——养成三步连写的肌肉记忆。

## 二、读回来：load（4 分钟）

```python
file = open("save.txt", "r", encoding="utf-8")
text = file.read()
file.close()
print(text)
```

`"r"` = 读模式。读回来的永远是**字符串**——`'{"paw": 3}'` 长得像字典，其实是文本。要用 eval？新手期先不碰，直接把它当「存档展示」用就够了：游戏开场 `print` 出上次的战绩，仪式感拉满。

## 三、存什么、何时存（3 分钟）

设计你的存档点：

- **存什么**：玩家名、最高分、图鉴收集进度——「值得跨局记住的」
- **何时存**：一局结束、打败 Boss、退出前——「自然的停靠点」
- **格式**：一行一个 `名字:值`，或整个字典 str 存——新手期怎么简单怎么来

**今日口诀：** open、write、close 三连；读回是文本，别当字典用。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
#include <fstream>
int main() {
    std::ofstream f("save.txt");
    f << "saved!" << std::endl;
    return 0;
}
```

三个认脸：

1. `std::ofstream` 写文件
2. `f << "saved!"` 写
3. Python `f = open("save.txt", "w"); f.write("saved!")`
