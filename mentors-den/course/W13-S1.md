## 一、列表的痛点（3 分钟）

W06 的列表用**编号**找东西：`prey[0]`、`prey[2]`。编号好使，但有痛点——

记住「猫武士档案里第 3 项是皮毛颜色」太难了。人类的记法是**用名字**：「皮毛颜色是什么？」「`cat["color"]`」。

**字典（dict）= 名字 → 东西 的映射表**，像查电话簿：翻到名字，直接拿到号码。W07 冒险岛你其实偷偷用过它存玩家状态，今天正式拜师。

## 二、字典的长相（4 分钟）

```python
cat = {
    "name": "Whiskers",
    "age": 3,
    "color": "tabby",
    "is_indoor": True,
}

print(cat["name"])        # Whiskers
print(cat["age"])         # 3
print(cat["color"])       # tabby
```

逐字拆解：

| 部件 | 作用 |
|---|---|
| `{ }` | 花括号包住整个字典（列表是方括号 `[ ]`） |
| `"name": "Whiskers"` | 一对**键值对**：名字 → 东西 |
| 键（key） | 「名字」，通常是字符串，要加引号 |
| 值（value） | 「东西」——字符串、数字、布尔，啥都行 |
| `cat["name"]` | 用键取值：报名字，拿东西 |

逗号隔开每一对，最后一对后面的逗号可写可不写（写了更方便以后加行）。

## 三、和列表长得像，规矩不同（2 分钟）

`cat["name"]` 和 `prey[0]` 都是方括号取东西——**但方括号里装的不一样**：

- 列表：装**位置编号**（整数，从 0 开始）
- 字典：装**键**（名字字符串）

所以 `cat[0]` 会报错：`KeyError: 0`——字典里没有叫 `0` 的键。KeyError 是字典世界的常客，意思是「查无此名」。

## 四、什么时候用字典（1 分钟）

| 场景 | 用谁 |
|---|---|
| 一周温度排排坐 | 列表（位置有意义） |
| 猫档案：名字 / 年龄 / 毛色 | 字典（名字有意义） |
| 通讯录：人名 → 电话 | 字典（按名查号） |

**判断口诀：位置重要用列表，名字重要用字典。**

**今日口诀：** 花括号、冒号配对、键找值——电话簿思维。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
#include <map>
int main() {
    std::map<std::string, int> config;
    config["lr"] = 1;
    config["batch"] = 32;
    std::cout << config["lr"] << std::endl;
    return 0;
}
```

三个认脸：

1. `std::map<string, int>` KV 字典
2. `config["lr"]` 用 key 找 value
3. Python `config = {"lr": 1, "batch": 32}`
