## 一、画笔个性化三件套（3 分钟）

默认的画是黑线白底。三件套让它变身：

| 命令 | 作用 | 例子 |
|---|---|---|
| `t.pencolor("red")` | 线条颜色 | 颜色名是字符串，要加引号 |
| `t.pensize(3)` | 线条粗细（像素） | 数字越大线越粗 |
| `t.speed(0)` | 速度（S2 见过） | 1 最慢 → 10 快 → 0 瞬移 |

颜色名常用的有：`"red"` `"orange"` `"yellow"` `"green"` `"blue"` `"purple"` `"pink"` `"black"` `"white"`。拼错了会报 `bad color sequence`——颜色名也是字符串，种族规矩不变（W02）。

## 二、填充：begin 和 end 夹三明治（4 分钟）

给形状「涂色」靠一对搭档：

```python
import turtle

t = turtle.Turtle()
t.speed(0)
t.pensize(3)

t.fillcolor("yellow")
t.begin_fill()
for i in range(4):
    t.forward(100)
    t.left(90)
t.end_fill()

turtle.done()
```

运行：一个**实心黄正方形**。

套路像夹三明治：

1. `t.fillcolor("yellow")`——先选好果酱
2. `t.begin_fill()`——掀开面包
3. 中间画形状（循环照旧）
4. `t.end_fill()`——盖上另一片面包，果酱自动涂满

**规矩：** begin 和 end **必须配对**。只有 begin 没有 end → 不涂；画了两个形状才 end → 涂成一大坨。

## 三、抬笔挪窝：penup / pendown（2 分钟）

想在别处再画一个，可不想连一条「飞行线」过去：

```python
t.penup()          # 抬笔：接下来移动不留痕
t.goto(-50, 0)     # 直接飞到坐标 (-50, 0)
t.pendown()        # 落笔：恢复画画
```

`t.goto(x, y)` 是瞬移到坐标点。**落着笔 goto = 画一条直线过去**，多半不是你要的。

## 四、彩虹五角星预告（2 分钟）

颜色还能从**列表**里轮流取（W06 老朋友）：

```python
colors = ["red", "orange", "yellow", "green", "blue"]
for i in range(5):
    t.pencolor(colors[i])
    t.forward(120)
    t.left(144)
```

每画一条边换一种颜色——五条边五种颜色。角度 144° 的秘密下节课拆。

**今日口诀：** pencolor 换色、pensize 加粗、begin/end 夹心填色、penup 挪窝不留痕。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
// 上色：模拟
void setColor(std::string c) { std::cout << "color=" << c << std::endl; }
void setWidth(int w)        { std::cout << "width=" << w << std::endl; }
int main() {
    setColor("red");
    setWidth(3);
    return 0;
}
```

三个认脸：

1. `setColor("red")` 改颜色
2. `setWidth(3)` 改粗细
3. Python turtle 一样：t.color("red")
