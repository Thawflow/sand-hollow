## 一、概念：从学到做（5 分钟）

12 周学了 Python 全套基础。今天开始**毕业项目**——自选主题，做一个**完整作品**。

毕业项目标准（来自 SYLLABUS）：

- 100+ 行自己写的代码
- 能讲清每一部分做什么
- 报错自己修

**今天只做两件事：选题 + 画设计图。代码明天写。**

## 二、选题（10 分钟）

四类可选（或自己提案）：

### A. 游戏类

- 文字冒险（基于 W07 扩展）
- 回合制 RPG（基于 W11 扩展）
- 答题游戏（多学科题库 + 计分）
- 贪吃蛇（用 turtle）

### B. 工具类

- 个人记账本（收支记录 + 月度报表）
- 待办清单（基于 W06 扩展 + 文件保存）
- 通讯录（基于 W10 扩展 + 搜索）
- 学习计划生成器

### C. 创作类

- turtle 画集（一组函数画多个图案）
- 故事生成器（输入关键词 → 随机拼一段故事）
- ASCII 艺术生成器
- 音乐生成器（用 turtle 画乐谱）

### D. 数据类

- 班级成绩分析器（输入成绩 → 统计图）
- 天气预报模拟（随机生成数据 + 图表）
- 简易搜索引擎（输入关键词 → 匹配标题）

**选一个你真的想做的。** 别选「最酷」的，选「你最想写完」的。

## 三、设计图（15 分钟）

打开草稿纸，画出作品的结构：

### 必须包含

1. **功能清单**：3-5 个核心功能（每个功能 1-2 句描述）
2. **数据结构**：用什么字典 / 列表存数据
3. **函数清单**：拆成几个函数（每个函数做什么）
4. **菜单/界面**：用户怎么用（菜单？命令？参数？）

### Example: Class Grade Analyzer

Features:
1. Input N student records (name + score)
2. Show average, highest, lowest
3. Show pass rate (>= 60)
4. Show distribution (0-59, 60-79, 80-100)

Data structures:
- students = [{"name": ..., "score": ...}, ...]
- brackets = {"0-59": 0, "60-79": 0, "80-100": 0}

Functions:
- add_student() - add one student
- show_stats() - show statistics
- show_distribution() - show distribution
- main() - main menu

Interface (pseudo-ASCII example):

```
=== Grade Analyzer ===
1. Add student
2. Show stats
3. Show distribution
4. Quit
```
