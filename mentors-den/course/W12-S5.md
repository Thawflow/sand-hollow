## 一、选型决策树（3 分钟）

```
need to store batch data?
|-- frequent random access (arr[i])? -> array (list)
|-- frequent head insert/delete? -> double-ended queue (deque)
|-- frequent middle insert/delete? -> doubly linked list (deque)
|-- key-value pair? -> dict
|-- no duplicates? -> set
|-- immutable seq? -> tuple
|-- heavy numeric? -> numpy array
```

## 二、Python 代码（5 分钟）

```python
def pick_data_structure(operation, n):
    '''Pick best data structure based on operation.'''
    if operation == 'random_access':
        if n < 1000:
            return 'list (O(1) access)'
        return 'list (still O(1), cache friendly)'
    elif operation == 'head_insert':
        if n < 100:
            return 'list (small N)'
        return 'deque (O(1) head insert)'
    elif operation == 'search_by_key':
        return 'dict (O(1) lookup)'
    elif operation == 'unique':
        return 'set (O(1) membership)'
    elif operation == 'immutable':
        return 'tuple (immutable, hashable)'
    elif operation == 'numeric':
        return 'numpy array (vectorized)'
    else:
        return 'list (default)'

# Test
ops = ['random_access', 'head_insert', 'search_by_key',
       'unique', 'immutable', 'numeric']
for op in ops:
    print(f'{op:20s} -> {pick_data_structure(op, 10000)}')
```

## 四、深入了解：选型 3 步法（3 分钟）

```
1. list main operations (by frequency)
2. check complexity of each structure
3. pick the best match
```

**AI 工程师原则**：**先看操作频次，不是先看数据**。

## 五、何时用：选型升级路径（3 分钟）

```
needs -> simple (list/dict) -> bottleneck -> advanced
                                       |-- deque (head insert)
                                       |-- set (unique)
                                       |-- numpy (numeric)
                                       |-- pandas (data science)
```

**99% 用 list/dict**——升级是后期优化。
