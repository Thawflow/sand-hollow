## 一、累加器复习：求和 + 平均（3 分钟）

W04 学的累加器，套上列表就是日常 80% 的数据处理：

```python
scores = [85, 92, 78, 95, 88]
total = 0
for s in scores:
    total += s
print(f"Total: {total}, Average: {total / len(scores):.1f}")
```

## 二、built-in 三兄弟：直接抄近道（4 分钟）

上面的循环是教学版——实战直接用 Python 自带的（不用 import）：

```python
nums = [12, 45, 7, 23, 56, 89, 34]
print(max(nums))
print(min(nums))
print(sum(nums))
```

89 / 7 / 266。**max 最大、min 最小、sum 求和**；平均没有自带，`sum(nums) / len(nums)` 一行拼出来。

**两个雷：** `sum` 只对数字列表——`sum(["1", "2"])` 直接 TypeError；空列表问 `max` 报 ValueError。

## 三、过滤两板斧：计数 + 存新列表（4 分钟）

**板斧一：数有几个达标的**（循环 + if + 计数器）：

```python
scores = [85, 92, 78, 95, 88, 90, 76, 91, 84, 89]
excellent = 0
for s in scores:
    if s >= 90:
        excellent += 1
print(f"Excellent: {excellent}")
```

**板斧二：把达标的捞进新列表**（循环 + if + append）：

```python
excellent = []
for s in scores:
    if s >= 90:
        excellent.append(s)
print(excellent)
```

进阶预告：`[s for s in scores if s >= 90]` 一行也能干这事（列表推导式），新手期先写循环版，周末项目再尝鲜。

**今日口诀：** max/min/sum 抄近道；过滤两板斧，计数或捞人。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
int main() {
    std::vector<int> nums = {3, 1, 4, 1, 5};
    int sum = 0, mx = nums[0];
    for (int x : nums) {
        sum += x;
        if (x > mx) mx = x;
    }
    std::cout << "sum=" << sum << " max=" << mx << std::endl;
    return 0;
}
```

三个认脸：

1. C++ 没有内置 sum/max，要手动累加
2. `#include <algorithm>` 有 `std::max_element`
3. Python `max(nums)` 一行解决
