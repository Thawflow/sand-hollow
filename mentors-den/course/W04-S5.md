## 一、概念：循环里再放循环（2 分钟）

- 一个月 30 天，每天 24 小时
- 乘法表：9 行，每行 9 个数
- 棋盘：8 行 8 列

「一层一层的事」用**嵌套循环**——循环里面再放循环。

## 二、第一招：3 排 5 列星星阵（5 分钟）

```python
for row in range(3):
    for col in range(5):
        print("*", end=" ")
    print()
```

输出：

```
* * * * *
* * * * *
* * * * *
```

### 嵌套三件套

| 部件 | 作用 |
|---|---|
| 外层 `for row in range(3)` | 管「行」：做 3 遍 |
| 内层 `for col in range(5)` | 管「列」：每行做 5 遍 |
| `print()`（不缩进在内层里） | 一行画完，换行 |

**执行总数 = 外层次数 × 内层次数 = 3 × 5 = 15 次。** 外层每走一步，内层走完一整轮。

### `end=" "` 是什么

print 默认每句结尾**换行**。`end=" "` 改成"以空格结尾"，星星才能横着排。记住：`end` 控制 print 句尾加什么。

## 三、第二招：直角楼梯（3 分钟）

```python
for row in range(1, 6):
    for col in range(row):
        print("*", end=" ")
    print()
```

```
*
* *
* * *
* * * *
* * * * *
```

**关键：内层 `range(row)`——每行的星星数 = 行号。** 这是嵌套循环最经典的形态：**外层管行号，内层管每行宽度**。

## 四、第三招：金字塔（3 分钟）

```python
height = 5
for row in range(1, height + 1):
    for space in range(height - row):
        print(" ", end="")
    for star in range(2 * row - 1):
        print("*", end="")
    print()
```

```
    *
   ***
  *****
 *******
*********
```

两个内层循环：先补空格（`height - row` 个），再打星星（`2 * row - 1` 个）。**第 N 行星数 = 2N - 1**——奇数序列，是数学规律不是死记。

**今日口诀：** 外层管行，内层管列；end 不换行，一行一 print()。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
int main() {
    for (int y = 0; y < 3; y++) {
        for (int x = 0; x < 3; x++) {
            std::cout << "(" << y << "," << x << ") ";
        }
        std::cout << std::endl;
    }
    return 0;
}
```

三个认脸：

1. 外层 `for y` 内层 `for x`（图像遍历）
2. 内层每轮跑完输出换行
3. Python 一样：`for y in range(3): for x in range(3):`
