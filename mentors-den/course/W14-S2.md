## 一、调用栈是什么（3 分钟）

```python
def a():
    print('a start')
    b()
    print('a end')

def b():
    print('b start')
    c()
    print('b end')

def c():
    print('c start')
    print('c end')

a()
# Output:
# a start
# b start
# c start
# c end
# b end
# a end
```

**调用顺序**：`a → b → c → (c 完) → b → (b 完) → a`

**栈变化**（可视化）：
```
Call c:  [a, b, c]   <- top
c done:  [a, b]
b done:  [a]
a done:  []
```

## 二、调用栈可视化函数（5 分钟）

```python
import sys

def visualize_call(func, *args):
    '''Run func and show call stack at each step.'''
    old_trace = sys.settrace(lambda *a, **k: None)  # disable default
    print(f'>>> Calling {func.__name__}{args}')
    result = func(*args)
    print(f'<<< Returned {result}')
    return result

# Test
def factorial(n, depth=0):
    indent = '  ' * depth
    print(f'{indent}factorial({n})')
    if n == 0:
        print(f'{indent}  -> base case, return 1')
        return 1
    result = n * factorial(n - 1, depth + 1)
    print(f'{indent}  -> return {result}')
    return result

factorial(3)
# factorial(3)
#   factorial(2)
#     factorial(1)
#       factorial(0)
#         -> base case, return 1
#       -> return 1
#     -> return 2
#   -> return 6
```

## 四、深入了解：栈帧（3 分钟）

每次函数调用 = 创建一个**栈帧（stack frame）**：
- 参数值
- 局部变量
- 返回地址

**栈空间有限**：Python 默认 1000 层。深度递归会爆栈。

```python
import sys
print(sys.getrecursionlimit())   # 1000
sys.setrecursionlimit(2000)      # raise limit (not recommended)
```

## 五、何时用：调用栈在 AI 框架（3 分钟）

**PyTorch** 每层 forward = 一次函数调用 = 一次栈帧。

```
forward(x)        # stack: [forward]
  layer1(x)       # stack: [forward, layer1]
    relu(...)      # stack: [forward, layer1, relu]
  layer2(x)       # pop: [forward, layer2]
backward()        # backprop (recursive backward call)
```

**栈追踪 = 调试 AI 模型**。`pdb.set_trace()` 配合栈。

## 七、答案

```python
import sys
# 3
sys.setrecursionlimit(1500)
def deep(n):
    if n == 0:
        return
    deep(n - 1)

try:
    deep(1500)
except RecursionError as e:
    print(f'RecursionError: {e}')
# RecursionError: maximum recursion depth exceeded
```
