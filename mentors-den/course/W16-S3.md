## 一、概念：先让空房子通电（2 分钟）

## 二、最小骨架长什么样（5 分钟）

以图鉴 v2 为例（换成你自己的项目，结构不变）：

```python
def list_all(codex):
    """打印所有宠物的一行摘要"""
    pass

def show_pet(codex):
    """打印指定宠物全部档案"""
    pass

codex = {}

print("=== Pet Codex v0.1 ===")
while True:
    print("1. List all   2. Quit")
    choice = input("> ").strip()
    if choice == "1":
        list_all(codex)
    elif choice == "2":
        print("Bye!")
        break
```

对账四件事：

- 函数们带着 docstring + `pass` 站好队（昨天小传单）
- **数据地基**：`codex = {}` 空字典先立住——数据结构定了，函数才有家
- while True 菜单：唯一出口是 break（W05 的规矩：活循环必须有门）
- **此刻运行**：程序能循环出菜单、选 2 退出——没有任何报错

## 三、搬第一块家具（3 分钟）

骨架通电后只做**一块**功能（挑最简单、最能在屏幕上看到效果的）——list_all：

```python
def list_all(codex):
    """打印所有宠物的一行摘要"""
    if not codex:
        print("(codex is empty)")
        return
    for name in codex:
        print(f"- {name}")
```

两个新细节：

- `if not codex:` ——空字典也能跑：第一次进游戏图鉴是空的，礼貌提示而不是冷场
- **return 提前退场**——W10-S5 的安检门思路，行不通就撤，不硬走

搬完立刻测：菜单选 1 → 看到 `(codex is empty)`；选 2 → 退出。**一块家具一块测试**，绝不连搬三块再一起测。
