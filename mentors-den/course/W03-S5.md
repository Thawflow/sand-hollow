## 一、概念：复杂世界需要组合条件（3 分钟）

单一条件不够用了：

- 当上战士：要「满 12 个月**且**训练完成」——缺一不可
- 周末：是「周六**或**周日」——满足其一
- 不饿：**not** 饿

三个连接词：**and（且）、or（或）、not（非）**。

## 二、and：两个都要真（3 分钟）

```python
if age >= 12 and trained == "yes":
    print("Warrior name granted!")
```

13 岁 + 训练完 → 授予；13 岁 + 没训完 → 安静；5 岁 + 训练完 → 安静。

**口算规则：and 左右都真，整体才真——一假全假。**

## 三、or：一个真就真（3 分钟）

```python
if day == "Saturday" or day == "Sunday":
    print("Family coding time!")
```

周六 ✅，周日 ✅，周一 ❌。

**口算规则：or 左右至少一个真，整体就真——全假才假。**

## 四、not 与小括号大法（2 分钟）

```python
hungry = True
print(not hungry)    # False —— 真假对调
```

新手期大法：**给组合条件套小括号**——`(age >= 12) and (trained == "yes")`，谁先谁后一目了然。

## 五、实战阅读：成绩等级评定器（4 分钟）

看懂这段就出师了（只读不敲）：

```python
score = int(input("Test score (0-100): "))
attend = int(input("Attendance (0-20): "))
```

## 六、一个必看的坑（1 分钟）

```text
if score > 60 or score < 90:   # ❌ 永远为真！
```

任何数都至少满足一头，这条件谁进来都过。**夹在中间要用 and**：`score > 60 and score < 90`。

**今日口诀：** and 全真才真，or 一真即真，not 真假对调。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
int main() {
    int age = 11;
    bool has_ticket = true;
    if (age >= 6 && has_ticket) {
        std::cout << "可以进" << std::endl;
    }
    return 0;
}
```

三个认脸：

1. `&&` 是 C++ 的 and（Python 是 `and`）
2. `||` 是 C++ 的 or（Python 是 `or`）
3. `!` 是 C++ 的 not（Python 是 `not`）

> AI 营笔试的编程题用 C++ 出。不用会写，**认得脸**就行。
