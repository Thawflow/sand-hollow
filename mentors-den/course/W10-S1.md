## 一、你早就在用函数了（3 分钟）

W07 的 `battle(player, wolf)`、每天的 `print(...)`、`input(...)`——全是**函数**：一段有名字的代码，可以反复调用。区别只是：print 是别人写好的，这周开始**写你自己的**。

为什么非要打包？三个理由：

- **不重复**：同一段代码不抄 10 遍
- **改一处**：函数改好，10 个调用点全部生效
- **读得懂**：`battle(player, wolf)` 一行，胜过 30 行战斗代码摊在眼前

## 二、def 的样子（4 分钟）

```python
def greet(name):
    print(f"Hello, {name}!")
    print("Welcome to Python.")

greet("Alice")
greet("Bob")
```

四件套拆解：

- `def`：定义（define）的缩写——「我要造积木了」
- `greet`：函数名，自己起，最好用动词
- `(name)`：**参数**，调用时传进来的数据（明天专门学）
- `:` + 缩进：冒号下面缩进 4 格的，都是函数体

## 三、定义 ≠ 执行（3 分钟）

最反直觉的一点：`def` 那一刻**什么都不执行**，只是把函数记进了 Python 的名册。真正执行的是**调用**——顶格写的 `greet("Alice")`：

```python
def say_hello():
    print("Hello!")

say_hello
say_hello()
```

`say_hello`（没括号）只是指着这块积木，不执行、不报错；`say_hello()`（带括号）才是「执行它」。**忘写括号 = 新手第一大坑**：程序安静跑完，一行 Hello 都没有。

**今日口诀：** def 造积木，调用才出发；括号不写，万物静默。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
void greet() {
    std::cout << "hello!" << std::endl;
}
int main() {
    greet();
    greet();
    return 0;
}
```

三个认脸：

1. `void greet()` 函数定义（C++ 用 `void`）
2. Python `def greet():` 更简洁
3. 调用两次 = 函数复用
