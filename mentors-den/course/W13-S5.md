## 一、图鉴的数据楼（3 分钟）

每只宠物一个字典，整个图鉴也是字典（键 = 宠物名）——昨天三层楼的直接应用：

```python
codex = {
    "Whiskers": {
        "species": "cat",
        "stats": {"hp": 50, "attack": 12},
        "skills": ["scratch", "purr"],
    },
    "Rex": {
        "species": "dog",
        "stats": {"hp": 80, "attack": 18},
        "skills": ["bite", "fetch"],
    },
}
```

结构：codex → 宠物 →（species / stats / skills）。数据库雏形就这么几行。

## 二、查询函数：show_pet（4 分钟）

```python
def show_pet(codex, name):
    if name not in codex:
        print(f"{name} not in codex")
        return
    pet = codex[name]
    print(f"=== {name} ({pet['species']}) ===")
    print(f"HP {pet['stats']['hp']} / ATK {pet['stats']['attack']}")
    print(f"Skills: {', '.join(pet['skills'])}")

show_pet(codex, "Whiskers")
```

看两个要点：

- **安检门**：`not in` 拦住查无此宠，查不到就 `return` 退场
- `', '.join(...)`：把技能列表粘成一句话（字符串功夫的亲戚）

## 三、加宠物：add_pet（3 分钟）

```python
def add_pet(codex, name, species, hp, attack):
    if name in codex:
        print(f"{name} already exists")
        return
    codex[name] = {"species": species,
                   "stats": {"hp": hp, "attack": attack},
                   "skills": []}

add_pet(codex, "Tweety", "bird", 30, 8)
```

**防覆盖检查**：名字已存在就直接退——不然 `codex[name] = {...}` 会把老档案**整个覆盖**（S2 的坑放大版：这次盖掉一整只宠物）。

## 四、全家福：list_all（3 分钟）

```python
def list_all(codex):
    print("=== Pet Codex ===")
    for name in codex:
        pet = codex[name]
        print(f"- {name} ({pet['species']}): HP {pet['stats']['hp']}")

list_all(codex)
```

list_all = S3 遍历 + S4 下钻的复习。add_skill 同理：先 `not in` 安检，再 `codex[name]["skills"].append(skill)`。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
#include <map>
#include <vector>
int main() {
    std::map<std::string, std::vector<std::string>> pets;
    pets["喵"] = {"爬树", "抓老鼠"};
    return 0;
}
```

三个认脸：

1. C++ 嵌套 map + vector
2. `pets["喵"] = {...}` 存技能列表
3. Python `pets = {"喵": ["爬树", "抓老鼠"]}`
