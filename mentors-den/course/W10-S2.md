## 一、凹槽：函数接住外面的数据（3 分钟）

调用时**塞值进去**，函数定义时**挖槽接住**——参数让一段代码变通用：

```python
def introduce(name, age, hobby):
    print(f"I'm {name}, {age} years old.")
    print(f"I like {hobby}.")

introduce("Alice", 12, "drawing")
introduce("Bob", 11, "coding")
```

同一个函数，两份数据，两种输出。塞进去的叫**实参**（实际的值），接住它们的凹槽叫**形参**（形式上的名字）——新手期记不住术语没关系，记住「塞值 → 凹槽」就行。

## 二、按位置对应：第一坑（3 分钟）

`introduce("Alice", 12, "drawing")` → name="Alice"、age=12、hobby="drawing"。**按位置一一对应**——所以顺序错了语义就错：

```text
introduce(12, "Alice", "drawing")
```

不报错！但输出变成「I'm 12, Alice years old」——程序很听话，错的是你。**参数错位是「安静的 bug」**，比报错难抓。

## 三、按名字传：关键字参数（3 分钟）

不想记顺序？用名字指定，顺序随意：

```python
introduce(hobby="coding", name="Bob", age=11)
```

混用规则只有一条：**没名字的（位置参数）必须在前**。

```text
introduce(name="Alice", 12, "drawing")
```

这行是 SyntaxError——关键字参数后面不能再跟裸的位置参数。

## 四、数量必须对上：第二坑（2 分钟）

函数挖两个槽，你塞三个值（或只塞一个）→ `TypeError: introduce() takes 3 positional arguments but 2 were given`。报错其实很友善：槽几个、给了几个，写得明明白白。**见到 TypeError 先数参数。**

**今日口诀：** 塞值进凹槽，位置一一咬；按名传也行，名字不能少。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
void greet(std::string name) {
    std::cout << "hi, " << name << std::endl;
}
int main() {
    greet("Alice");
    return 0;
}
```

三个认脸：

1. `std::string name` 参数声明类型
2. 调用 `greet("Alice")` 传实参
3. Python `def greet(name):` 不声明类型
