## 二、递归解迷宫（5 分钟）

```python
def solve_maze(maze, x, y, end_x, end_y, path=None):
    '''Recursive DFS. Returns path or None.'''
    if path is None:
        path = []

    # boundary check
    rows, cols = len(maze), len(maze[0])
    if not (0 <= x < rows and 0 <= y < cols):
        return None
    # hit wall or visited
    if maze[x][y] == 1 or (x, y) in path:
        return None
    # reach exit
    if x == end_x and y == end_y:
        return path + [(x, y)]

    # mark visited
    path.append((x, y))

    # try 4 directions: up, right, down, left
    for dx, dy in [(-1, 0), (0, 1), (1, 0), (0, -1)]:
        result = solve_maze(maze, x + dx, y + dy, end_x, end_y, path)
        if result:
            return result

    # backtrack on dead end
    path.pop()
    return None
```

## 四、深入了解：DFS vs BFS（3 分钟）

| 算法 | 找路径 | 找最短 |
|---|---|---|
| **DFS** (递归) | ✓ | ✗ 找到一条就行 |
| **BFS** (队列) | ✓ | ✓ 最短路径 |
| **A*** (启发式) | ✓ | ✓ 最优路径 |

**AI 工程师原则**：
- 简单解 → DFS（递归）
- 最短解 → BFS
- 大规模 + 启发式 → A*

## 五、何时用：递归在 AI 搜索（3 分钟）

| AI 场景 | 用递归？ |
|---|---|
| 迷宫 / 游戏 | ✓ DFS |
| 决策树（minimax）| ✓ alpha-beta 剪枝 |
| 图搜索 | ✓ DFS / BFS |
| 知识图谱查询 | ✓ BFS |
| 神经网络 forward | ✗ 用循环 |
| 训练优化（梯度下降）| ✗ 用循环 |

**99% 搜索算法是递归**。

def print_maze_with_path(maze, path):
    for i in range(len(maze)):
        row = ''
        for j in range(len(maze[0])):
            if (i, j) in path:
                row += '* '
            elif maze[i][j] == 1:
                row += '# '
            else:
                row += '. '
        print(row)

result = solve_maze(maze, 0, 0, 4, 4)
