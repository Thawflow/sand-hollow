## 一、光会走还不够：玩家得有「状态」（3 分钟）

前两节的猫武士只会走来走去，像幽灵。今天起她有了身体——**HP（生命值）、攻击、防御、道具栏**。这些数据合起来叫**玩家状态**，整个游戏都在读写它：战斗扣血、捡道具入库、喝草药回血，全是改这几个数。

存哪？一个**字典**：

```python
player = {
    "name": "Paw",
    "hp": 100,
    "max_hp": 100,
    "attack": 10,
    "defense": 5,
    "inventory": [],
}
print(f"{player['name']}: HP {player['hp']}/{player['max_hp']}")
```

## 二、字典：钥匙开锁式取数（4 分钟）

W06 学过列表 `[值, 值]`——按**位置**取。字典是 `{键: 值}`——按**名字**取：

- `player["hp"]` → 拿到 100
- `player["inventory"]` → 拿到空列表
- `player["mp"]` → 💥 `KeyError: 'mp'`——字典里没有这把钥匙！

**新手第一坑：** 键名打错不报「拼写错误」，报 KeyError。卡住时先 `print(player)` 看清楚到底有哪些键。

**新手第二坑：** 花括号 `{}` 是字典，方括号 `[]` 是列表。第一眼分清，别混。

## 三、道具栏：列表长在字典里（3 分钟）

`"inventory": []`——道具栏就是一个空列表，挂在字典里当值。捡到东西用 W06 的 `append`：

```python
player["inventory"].append("herb")
print(player["inventory"])
```

回头看 S1 画的地图：草药房、羽毛房……那些标注今天全部有了着落——**地图上的道具 = inventory 里将来会多出来的一项**。

## 四、状态显示在游戏里（2 分钟）

把状态打印接进 S2 骨架，每圈循环开头亮一次血条：

```python
while room != "quit":
    print(f"\n[{player['name']}] HP: {player['hp']}/{player['max_hp']}")
    if room == "shrine":
        print("--- Cat Shrine ---")
```

玩家随时知道自己几条命，游戏立刻有「活」的感觉。

**今日口诀：** 状态进字典，取数用钥匙；道具是列表，append 一键塞。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
#include <map>
int main() {
    std::map<std::string, int> state;
    state["hp"] = 100;
    state["mp"] = 50;
    std::cout << "HP = " << state["hp"] << std::endl;
    return 0;
}
```

三个认脸：

1. `std::map<string, int>` 类似 Python dict
2. `state["hp"]` 取值
3. C++ 没有 dict 字面量，要逐个 insert
