## 一、概念：让程序「画」出来（3 分钟）

前八周的程序全是文字输出：print 一行行往上滚。从今天起，程序能**画**了——

**turtle**（海龟画图）是 Python 自带的画画工具：想象屏幕上有一只小海龟，肚皮底下绑着一支笔。你喊口令，它就爬；爬过的地方，留下线条。

玩过 Scratch 画笔的同学：一模一样的思想，只是口令换成了英文单词。

## 二、第一段海龟代码（4 分钟）

今天只看不敲，记住三句口令的样子：

```python
import turtle

t = turtle.Turtle()
t.forward(100)   # 前进 100 像素，画出一条线
t.left(90)       # 左转 90 度
t.forward(100)   # 再前进，画出新方向的线
```

逐行拆解：

| 部件 | 作用 |
|---|---|
| `import turtle` | 领出画画工具箱（Python 自带，不用安装） |
| `t = turtle.Turtle()` | 创建一只海龟，给它起名叫 `t`（变量名随你） |
| `t.forward(100)` | 前进 100 像素（像素 = 屏幕上的小格子） |
| `t.left(90)` | 原地左转 90 度（不移动，只转向） |

海龟刚出生时站在屏幕正中央，头朝**右**（东边）。

## 三、角度是方向的语言（2 分钟）

转弯的单位是**度**，和数学课的量角器同一套：

- `t.left(90)` → 左转一个直角
- `t.right(45)` → 右转半 个直角
- `t.left(180)` → 掉头，原地反向

**关键：** 角度是「相对」的——海龟不管自己脸朝哪，`left(90)` 永远是「往自己左手边转 90 度」。转完后的方向 = 原方向 + 转的角度。

## 四、预告：正方形只差一把火（1 分钟）

前进 → 左转 90 → 前进 → 左转 90……重复 4 次就是正方形。你心里应该已经冒出老朋友了——**for 循环**（W04）。明天就让它和海龟合体。

**今日口诀：** forward 爬、left/right 转、角度跟着感觉走。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
// C++ 没有 turtle，用 cout 模拟
void forward(int d) { std::cout << "go " << d << std::endl; }
void right(int deg) { std::cout << "turn " << deg << std::endl; }
int main() {
    forward(100); right(90);
    return 0;
}
```

三个认脸：

1. `forward(100)` 前进（Python `t.forward(100)`）
2. `right(90)` 右转
3. C++ 没图形库，AI 训练用专门的 graphics lib
