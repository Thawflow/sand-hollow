## 一、场景：猫武士巡逻（3 分钟）

部落有 N 个巡逻点，每个点：
- 距离（km）
- 价值（食物/水源/安全）
- 时间窗（h-h）

目标：**8 小时内选最高总价值的巡逻**。

## 二、3 种贪心策略（5 分钟）

```python
def patrol_greedy_value(patrols):
    '''Strategy 1: pick highest value first.'''
    sorted_p = sorted(patrols, key=lambda p: -p['value'])
    return pick_within_time(sorted_p, 8)

def patrol_greedy_efficiency(patrols):
    '''Strategy 2: pick highest value/time ratio.'''
    sorted_p = sorted(patrols, key=lambda p: -(p['value'] / p['time']))
    return pick_within_time(sorted_p, 8)

def patrol_greedy_shortest(patrols):
    '''Strategy 3: pick shortest time first.'''
    sorted_p = sorted(patrols, key=lambda p: p['time'])
    return pick_within_time(sorted_p, 8)

def pick_within_time(sorted_patrols, max_time):
    '''Pick patrols in order while time permits.'''
    selected = []
    total_time = 0
    for p in sorted_patrols:
        if total_time + p['time'] <= max_time:
            selected.append(p)
            total_time += p['time']
    return selected
```

## 三、示例演算：6 个巡逻点（3 分钟）

| 巡逻 | 距离 | 时间 | 价值 |
|---|---|---|---|
| A | 5 km | 2h | 10 |
| B | 8 km | 3h | 15 |
| C | 3 km | 1h | 5 |
| D | 6 km | 2h | 12 |
| E | 4 km | 2h | 8 |
| F | 10 km | 4h | 20 |

**价值优先**：A(10) + B(15) + D(12) + E(8) = 45 (8h) ← 但 D 时间冲突
**效率优先**：B(5/h) + C(5/h) + D(6/h) + A(5/h) = 42 (8h)
**最短优先**：C(1) + A(2) + D(2) + E(2) + B(3) = 45 (10h 超时) → C + A + D + E = 35 (7h)

**效率优先胜出**：用更少时间得更高价值。

## 四、深入了解：3 种策略的取舍（3 分钟）

| 策略 | 优点 | 缺点 |
|---|---|---|
| 价值优先 | 简单 | 不考虑时间，可能超 |
| 效率优先 | 时间利用率高 | 错过大单 |
| 最短优先 | 快速集齐 | 可能选低价值 |

**实战**：**效率优先**最常用（折中）。

## 七、答案

```python
import random

# Random patrols
patrols = [
    {'name': chr(65+i), 'time': random.randint(1, 4),
     'value': random.randint(5, 25)}
    for i in range(10)
]

print('Strategy comparison:')
for name, fn in [('value-first', patrol_greedy_value),
                 ('efficiency-first', patrol_greedy_efficiency),
                 ('shortest-first', patrol_greedy_shortest)]:
    selected = fn(patrols)
    total_value = sum(p['value'] for p in selected)
    total_time = sum(p['time'] for p in selected)
    print(f'  {name}: total value={total_value}, total time={total_time}h, count={len(selected)}')
```
