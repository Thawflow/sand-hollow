## 三、家族展示会（15 分钟）

### 准备

- **5 分钟讲**：这是什么 / 怎么用 / 我做了什么
- **5 分钟演示**：跑一遍
- **5 分钟回答问题**

### 邀请谁

- 至少 2 个家人（爸妈 / 兄弟姐妹 / 朋友）
- 不需要懂编程，能用就行

### 怎么讲

**不要**：「我做了一个 Python 程序...」（太抽象）

**要讲**：

- 「我做的是 XX 工具」（具体是什么）
- 「用它可以 XX」（解决了什么问题）
- 「比如...」（具体例子）
- 「我学到了...」（自己的成长）

### 演示流程

1. 启动程序
2. 演示核心功能
3. 故意触发一个边界 case（如输入错），展示程序怎么应对
4. 展示保存 / 加载

### 收集反馈

让家人用一遍，记下他们：

- 卡在哪里
- 哪里不清楚
- 哪里喜欢

## 四、⚠️ 新手三大坑（5 分钟）

1. **光讲代码不讲功能**：家人听不懂代码。**讲做了什么 / 解决什么问题**
2. **演示时手忙脚乱**：提前 Run 一遍熟悉流程，**别第一次跑就当演示**
3. **不收反馈就结束**：演完就走了 = 错过改进机会。**主动问「哪里不好用？」**
