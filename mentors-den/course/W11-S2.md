## 一、四条边 = 四次重复（2 分钟）

正方形有什么特点？**四条一样长的边、四个 90 度的角。**

「一样的活儿干 4 次」——这不就是 for 循环吗（W04 老朋友）。海龟画图和循环天生一对。

## 二、第一个正方形（4 分钟）

```python
import turtle

t = turtle.Turtle()
t.speed(0)

for i in range(4):
    t.forward(100)
    t.left(90)

turtle.done()
```

运行：海龟「上、左、下、右」爬一圈，闭合出一个正方形。

逐行拆解：

| 部件 | 作用 |
|---|---|
| `t.speed(0)` | 最快档（1 最慢，10 很快，0 瞬移）——画几何图不用等动画 |
| `for i in range(4):` | 重复 4 次 = 4 条边 |
| `t.forward(100)` | 画一条边（长 100 像素） |
| `t.left(90)` | 转过直角，准备画下一条边 |
| `turtle.done()` | 「画完了别关窗」——不写的话窗口闪一下就没了 |

**关键观察：** 画完第 4 条边，海龟**回到起点、朝回原方向**——4 × 90 = 360，转了一整圈。这不是巧合，是明天的密码。

## 三、边和角怎么数（2 分钟）

- 每次循环 = 一条边 + 一个转角
- 4 边形循环 4 次，每次转 90：`4 × 90 = 360`
- 想画三角形？3 条边……每次该转多少度？先自己口算一下，明天公布答案

## 四、常见坑：忘 done、忘缩进（2 分钟）

```text
for i in range(4):
t.forward(100)    # ❌ 没缩进——不属于循环，只画一条线
```

```text
# 文件结尾忘了 turtle.done()
# ❌ 窗口闪退，画没看清
```

缩进即语法（W03 的老规矩）在 turtle 世界照样管用；`turtle.done()` 是画完的「定妆照」，别忘。

**今日口诀：** 边数 = 循环次数，一条边配一个转角。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
void forward(int d) { std::cout << "go " << d << std::endl; }
void right(int deg) { std::cout << "turn " << deg << std::endl; }
int main() {
    for (int i = 0; i < 4; i++) {
        forward(100);
        right(90);
    }
    return 0;
}
```

三个认脸：

1. 4 次循环画正方形
2. `i < 4` 循环 4 次
3. Python `for i in range(4):` 更简洁
