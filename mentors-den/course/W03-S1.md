## 一、概念：程序终于会「看情况」了（3 分钟）

前两周的程序都是"直线剧本"：从第一行演到最后一行，不管不顾。真实世界不是这样——

- 分数到了 60，才能及格
- 猫粮剩得不多，就该提醒囤货
- 边境出现入侵者，族长才下令出击

**if** 就是让程序学会"看情况"。玩过 Scratch 的同学：「如果……那么……」积木，一模一样的思想。

## 二、if 的样子（4 分钟）

看这段代码（今天只看不敲）：

```python
score = int(input("What score did you get? "))

if score >= 60:
    print("Passed!")
    print("You can play Scratch for 30 minutes")
```

运行两次会发生什么？

- 输入 **80** → 两行都打印
- 输入 **59** → 一片安静——条件不满足，if 手下的活儿**全部跳过**

一片安静不是程序死了，是 if 在"看情况"。

## 三、逐字拆解：if 四件套（3 分钟）

| 部件 | 作用 |
|---|---|
| `if` | 「如果」这个词 |
| `score >= 60` | 条件：结果非真即假 |
| `:` | 冒号 =「那么」，下面缩进的行归它管 |
| 缩进 4 格 | 手下名单：哪些行听 if 的 |

**关键：** 归 if 管的是**缩进的那几行**。条件不满足，这几行整段跳过；条件满足，这几行全部执行。

**今日口诀：** if、条件、冒号、缩进——四件套齐了，程序就会看情况。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 里的 `if` 长这样：

```cpp
#include <iostream>
int main() {
    int score = 85;
    if (score >= 60) {
        std::cout << "pass" << std::endl;
    }
    return 0;
}
```

三个认脸：

1. `#include <iostream>` 第一行领工具箱（Python 不用）
2. `int score = 85;` 声明变量（C++ 必须声明类型，Python 不用）
3. `if (score >= 60)` 条件必须用括号包（Python 直接 `if score >= 60:`）

> AI 营笔试的编程题用 C++ 出。不用会写，**认得脸**就行。
