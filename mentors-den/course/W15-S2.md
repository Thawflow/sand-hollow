## 二、第一版长什么样（5 分钟）

只读不敲，眼睛走一遍：

```python
import random

choices = ["rock", "paper", "scissors"]

player = input("Your choice: ").strip().lower()
computer = random.choice(choices)
print(f"You: {player}, Computer: {computer}")

if player == computer:
    print("Tie!")
elif (player == "rock" and computer == "scissors") or \
     (player == "scissors" and computer == "paper") or \
     (player == "paper" and computer == "rock"):
    print("You win!")
else:
    print("Computer wins!")
```

三个老朋友全回来了：`strip().lower()`（W02）防手滑空格大小写、`choice`（昨天）、and/or 组合条件（W03-S5）。

## 三、判定逻辑拆开看（4 分钟）

elif 那长串其实是**三个「赢」的条件用 or 连起来**：

```python
win = (player == "rock" and computer == "scissors") \
   or (player == "scissors" and computer == "paper") \
   or (player == "paper" and computer == "rock")
```

- 每个小括号 = 一种「刚好克制」的组合
- 括号之间用 or：满足任意一种就是赢
- 行尾的 `\` 是续行符——一行太长可以折成三行写

判断顺序也有讲究：先排除平局（`==`），再判赢，剩下的自然判负——**平局不先排掉，赢的条件永远轮不到细看**。

**今日口诀：** 先判平，再判赢，剩下的全输给电脑。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的对应写法：

```cpp
#include <iostream>
#include <cstdlib>
int main() {
    int n = rand() % 3;  // 0=rock 1=paper 2=scissors
    if (n == 0) std::cout << "rock" << std::endl;
    else if (n == 1) std::cout << "paper" << std::endl;
    else std::cout << "scissors" << std::endl;
    return 0;
}
```

三个认脸：

1. `rand() % 3` 0-2 三选一
2. if-elif 判定
3. Python `random.choice(["rock", "paper", "scissors"])`
