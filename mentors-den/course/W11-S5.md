## 一、雪花 = 一根冰枝 × 转圈盖章（3 分钟）

先造一个「积木」：一条带分叉的冰枝。

```python
import turtle

t = turtle.Turtle()
t.speed(0)

def snowflake_arm():
    for i in range(5):
        t.forward(30)
        t.backward(30)   # 原路退回，不留往返线
        t.left(60)       # 换个角度再画一根小刺
```

拆解：前进 30 画一根刺，**backward 原路退回**回到出发点，左转 60° 再画下一根——5 根刺组成一根冰枝（backward 不留线是因为退回的线**盖在去线上**，看起来一根）。

## 二、转圈盖章：6 枝成雪花（3 分钟）

一根冰枝不够，转着复印 6 次：

```python
for arm in range(6):
    snowflake_arm()
    t.left(60)

turtle.done()
```

**眼熟吗？** 6 枝 × 60° = 360°——又是 S4 的外角和公式！雪花 = 冰枝积木 × 总转角 360°。想要 8 枝雪花？360 ÷ 8 = 45°，换两个数字就成。

## 三、螺旋：递增 + 偏一点（3 分钟）

换个魔法：边长**每次变长一点**，角度**故意不整**：

```python
t.pencolor("blue")
for i in range(40):
    t.forward(5 + i * 5)   # 边长随 i 递增：5,10,15,...
    t.left(91)             # 91 度 = 90 多 1 度
```

为什么 91° 会旋出去？每次多偏 1°，40 步累计偏 40°——正方形框架被慢慢「拧」成螺旋。若一直转 90°，画出来的只是越来越大的方框，**永远闭不成螺旋**。

**递增公式：** `5 + i * 5`——起步 5，每步加 5。想让螺旋更密，把 5 换小；更疏，换大。

## 四、三件套合体回顾（2 分钟）

| 图案 | 套路 |
|---|---|
| 多边形 | 360/边数 转角 × 边数次 |
| 雪花 | 冰枝函数 × (360/枝数) 次 |
| 螺旋 | 递增边长 + 「差一点」的角度 |

全是**循环 + 角度**的组合拳——这就是「循环艺术」的全部配方。

**今日口诀：** 雪花靠盖章，螺旋靠递增 + 偏角。
