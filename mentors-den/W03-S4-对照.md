## 快照零接触（2026-11-09 拍板⑤ 增补）

**为什么补这一段**：拍板⑤ 定「对照内容整体放本文件，快照本体零接触」——
原因不是洁癖，是**判据 A 会被快照的触碰刷假活跃**：

- 学员零活跃双判据的判据 A = `git log -1 -- <学员目录>`（该目录末次被 commit 触碰的日期）；
- 快照本体在 `tree/reviews/` 下 ⇒ **任何对它的改动都会刷新 tree 的判据 A**；
- 实测：11-09 上午给快照加对照行 ⇒ tree 的 A 从 2026-10-06（真实最后落档日）
  刷到 2026-11-09 ⇒ **零活跃 34 天的学员被洗成「单维零（仅提示）」** = 假活跃。
- 活跃信号是给家人看的仪表盘 ⇒ 洗掉一次，以后每次亮黄都要重新猜是不是被哪笔 commit 刷的。

⇒ 结论：**对照行只能落本文件（`mentors-den/` 顶层）**，快照本体一个字都不动。

⚠️ 落点约束（冰爪 11-08 自曝 + 11-09 复核）：
`mentors-den/reviews/` 整棵被仓根 `.gitignore` 的 `**/reviews/` 挡（`git check-ignore` 实测命中）
⇒ 对照文件落那儿 = git 永远看不见 = 白落。
