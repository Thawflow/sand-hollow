# B 方案：零依赖离线学习通道（v0.2）

> **状态**：v0.2 落档 · 依 mentors-den 家长会讨论方向整理 · 待家长 review
> **定位**：本文件是方案本体（公开仓），学员个人学习进度等私域细节**不入库**，走家庭内部渠道
> **前置政策**：沙坑接入以智能体（agent）为必要通道 —— 见站点 `<meta name="required-agents">` 声明（Hermes / OpenClaw / WorkBuddy 等）。本方案不绕过该政策：**「零依赖」指学员无需个人账号/token，仍默认经 agent 接入**
> **关联**：PWA 外壳（`docs/manifest.webmanifest` + `sw.js`，cache-first）；课程静态化后的 `/course/*.html`

---

## 〇、问题陈述

沙坑 `learning.thawflow.com` 的完整学习闭环目前强依赖三件外部设施：① 作业信箱（KV upsert）② agent 侧确认回执 ③ 玩家号体系 —— 都需要 token 或账号。目标：**学员第一次访问即可看课、可写 demo 代码、可对照答案，全程不要求任何个人身份**，联网后可自愿升级为正式学员。

## 一、现状盘点

### ✅ 已实现（无需重做）

- **PWA 外壳**：manifest + service worker（cache-first）+ 图标三件套；Chrome 可装为桌面应用，断网可看课
- **课程静态化**：课程页走 `/course/*.html` 静态产物，离线缓存后不依赖后端
- **课程配图零依赖**：内联 SVG 渲染，无需后端拉取
- **答案对照**：随课程页下发（静态化后天然离线可用）

### ❌ 待实现

| 项 | 说明 | 状态 |
|---|---|---|
| **L2 · 离线写 demo** | 学员本机写 `.py`，浏览器内存续（IndexedDB）或导出文件 | 未做 |
| **L3 · 联网交作业** | 学员联网时把 demo 提交到作业信箱（worker endpoint） | 未部署 |
| **升级路径** | 首次联网时「上传 demo → 建档 → 升级正式学员」引导 | 未做 |

### 范围分层（v1 建议只做 L1+L2）

| 层 | 内容 | 当前状态 |
|---|---|---|
| **L1 · 看课** | 课程全量 web 离线浏览 | ✅ 已支持 |
| **L2 · 写 demo** | 离线写代码 + 本地存续 | ❌ 待做 |
| **L3 · 交作业** | 联网回传信箱 + 升级建档 | ⚠️ 依赖 worker endpoint |

## 二、实施骨架

1. **L2 最小闭环**：课程页嵌编辑区（现有 textarea 起步，不引重型编辑器），IndexedDB 按 `课节+题号` 存草稿；「导出 .py」按钮兜底（无 IndexedDB 环境也能用）
2. **L3 前置**：worker endpoint 部署后，课程页「交作业」按钮 → POST 信箱 → 回执号展示
3. **升级路径**：信箱建档后由 agent 侧把学员接入现有 review 链路（家庭内部流程，不入公开仓）

## 三、不重叠确认

- **no-hermes 外部学员线**：另一文档承载「完全无 agent 学员」的路径；本方案默认 agent 接入，两者互补
- **登录系统**：「学习后记住你」是 L3 建档的可选增强，不是本方案前置
- **作业 review 链路**：属家庭内部流程，只在本方案留接口（L3 回传），细节不入库
