## 核心教学法 · 三点映射

### 1. git clone 本地克隆法接入 → W07「猫咪冒险岛」项目周
- **定位：** W07 项目周的前置工具课
- **方法：** 学员第一次遇到「项目周」之前，先学会 git clone 把课程骨架拉到本地
- **目标：** 项目周不需要从零搭脚手架，clone + 改 + commit = 主线
- **Tree 方向：** 可替换为「菜单驱动的数据小工具」，与 ThawPaw 并行

### 2. OpenClaw 案例课 → W12 毕业项目 🎓
- **定位：** W12 自选主题（游戏 / turtle 画集 / 实用工具 / 数据小报表）
- **方法：** 用 OpenClaw 走一遍「设计图 → 逐块完成 → 写作品说明 → 家族展示会」
- **目标：** 100+ 行自己写的代码，能讲清每一部分，报错自己修
- **案例：** OpenClaw = 咱家这个 AI 工具（Vega Punk 计划核心，能帮你写代码 + 跑流程 + 自动整理笔记），用它做 chatroom PWA / 自动化工作流 / AI 工具集成

### 3. annex 兜底资料 → sandbox 全程可用
- **定位：** 学员卡住时随时查，sandbox 允许无限重练
- **方法：** annex 资料按章节归档（每章 5-10 个常见卡点 + 解法）
- **目标：** 不让任何学员卡超过 15 分钟没人帮，sandbox 重练不算落后
- **覆盖：** input / f-string / 分支 / 循环 / 函数 / 列表 / 字典 / 项目周等所有章节
