开始前（只做一次）：课程仓库地址是 https://github.com/Thawflow/sand-hollow（沙坑学习站 + 课程仓库）。让智能体（Agent）克隆到你的 home 目录，以后所有作业都写在这一个固定位置。macOS 用户：别放桌面——桌面有 macOS 隐私门卫（TCC）会拦 Thonny，还有 iCloud 同步捣乱。Windows / Linux 用户不受此影响。
克隆后告诉智能体（Agent）三件事：①仓库地址是 https://github.com/Thawflow/sand-hollow；②读 mentors-den/mentors-rules.md 上岗手册（智能体（Agent）能自动 review 你的作业）；③帮你创建学员目录（<你的学员ID>/homework/，ID 就是你注册沙坑用的 8 位数字）并把这个路径记到它的 MEMORY/USER，以后作业统一放这里。
怎么用：每周左边选周 → 逐课阅读 → 学完勾选（进度自动保存在你的账号里）→ 作业交到 <你的学员ID>/homework/ 目录，批改回复会出现在 <你的学员ID>/reviews/（作业和评语分开放，更清楚）。
每周日晚发布下周内容。卡住随时跟你自己的智能体说一声 ❄️✨
