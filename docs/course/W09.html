一、核心想法（3 分钟）

要凑 8.7 元，硬币面额是 [1元, 5角, 1角]。每种硬币无限。

方法 1：随便挑（不挑最大）。先挑 1 角、1 角、1 角……要 87 枚。

方法 2：永远挑最大。先 5 元（剩 3.7），再 1 元（剩 2.7），再 1 元（剩 1.7），再 1 元（剩 0.7），再 5 角（剩 0.2），再 1 角（剩 0.1），再 1 角（剩 0）。8 枚。

方法 2 用更少硬币（虽然多一步）。这就是贪心：每步挑当前能挑的最大。

二、示例演算：凑 8.7 元（5 分钟）

步 选什么 还剩
1 1 元 7.7
2 1 元 6.7
3 1 元 5.7
4 1 元 4.7
5 1 元 3.7
6 5 角 3.2
7 1 角 3.1
8 1 角 3.0

每步都"挑当前能挑的最大"——每步之后 8.7 的剩余量减少 1 枚最大硬币的量。每枚大硬币 = 多枚小硬币——所以挑大能省。

三、Python 代码（5 分钟）

def greedy_coin_change(amount, coins):
    '''
    Return a list of coins that sums to amount, using greedy.
    coins must be sorted from largest to smallest.
    '''
    result = []
    for coin in coins:
        while amount >= coin:
            result.append(coin)
            amount = amount - coin
    return result

# Make 8.7 yuan (870 cents)
coins = [100, 50, 10]    # 1 yuan, 5 jiao, 1 jiao (unit: cents)
print(greedy_coin_change(870, coins))
# [100, 100, 100, 100, 100, 50, 10, 10]  <- 5x 1 yuan + 1x 5 jiao + 2x 1 jiao = 8 coins

核心循环：for coin in coins: while amount >= coin: 拿一个 coin。

四、深入了解：贪心为什么有时错（3 分钟）

贪心 = 永远挑局部最优——不回头看。有时会"卡"在局部最优，找不到全局最优。

真实案例：

  • 导航：贪心 = 每步选最近的路——但可能错过"绕远但快"的高速
  • 股票：贪心 = 每天买涨的——但可能错过"低买高卖"的最佳时机
  • AI 训练：贪心梯度下降 = 每步选下降最快的方向——但可能卡在"局部最低"，找不到"全局最低"

AI 工程师怎么应对：

  • 贪心失败时：升级为动态规划、搜索、模拟退火
  • 永远先试贪心：O(n) 简单；失败再升级

没学贪心的 AI 工程师 = 不会"快但不一定对"哲学。

五、何时用：贪心的 4 个使用场景（3 分钟）

场景 用贪心 理由
找零（标准硬币 [1, 5, 10, 25, 100] 美分） ✓ 数学证明过永远最优
活动选择（选最多不重叠） ✓ 选最早结束的

一、贪心函数实战（5 分钟）

def greedy_change(amount, coins):
    '''Greedy. coins sorted largest to smallest.'''
    result = []
    for coin in coins:
        while amount >= coin:
            result.append(coin)
            amount -= coin
    return result

# Test
print(greedy_change(870, [100, 50, 10]))    # 8 coins
print(greedy_change(60, [40, 30, 10]))      # 3 coins (NOT optimal)

二、暴力函数（5 分钟）

def brute_change(amount, coins):
    '''Try every combination, return shortest.'''
    best = None
    def try_combos(remaining, coins, current):
        nonlocal best
        if remaining == 0:
            if best is None or len(current) < len(best):
                best = list(current)
            return
        if remaining < 0:
            return
        if best is not None and len(current) >= len(best):
            return
        for i, coin in enumerate(coins):
            current.append(coin)
            try_combos(remaining - coin, coins[i:], current)
            current.pop()
    try_combos(amount, coins, [])
    return best if best is not None else []

关键：先 sort coins + coins[i:] 让后面只看更小硬币，避免重复。

三、示例演算：amount=60, coins=[40, 30, 10]（3 分钟）

贪心：40 + 10 + 10 = 60 (3 枚) 暴力：30 + 30 = 60 (2 枚) ✓ 最优

暴力赢——贪心用了 3 枚，最优 2 枚。

四、深入了解：暴力为什么"慢"（3 分钟）

暴力 = 遍历所有组合 = O(2^n)。

金额 硬币数 组合数（最坏）
60 3 2³ = 8
100 3 2³ = 8
1000 5 2⁵ = 32
100 万 5 2⁵ = 32（但 amount 大）

amount 比 coin 数更影响——所以暴力适合小 amount 测试贪心对错。

data small (< 1000)?
  yes -> brute (gold standard)
  no -> greedy
       counter-example?
            yes -> dynamic programming
            no -> greedy ✓

def test_greedy_vs_brute():
    '''Random test: greedy vs brute.'''

一、核心想法：贪心失败的例子（3 分钟）

凑 6 角，硬币 [4角, 3角, 1角]：

贪心：先 4 角（剩 2 角）→ 1 角（剩 1 角）→ 1 角（剩 0）= 3 枚。

最优：3 角 + 3 角 = 2 枚。

贪心：3 枚。最优：2 枚。差 1 枚。

为什么失败？ 贪心看到 4 角最大就挑，但两个 3 角才 = 6 角，比 4 角 + 1 角 + 1 角 更省。

二、示例演算：0.9 元凑 50/30/10/1 硬币（5 分钟）

步 选什么 还剩
1 50 (5 角) 40
2 30 (3 角) 10
3 10 (1 角) 0
4 1 (1 分) — 剩 90 分，4 步 4 枚？错了

重新算（贪心选最大 5 角）：

步 选什么 还剩
1 50 (5 角) 40
2 30 (3 角) 10
3 10 (1 角) 0
4-93 1 (1 分) × 90 0

贪心结果：1 个 5 角 + 1 个 3 角 + 1 个 1 角 + 90 个 1 分 = 93 枚。

最优：3 个 3 角 = 9 角 = 3 枚。

差 90 枚！

三、活动选择问题（5 分钟）

任务：选最多不重叠的活动。

Activities: A(1-4)  B(3-5)  C(0-6)  D(5-7)  E(8-9)  F(5-9)

贪心：选最早结束的活动。

  1. A 最早结束 (4)，选
  2. 跳过 B (3-5 和 A 重叠)、C (0-6 和 A 重叠)
  3. D 最早结束 (7)，选
  4. 跳过 F (5-9 和 D 重叠)
  5. E (8-9)，选

结果：[A, D, E] = 3 个活动。

最优：[B, D, E] 或 [B, E, ...] = 同样 3 个。在这个例子贪心刚好对。

真反例：

A(1-4)  B(2-3)  C(3-5)
  • 贪心：A 最早结束 4 选
  • 最优：B(2-3) + C(3-5) = 2 个
  • 贪心只选 A = 1 个

五、深入了解：贪心 vs 动态规划（3 分钟）

当贪心失败时，AI 工程师升级到动态规划：

算法 复杂度 何时用
贪心 O(n) 简单问题（找零/活动选择）
动态规划 O(n²) 或更多 复杂问题（背包/最短路径）
暴力搜索 O(2ⁿ) 极小问题（n < 20）

实际经验：

  • 90% 简单问题贪心搞定
  • 9% 需要动态规划
  • 1% 需要暴力/启发式

AI 工程师的肌肉记忆：先试贪心，失败再升级——别上来就动态规划（杀鸡用牛刀）。

六、何时用：识别贪心失败（3 分钟）

3 个红旗：

  1. 整数约束：硬币只能是整数个（找零、切割）
  2. 组合爆炸：可能有"大+小"代替"中+中"（背包）
  3. 未来约束：现在的选择影响未来可能性（活动选择）

如果有红旗：别用贪心，先用暴力算法（小数据验证），再升级动态规划。

一、问题：选最多不重叠（3 分钟）

Activities: A(1-4)  B(3-5)  C(0-6)  D(5-7)  E(8-9)  F(5-9)

目标：选最多活动，互不重叠。

二、贪心策略：选最早结束（5 分钟）

算法：

  1. 按结束时间排序所有活动
  2. 选第一个（最早结束）
  3. 跳过所有跟它重叠的
  4. 重复选下一个
def activity_selection(activities):
    '''Greedy: pick earliest-finishing activity.'''
    # Sort by end time
    sorted_acts = sorted(activities, key=lambda a: a[1])
    selected = [sorted_acts[0]]
    last_end = sorted_acts[0][1]

    for activity in sorted_acts[1:]:
        start, end = activity
        if start >= last_end:    # no overlap
            selected.append(activity)
            last_end = end

    return selected

四、深入了解：为什么"选最早结束"最优（3 分钟）

数学证明思路（简化）：

  • 假设选活动 a 结束时间最早 = t
  • 任何最优解都可以替换成"选 a + 剩下的最优解"

二、3 种贪心策略（5 分钟）

def patrol_greedy_value(patrols):
    '''Strategy 1: pick highest value first.'''
    sorted_p = sorted(patrols, key=lambda p: -p['value'])
    return pick_within_time(sorted_p, 8)

def patrol_greedy_efficiency(patrols):
    '''Strategy 2: pick highest value/time ratio.'''
    sorted_p = sorted(patrols, key=lambda p: -(p['value'] / p['time']))
    return pick_within_time(sorted_p, 8)

def patrol_greedy_shortest(patrols):
    '''Strategy 3: pick shortest time first.'''
    sorted_p = sorted(patrols, key=lambda p: p['time'])
    return pick_within_time(sorted_p, 8)

def pick_within_time(sorted_patrols, max_time):
    '''Pick patrols in order while time permits.'''
    selected = []
    total_time = 0
    for p in sorted_patrols:
        if total_time + p['time'] <= max_time:
            selected.append(p)
            total_time += p['time']
    return selected

二、贪心函数（10 分钟）

def greedy_change(amount, coins):
    '''Return a list of coins that sums to amount using greedy.'''
    result = []
    for coin in coins:
        while amount >= coin:
            result.append(coin)
            amount = amount - coin
    return result

三、暴力函数（15 分钟）

def brute_change(amount, coins):
    '''
    Try every combination, return the shortest.
    Exponential: only works for small amount and small coin set.
    '''
    best = None
    def try_combinations(remaining, coins, current):
        nonlocal best
        if remaining == 0:
            if best is None or len(current) < len(best):
                best = list(current)   # copy
            return
        if remaining < 0:
            return
        if best is not None and len(current) >= len(best):
            return   # prune: cannot beat current best
        for i, coin in enumerate(coins):
            current.append(coin)
            try_combinations(remaining - coin, coins[i:], current)
            current.pop()

    try_combinations(amount, coins, [])
    return best if best is not None else []

技巧：先 sort coins（最大到最小），同时 coins[i:] 让后面递归只看当前和更小的硬币，避免重复。

六、深入了解：暴力为什么仍有用（3 分钟）

暴力算法 = 黄金标准——慢但保证对。3 个用途：

  1. 测试贪心对错：暴力找最优，贪心 vs 暴力 = 反例检测
  2. 小数据 baseline：n < 20 时暴力足够，不必优化
  3. 教学：暴力最直观，先写暴力再优化

真实案例：

  • 单元测试：永远拿"已知答案"测试代码（参考实现是暴力）
  • 算法竞赛：小数据暴力得部分分，大数据再优化
  • AI debug：用暴力结果对比 ML 输出，看偏差

没学暴力的 AI 工程师 = 不会"找反例"的工程师。
