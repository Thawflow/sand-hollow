一、概念：程序终于会「看情况」了（3 分钟）

前两周的程序都是"直线剧本"：从第一行演到最后一行，不管不顾。真实世界不是这样——

  • 分数到了 60，才能及格
  • 猫粮剩得不多，就该提醒囤货
  • 边境出现入侵者，族长才下令出击

if 就是让程序学会"看情况"。玩过 Scratch 的同学：「如果……那么……」积木，一模一样的思想。

二、if 的样子（4 分钟）

看这段代码（今天只看不敲）：

score = int(input("What score did you get? "))

if score >= 60:
    print("Passed!")
    print("You can play Scratch for 30 minutes")

运行两次会发生什么？

  • 输入 80 → 两行都打印
  • 输入 59 → 一片安静——条件不满足，if 手下的活儿全部跳过

一片安静不是程序死了，是 if 在"看情况"。

三、逐字拆解：if 四件套（3 分钟）

部件 作用
if 「如果」这个词
score >= 60 条件：结果非真即假
: 冒号 =「那么」，下面缩进的行归它管
缩进 4 格 手下名单：哪些行听 if 的

关键： 归 if 管的是缩进的那几行。条件不满足，这几行整段跳过；条件满足，这几行全部执行。

今日口诀： if、条件、冒号、缩进——四件套齐了，程序就会看情况。

👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 里的 if 长这样：

#include <iostream>

    int score = 85;

W03-S2 · 比较六兄弟与缩进魔法

每日节奏（v1.9）： 本篇纯阅读 ≈11 分钟，读完做当天作业 ≈10 分钟，总共 ≤25 分钟 不需要 Thonny（正文）——作业时间才开编辑器 难度：⭐⭐ · 本篇是原 W03-L01 的中段（比较运算符 + 缩进即语法）

一、比较运算符六兄弟（5 分钟）

if 的"条件"靠它们写出来：

写法 读作 例子 结果
== 等于 10 == 10 True
!= 不等于 "猫" != "狗" True
> 大于 3 > 5 False
< 小于 3 < 5 True
>= 大于等于 60 >= 60 True
<= 小于等于 59 >= 60 False

比较的结果是 True / False（真 / 假），这类值叫布尔值——今天混个脸熟，后面天天见。

透视镜时刻（W02 的知识回来了）：

print("10" == 10)   # False！

字符串 "10" 和数字 10 类型不同，Python 眼里永不相等。引号是种族标志，忘了的回 W02-S1 翻口诀。

二、缩进即语法（5 分钟）

别的语言用花括号 {} 圈地盘，Python 用缩进。看这段：

score = 59
if score >= 60:
    print("Passed!")
print("Done!")

最后一行没缩进——它不属于 if，不管及不及格都会打印。

  • 运行：if 内部跳过，但 "Done!" 照样出现
  • 缩进与否，改变每一行的归属

这就是「缩进即语法」：缩进不是美观，是规则本身。

三、Thonny 缩进小贴士（1 分钟）

写完 if ...: 按回车，光标自动缩进；想退出缩进，按一次删除键。Thonny 在帮你守规矩。

今日口诀： 六兄弟比出真假，缩进决定谁听谁的。

想写「如果年龄是 18」，手滑写成：

符号 名字 意思
= 一个等号 装进去（赋值）：把右边装进左边

Python 把关把得好——这种错它替你拦下，感恩。

二、坑②：漏冒号（3 分钟）

报错： SyntaxError: expected ':'——报错就在告诉你缺什么。if 行尾的冒号，一个不能少（else / elif / 以后的 for 全都一样）。

三、坑③：缩进忽长忽短（3 分钟）

    print("Passed!")

规矩：统一 4 个空格，全文件一致。Thonny 的 Tab 键就是按 4 格设计的，别手滑多敲一个空格。

W03-S4 · else 与 elif：B 计划和多岔路口

每日节奏（v1.9）： 本篇纯阅读 ≈12 分钟，读完做当天作业 ≈10 分钟，总共 ≤25 分钟 不需要 Thonny（正文）——作业时间才开编辑器 难度：⭐⭐ · 本篇是原 W03-L02 的精华（else / elif / 命中即止 / 顺序陷阱）

一、概念：if 只管晴天（3 分钟）

上次的年龄闸机有个尴尬：条件不满足时，屏幕一片安静，用户以为程序死了。真实世界要有 B 计划：

  • 满了 18 → 欢迎入座
  • 不满 18 → 「再等等，先去看猫武士」

今天两位新成员：else（否则）和 elif（否则如果）。

二、else：B 计划（4 分钟）

n = int(input("Give me a whole number: "))

if n % 2 == 0:
    print(n, "is even")
else:
    print(n, "is odd")

输入 8 → 偶数；输入 7 → 奇数。必有其一，只走其一。

else 语法三件事：

  • 行尾也要冒号
  • 下面的行也要缩进 4 格
  • else 后面不接条件——if 已经问过了，剩下的全归它

（还记得 % 吗？W02 说的"判断奇偶天天用"，今天兑现了。）

三、elif：多岔路口（5 分钟）

只有两条路不够用？elif = else + if 合体：

height = int(input("Your height in cm? "))

if height >= 140:
    print("Any roller coaster you like!")
elif height >= 120:
    print("You can ride the small coaster")
else:
    print("Try the carousel first, build some courage")

身高 150 → 大过山车；125 → 小过山车；100 → 旋转木马。

四、命中即止：elif 链的灵魂（3 分钟）

Python 的走法：从上往下扫描，命中一条，其余全部跳过。

用 150 验证：150 >= 140 成立，150 >= 120 其实也成立——但只打印大过山车。命中第一条后，整串直接跳过，绝不回头。

身高 >= 140？ >= 120？ 实际输出
150 真（命中） 不再看 大过山车
125 假 真（命中） 小过山车
100 假 假 落入 else：旋转木马

五、顺序陷阱（1 分钟）

把 >= 120 放在 >= 140 前面会怎样？150 一进门就命中 120，永远坐不上大过山车。

规矩：门槛从高到低排（大的条件放前面）。

今日口诀： 从上往下，命中即止；门槛高的，站在前排。
