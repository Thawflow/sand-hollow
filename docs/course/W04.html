二、for 的样子（4 分钟）

    print("Hello,", i)

Hello, 2

三、逐字拆解：for 四件套（3 分钟）

部件 作用
for 「为了」每个值，做下面的事
i 临时变量，每次循环换一个新值
in range(5) 从 0、1、2、3、4 里逐个取
: + 缩进 冒号 =「那么」，缩进的行每次循环都跑

W04-S2 · range 的三种玩法

每日节奏（v1.9）： 本篇纯阅读 ≈11 分钟，读完做当天作业 ≈10 分钟，总共 ≤25 分钟 不需要 Thonny（正文）——作业时间才开编辑器 难度：⭐⭐ · 本篇是原 W04-L01 的中段（range 三姿势 + 有用小事）

一、三种姿势一次看全（6 分钟）

# 姿势一：range(5) → 0,1,2,3,4（从 0 开始，到 N-1 收）
for i in range(5):
    print(i)

# 姿势二：range(2, 7) → 2,3,4,5,6（从 2 开始，到 7 之前收）
for i in range(2, 7):
    print(i)

# 姿势三：range(0, 10, 2) → 0,2,4,6,8（步长 2，跳着走）
for i in range(0, 10, 2):
    print(i)

想偷看 range 里装了什么？用 list() 照一照：

print(list(range(1, 6)))     # [1, 2, 3, 4, 5]
print(list(range(0, 20, 5))) # [0, 5, 10, 15]

二、含头不含尾：range 唯一铁律（3 分钟）

  • range(5) 给 0-4，不含 5
  • range(2, 7) 给 2-6，不含 7

记忆口诀：含头不含尾，永远差一个。

想数 1 到 10？range(1, 11)——尾巴多写一个，就是诀窍。

三、循环做点有用的（2 分钟）

9 的乘法表前 9 项，三行搞定：

for n in range(1, 10):
    print(f"9 x {n} = {9 * n}")

f-string（W02 的老朋友）+ for（本周新朋友）= 自动化第一步。循环体里还能放 if——下一题作业你会用到。

四、步长为负：倒着走（2 分钟）

步长还能写负数——range 不光往前走，也能往回走。

for n in range(5, 0, -1):
    print(n)        # 5,4,3,2,1

诀窍： 步长是 -1 时，range 从第一个参数往下数到第二个参数之前。第三个 -1 决定方向，正数往上、负数往下。想从 10 倒到 1？range(10, 0, -1)——含头不含尾的规矩没变，只是倒着数。

今日口诀： 一个 N 数到 N-1，两个数含头不含尾，三个数跳着走，步长为负是倒档。

一、概念：循环真正的威力（3 分钟）

打 5 行 Hello 像玩具。for 循环真正的威力是「累加」——把一堆数压成一个数：

  • 算这个月花了多少钱（10 笔加一起）
  • 算全班平均分（30 个分数加完除以 30）

记住四个字：先建箱子，再往里扔。

二、第一招：求和（5 分钟）

total = 0
for i in range(1, 11):
    total = total + i
print("Sum 1-10 =", total)

运行得 Sum 1-10 = 55（高斯 7 岁就算出来过，你也不差）。

累加器四件套

部件 作用
total = 0 建箱子：起手归零
for i in range(...) 循环：逐个取数
total = total + i 往里扔：把当前数加进箱子
print(...) 出箱子：循环结束看结果

total = total + i 看着像"自己等于自己"，其实是先算右边、再装进左边：右边的 total 是老总和，左边是装上新值的箱子。每轮循环，箱子长大一圈。

简短写法： total += i 等价于 total = total + i，以后常用。

三、第二招：计数（4 分钟）

计数 = 每看到目标，箱子 +1：

count = 0
for i in range(1, 21):
    if i % 2 == 0:
        count += 1
print("Even numbers in 1-20:", count)
  • count = 0：建空计数器
  • if i % 2 == 0：是偶数吗（W03 的 if 在循环里上班了！）
  • count += 1：是的话计数器 +1

for 循环里放 if——两个老朋友合体，这是本周最重要的形态。

今日口诀： 建箱子、进循环、往里扔、出箱子。

W04-S4 · 累加器·找最大与三坑

每日节奏（v1.9）： 本篇纯阅读 ≈11 分钟，读完做当天作业 ≈10 分钟，总共 ≤25 分钟 不需要 Thonny（正文）——作业时间才开编辑器 难度：⭐⭐⭐ · 本篇是原 W04-L02 的后段（找最大 + 累加器三坑）

一、第三招：找最大——擂台赛（5 分钟）

不是把所有数加起来，而是留住最大的那个：

nums = [3, 7, 2, 9, 4]
biggest = nums[0]
for n in nums:
    if n > biggest:
        biggest = n
print("The biggest is:", biggest)

得 The biggest is: 9。

擂台赛规则

  • nums = [3, 7, 2, 9, 4]：一个列表（W06 正式学，今天先借用）
  • biggest = nums[0]：第一个数先当擂主（nums[0] 是列表第 1 个——Python 从 0 数起）
  • if n > biggest：有人比擂主强？
  • biggest = n：是的话，换人当擂主

二、初值口诀（2 分钟）

目标 箱子初值
求和 0
计数 0
找最大 / 找最小 第一个数（不是 0！）

为什么找最大不能从 0 起手？想象列表全是负数 [-5, -2, -9]——0 谁都赢不了，最后打印 0，可 0 根本不在列表里。擂主必须从选手里产生。

三、⚠️ 累加器三坑（4 分钟）

  1. 忘建箱子：循环里 total += i 但 total 没先建 → NameError: name 'total' is not defined。累加器必须先建再循环。
  2. 建错初值：找最大却 biggest = 0 → 全负数列表全军覆没（见上）。
  3. = 与 == 混淆：if n = biggest: → SyntaxError。比较用 ==（W03-S3 踩过的坑，穿越而来）。

今日口诀： 擂主从选手里产生——初值选错，满盘皆输。

二、第一招：3 排 5 列星星阵（5 分钟）

for row in range(3):
    for col in range(5):
        print("*", end=" ")
    print()

输出：

* * * * *
* * * * *
* * * * *

嵌套三件套

部件 作用
外层 for row in range(3) 管「行」：做 3 遍
内层 for col in range(5) 管「列」：每行做 5 遍
print()（不缩进在内层里） 一行画完，换行

执行总数 = 外层次数 × 内层次数 = 3 × 5 = 15 次。 外层每走一步，内层走完一整轮。

end=" " 是什么

print 默认每句结尾换行。end=" " 改成"以空格结尾"，星星才能横着排。记住：end 控制 print 句尾加什么。

三、第二招：直角楼梯（3 分钟）

for row in range(1, 6):
    for col in range(row):
        print("*", end=" ")
    print()

*
* *
* * *
* * * *
* * * * *

关键：内层 range(row)——每行的星星数 = 行号。 这是嵌套循环最经典的形态：外层管行号，内层管每行宽度。

四、第三招：金字塔（3 分钟）

height = 5
for row in range(1, height + 1):
    for space in range(height - row):
        print(" ", end="")
    for star in range(2 * row - 1):

两个内层循环：先补空格（height - row 个），再打星星（2 * row - 1 个）。第 N 行星数 = 2N - 1——奇数序列，是数学规律不是死记。

📁 项目存 ~/sand-hollow/<你的学员ID>/homework/，新建 hollow_diamond.py。

需求：打一个空心的菱形（中间是空的），边长 5：

    *
   * *

 *     *

参考实现：

size = 5
# Top half (including middle row)
for row in range(1, size + 1):
    # Leading spaces
    for s in range(size - row):
        print(" ", end="")
    # Left star
    print("*", end="")
    # Inside (hollow part)
    if row > 1:
        for inner in range(2 * row - 3):
            print(" ", end="")
        # Right star
        print("*", end="")
    print()
# Bottom half
for row in range(size - 1, 0, -1):
    for s in range(size - row):
        print(" ", end="")
    print("*", end="")
    if row > 1:
        for inner in range(2 * row - 3):
            print(" ", end="")
        print("*", end="")
    print()

拆解

  • 上半部分行数：range(1, size + 1) 从 1 到 size
  • 下半部分行数：range(size - 1, 0, -1) 从 size-1 到 1（不含中线）

参考实现：

print("=== Multiplication Table ===")

    for j in range(1, i + 1):
        print(f"{j} x {i} = {i*j}", end="\t")

关键观察

  • 外层 i 从 1 到 9：行号
  • 内层 j 从 1 到 i+1：每行的列数（第 i 行有 i 个算式）
