一、Python 是什么（5 分钟）

Python 是全世界最流行的编程语言之一：AI、游戏、科学计算、网站都在用。 写 Python = 用它能看懂的文字，一步一步告诉电脑做什么。

给玩过 Scratch 的同学： Python 就是"文字版 Scratch"，你搭积木做的贪吃蛇，思想完全通用，只是把拖积木变成打字。 没玩过 Scratch 也不用管上面这句，直接开始。

本课两大任务：① 装好写代码的工具 Thonny；② 写出你的第一行代码。

四、第一行代码（15 分钟）

在上方空白区亲手打字（不要复制粘贴！从今天起 4 周内全部手敲）：

逐字拆解 print("Hello, Python!")

部件 作用
print 命令名：把内容打印出来（Python 自带）
( ) 内容放括号里，交给命令
"Hello, Python!" 引号包住的一串文字，叫字符串

规则：一行一个命令，结尾不用分号。

⚠️ 新手三大坑（每个都值得亲手踩一次）

  1. 引号必须英文："..." ✅，中文引号 “...” ❌（输入法切英文！）
  2. 引号要一对：print("你好) 少右引号 → 报错
  3. 区分大小写：Print ≠ print

踩坑方法：故意删掉一个引号，点 Run，读报错。报错最后一行永远是最重要的信息。 读完把引号补回来。

变量（variable）：给东西起名字

W01-L02 · 变量（variable）：给东西起名字

用时：35-45 分钟 · 难度：⭐⭐ · 核心概念：变量（variable）、赋值（assignment）、新手第一大坑

📂 课前准备：先在 Thonny 文件 → 新建，立刻 文件 → 另存为... 存为 ~/sand-hollow/<你的学员ID>/homework/W01-L02-practice.py（ID 就是你注册沙坑用的 8 位数字）。本课所有亲手敲的代码都写进这个文件；课后作业写进同目录的 W01-L02-homework.py，两个文件严格分开，别混。

一、概念：变量 = 贴了标签的盒子（5 分钟）

变量（variable）就是给数据起个名字，以后用名字就能拿到数据。

score = 95

读作：准备一个盒子，贴上 score 标签，里面装 95。

  • = 读作"装进去"，英文叫 assignment（赋值）——它不是数学的 equals（等于）！
  • 标签名（变量名）自己起，要见名知意
  • 盒子里的东西随时可以换

为什么需要变量：程序里同一份数据要用很多次（比如游戏里的得分），不可能每次都重写一遍——起个名字，一劳永逸。

二、第一批变量（10 分钟）

亲手敲：

name = "Alex"
age = 12
pet = "cat"
score = 95

print(name)
print(age)
print(pet)
print(score)

Run 运行，四行数据都出来了。

拆解

  • name = "Alex" —— 文字要引号（字符串）
  • age = 12 —— 数字不要引号
  • print(name) —— 打印盒子里的内容：Alex

换盒子里的东西

在文件末尾加：

score = 95
print(score)
score = 100
print(score)

第一次打印 95，改完再打印变 100。旧值被扔掉，盒子里永远是最新装的。

最烧脑的一行：score = score + 5

score = 90
score = score + 5
print(score)      # 95

读三遍："新的 score = 旧的 score + 5"。 执行顺序：① 打开盒子拿出 90 → ② 算 90 + 5 得 95 → ③ 把 95 装回盒子。 （玩过 Scratch 的同学：这就是「将得分增加 5」积木。）

三、新手第一大坑（10 分钟）

这两行各跑一次，看差别：

print(name)      # prints: Alex (open the box)
print("name")    # prints: name (read the label as-is)

一句话记住：带引号 = 原样照念，不带引号 = 打开盒子拿内容。

再用数字验证一遍坑的威力：

age = 12
print("age")     # prints: age
print(age)       # prints: 12

这个坑至少会陪伴你前两周，每次 print 输出不对，先检查引号。

四、变量命名规则（5 分钟）

  • ✅ 合法：score、my_name、pet2、love_cats
  • ❌ 不合法：2score（数字开头）、my name（有空格）、print（占用命令名）
  • 习惯：全小写 + 下划线；名字要有含义——cat_age 比 x 好一万倍

五、新装备：备注（comment）——写给看代码的人（3 分钟）

程序里常常要留话——给看代码的人看，不让电脑执行。这就是备注（comment）：

# this whole line is a comment - the computer skips it
score = 95   # a comment can also follow the code, like this
  • # 号开头，到行尾为止都是备注，电脑看都不看
  • 用处一：给代码写说明——给读代码的人，包括三个月后的自己
  • 用处二：给文件分区——做练习时每道题前写一行 # --- 题 1 ---，导师一眼看清你做到了第几题
  • 习惯：备注说「为什么」就够，不用复述代码本身

一、概念：让程序跟你聊天（5 分钟）

目前为止都是程序单方面打印。加上 input，程序就能提问并记住你的回答：

name = input("What is your name? ")

拆解：

  • 先打印括号里的问题
  • 然后程序停下，等你打字，你按回车
  • 你打的字就变成了结果，被装进 name 盒子

二、第一个对话程序（10 分钟）

亲手敲：

print("Hello! I am the quiz bot")

name = input("What is your name? ")
food = input("What food do you like best? ")
game = input("What game do you like best? ")

print("So happy to meet you, " + name + "!")
print(name + " likes " + food + ", and loves " + game + ".")

运行，认真回答三个问题，看程序的回应。

拆解拼接

"So happy to meet you, " + name + "!" —— + 把字符串首尾粘起来：

  • 引号里是固定文字，name 是盒子里的内容
  • 空格标点要自己设计在引号里（" likes " 前后有空格）
  • + 只能连接字符串，连数字会报错——马上讲

三、致命细节：input 收到的永远是文字（10 分钟）

input 哪怕收到数字，也当作字符串处理：

age = input("How old are you? ")
print(age + 1)        # error!

报错：字符串不能加数字。你说"11"，程序看做两个字符「1」「1」。

解法——转换：

age = int(input("How old are you? "))
print(age + 1)        # works!

int(...) 把"11"变成 11（真数字）。int 就是 integer（整数）的缩写——顾名思义，它的工作就是把"文字数字"变回整数。

口诀：input 收到的是话，要算数先 int。

再体验一次两种东西的差别：

print("2026" + "2026")    # 20262026 (concatenation)
print(2026 + 2026)        # 4052 (math)
