部件 作用

三、角度是方向的语言（2 分钟）

转弯的单位是度，和数学课的量角器同一套：

  • t.left(90) → 左转一个直角
  • t.right(45) → 右转半 个直角
  • t.left(180) → 掉头，原地反向

关键： 角度是「相对」的——海龟不管自己脸朝哪，left(90) 永远是「往自己左手边转 90 度」。转完后的方向 = 原方向 + 转的角度。

四、预告：正方形只差一把火（1 分钟）

前进 → 左转 90 → 前进 → 左转 90……重复 4 次就是正方形。你心里应该已经冒出老朋友了——for 循环（W04）。明天就让它和海龟合体。

今日口诀： forward 爬、left/right 转、角度跟着感觉走。

二、第一个正方形（4 分钟）

t = turtle.Turtle()

    t.forward(100)
    t.left(90)

逐行拆解：

部件 作用
t.speed(0) 最快档（1 最慢，10 很快，0 瞬移）——画几何图不用等动画

一、画笔个性化三件套（3 分钟）

默认的画是黑线白底。三件套让它变身：

命令 作用 例子
t.pencolor("red") 线条颜色 颜色名是字符串，要加引号
t.pensize(3) 线条粗细（像素） 数字越大线越粗
t.speed(0) 速度（S2 见过） 1 最慢 → 10 快 → 0 瞬移

颜色名常用的有："red" "orange" "yellow" "green" "blue" "purple" "pink" "black" "white"。拼错了会报 bad color sequence——颜色名也是字符串，种族规矩不变（W02）。

二、填充：begin 和 end 夹三明治（4 分钟）

给形状「涂色」靠一对搭档：

import turtle

t = turtle.Turtle()
t.speed(0)
t.pensize(3)

t.fillcolor("yellow")
t.begin_fill()
for i in range(4):
    t.forward(100)
    t.left(90)
t.end_fill()

turtle.done()

运行：一个实心黄正方形。

套路像夹三明治：

  1. t.fillcolor("yellow")——先选好果酱
  2. t.begin_fill()——掀开面包
  3. 中间画形状（循环照旧）
  4. t.end_fill()——盖上另一片面包，果酱自动涂满

规矩： begin 和 end 必须配对。只有 begin 没有 end → 不涂；画了两个形状才 end → 涂成一大坨。

三、抬笔挪窝：penup / pendown（2 分钟）

想在别处再画一个，可不想连一条「飞行线」过去：

t.penup()          # 抬笔：接下来移动不留痕
t.goto(-50, 0)     # 直接飞到坐标 (-50, 0)
t.pendown()        # 落笔：恢复画画

t.goto(x, y) 是瞬移到坐标点。落着笔 goto = 画一条直线过去，多半不是你要的。

四、彩虹五角星预告（2 分钟）

每画一条边换一种颜色——五条边五种颜色。角度 144° 的秘密下节课拆。

今日口诀： pencolor 换色、pensize 加粗、begin/end 夹心填色、penup 挪窝不留痕。

W11-S4 · 正多边形公式：360 的秘密

每日节奏（v1.9）： 本篇纯阅读 ≈11 分钟，读完做当天作业 ≈10 分钟，总共 ≤25 分钟 不需要 Thonny——正文一个字都不用敲，作业时间才开编辑器 难度：⭐⭐⭐ · 本篇对应原 turtle 第三课（文件名 W10-L03）的正多边形函数部分

一、一个观察值千金（3 分钟）

正方形：4 条边，每次转 90°。算一算：4 × 90 = 360。

等边三角形：3 条边，每次转 120°。3 × 120 = 360。

五边形：5 条边，每次转 72°。5 × 72 = 360。

秘密揭晓： 不管几边形，海龟画完一圈总共转了 360 度——转回出发方向，图形才能闭合。这叫外角和定理：任何正多边形的外角和都是 360°。

所以每次转的角度 = 360 ÷ 边数：

形状 边数 每次左转
三角形 3 360/3 = 120°
正方形 4 360/4 = 90°
五边形 5 360/5 = 72°
六边形 6 360/6 = 60°

二、一个函数画遍全家（4 分钟）

把公式塞进函数（W08 老朋友），一个积木画所有形状：

import turtle

t = turtle.Turtle()
t.speed(0)

def polygon(sides, length):
    angle = 360 / sides
    for i in range(sides):
        t.forward(length)
        t.left(angle)

polygon(3, 100)    # 三角形
polygon(6, 60)     # 六边形
polygon(8, 50)     # 八边形

turtle.done()

逐行拆解：

部件 作用
def polygon(sides, length): 积木的两个凹槽：边数 + 边长
angle = 360 / sides 公式本体：360 ÷ 边数
for i in range(sides): 有几条边循环几次

（三个形状会叠在一起——S3 的 penup 挪窝正好用来把它们摆开，作业里试。）

四、坑：为什么 144 不是 72（1 分钟）

五角星每次转 144°，不是 72°——因为五角星画的是星形路径，不是绕一圈的普通五边形。记住区分：普通多边形 360/边数；五角星这种「跨着画」的另有角度。猜角度前先想清楚海龟走的是什么路线。

今日口诀： 360 除以边数，外角和定天下。

每日节奏（v1.9）： 本篇纯阅读 ≈11 分钟，读完做当天作业 ≈10 分钟，总共 ≤25 分钟 不需要 Thonny——正文一个字都不用敲，作业时间才开编辑器 难度：⭐⭐⭐ · 本篇对应原 turtle 第三课（文件名 W10-L03）的雪花 / 螺旋部分——W09 收官！

一、雪花 = 一根冰枝 × 转圈盖章（3 分钟）

先造一个「积木」：一条带分叉的冰枝。

import turtle

t = turtle.Turtle()
t.speed(0)

def snowflake_arm():
    for i in range(5):
        t.forward(30)
        t.backward(30)   # 原路退回，不留往返线
        t.left(60)       # 换个角度再画一根小刺

拆解：前进 30 画一根刺，backward 原路退回回到出发点，左转 60° 再画下一根——5 根刺组成一根冰枝（backward 不留线是因为退回的线盖在去线上，看起来一根）。

二、转圈盖章：6 枝成雪花（3 分钟）

一根冰枝不够，转着复印 6 次：

for arm in range(6):
    snowflake_arm()
    t.left(60)

turtle.done()

眼熟吗？ 6 枝 × 60° = 360°——又是 S4 的外角和公式！雪花 = 冰枝积木 × 总转角 360°。想要 8 枝雪花？360 ÷ 8 = 45°，换两个数字就成。

三、螺旋：递增 + 偏一点（3 分钟）

换个魔法：边长每次变长一点，角度故意不整：

t.pencolor("blue")
for i in range(40):
    t.forward(5 + i * 5)   # 边长随 i 递增：5,10,15,...
    t.left(91)             # 91 度 = 90 多 1 度

为什么 91° 会旋出去？每次多偏 1°，40 步累计偏 40°——正方形框架被慢慢「拧」成螺旋。若一直转 90°，画出来的只是越来越大的方框，永远闭不成螺旋。

递增公式： 5 + i * 5——起步 5，每步加 5。想让螺旋更密，把 5 换小；更疏，换大。

四、三件套合体回顾（2 分钟）

图案 套路
多边形 360/边数 转角 × 边数次
雪花 冰枝函数 × (360/枝数) 次
螺旋 递增边长 + 「差一点」的角度

全是循环 + 角度的组合拳——这就是「循环艺术」的全部配方。

今日口诀： 雪花靠盖章，螺旋靠递增 + 偏角。
