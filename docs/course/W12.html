一、核心想法（3 分钟）

数组 = 火车站：座位连号（1, 2, ..., 100），找第 50 号 → 立刻知道。

  • 找第 N 个：O(1)

  • 找第 N 个：O(n)
  • 中间插入：O(1)

        self.data = data
        self.next = None

# Build: 1 -> 2 -> 3 -> None
node1 = Node(1)
node2 = Node(2)
node3 = Node(3)
node1.next = node2
node2.next = node3

# Walk: print all
current = node1
while current is not None:
    print(current.data, end=' ')
    current = current.next
# 1 2 3

一、动态数组核心（3 分钟）

Python list 内部 = C 数组（连续内存） + 容量管理。

Operation     | Complexity | Why
--------------|--------|----------------------
list[i]       | O(1)   | direct jump
list.append(x)| O(1)*  | capacity enough
list.insert(0)| O(n)   | all shift right
list.pop()    | O(1)   | tail pop
list.remove(x)| O(n)   | find + shift
x in list     | O(n)   | scan one by one

*Amortized O(1) = average O(1), occasionally O(n) (capacity double).

二、容量翻倍策略（5 分钟）

为什么 append 是 O(1) 摊销？

# simplified list implementation
class SimpleList:
    def __init__(self):
        self.capacity = 1
        self.size = 0
        self.data = [None] * self.capacity

    def append(self, x):
        if self.size == self.capacity:
            self._resize()
        self.data[self.size] = x
        self.size += 1

    def _resize(self):
        '''Double capacity when full.'''
        new_capacity = self.capacity * 2
        new_data = [None] * new_capacity
        for i in range(self.size):
            new_data[i] = self.data[i]
        self.data = new_data
        self.capacity = new_capacity

为什么 O(1) 摊销：resize 罕见（按对数频次），平均下来每步 O(1)。

三、示例演算：append 8 次（3 分钟）

步 size capacity 操作
1 1 1 append → fill
2 2 2 append → resize 1→2
3 3 4 append → resize 2→4
4 4 4 append
5 5 8 append → resize 4→8
... ... ... ...

resize 总次数：log₂(8) = 3 次。8 个 append 8 步 + 3 步 resize = 11 步。平均 11/8 ≈ 1.4 步 = O(1) 摊销。

四、深入了解：为什么不用链表（3 分钟）

链表在 Python 里几乎没用：

  • 链表多 2x 内存（每个节点要 2 个指针）
  • 链表 cache 不友好（节点不连续）
  • Python list 已经够用

什么时候用链表：

  • 需要频繁中间插入（数据库 B 树）
  • 大数据（> 10⁹）放不进内存

AI 工程师原则：99% 用 list。

一、核心想法：每次找最小的放前面（3 分钟）

[3, 1, 4, 1, 5, 9, 2, 6]  -> find min: 1 -> swap
[1, 3, 4, 1, 5, 9, 2, 6]  -> find min: 1 -> swap

[1, 1, 2, 3, 4, 5, 6, 9]  DONE

7 步（n-1 = 8-1 = 7）。每步"找最小 + 交换"。

二、Python 代码（5 分钟）

def selection_sort(arr):
    '''Sort arr in place using selection sort.'''
    n = len(arr)
    for i in range(n - 1):           # i is the position to fill
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        if min_idx != i:
            arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr

nums = [3, 1, 4, 1, 5, 9, 2, 6]
print(selection_sort(nums))   # [1, 1, 2, 3, 4, 5, 6, 9]

|-- frequent random access (arr[i])? -> array (list)
|-- frequent head insert/delete? -> double-ended queue (deque)
|-- frequent middle insert/delete? -> doubly linked list (deque)
|-- key-value pair? -> dict
|-- no duplicates? -> set
|-- immutable seq? -> tuple
|-- heavy numeric? -> numpy array

二、Python 代码（5 分钟）

def pick_data_structure(operation, n):
    '''Pick best data structure based on operation.'''
    if operation == 'random_access':
        if n < 1000:
            return 'list (O(1) access)'
        return 'list (still O(1), cache friendly)'
    elif operation == 'head_insert':
        if n < 100:
            return 'list (small N)'
        return 'deque (O(1) head insert)'
    elif operation == 'search_by_key':
        return 'dict (O(1) lookup)'
    elif operation == 'unique':
        return 'set (O(1) membership)'
    elif operation == 'immutable':
        return 'tuple (immutable, hashable)'
    elif operation == 'numeric':
        return 'numpy array (vectorized)'
    else:
        return 'list (default)'

二、选择排序（10 分钟）

def selection_sort(arr):
    '''In-place selection sort.'''
    arr = list(arr)   # don't modify original
    n = len(arr)
    for i in range(n - 1):
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        if min_idx != i:
            arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr

三、内置排序（5 分钟）

def builtin_sort(arr):
    '''Use Python built-in sort (Timsort).'''
    return sorted(arr)

四、跑比赛（15 分钟）

import time
import random

def time_sort(fn, arr):
    start = time.time()
    fn(arr)
    return time.time() - start

print(f'{"N":>6s} {"selection":>12s} {"builtin":>12s} {"ratio":>8s}')
for n in [100, 500, 1000, 2000, 5000]:
    data = [random.randint(0, 1000000) for _ in range(n)]
    s = time_sort(selection_sort, data)
    b = time_sort(builtin_sort, data)
    print(f'{n:6d} {s:12.4f}s {b:12.4f}s {s/b:8.0f}x')

五、深入了解：Timsort 为什么快（3 分钟）

Timsort = 归并排序 + 插入排序混合（2002 年 Tim Peters 为 Python 发明）。

优势：

  1. 自适应：检测"已排好序"段（run）
  2. 稳定：相等元素保持原顺序
  3. C 实现 + 高度优化
  4. 最坏 O(N log N)
