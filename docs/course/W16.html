三、函数小传单（3 分钟）

每个函数写一行「小传单」，S3 动工时照单开工：

def list_all(codex):
    """打印所有宠物的一行摘要"""

def add_pet(codex):
    """问名字和属性，安检后加进 codex"""

def show_pet(codex):
    """问名字，打印该宠物全部档案"""

三引号字符串叫 docstring——函数说明书，写在 def 第一行。现在只需写名字 + 一句说明，身体 S3 再填。

def list_all(codex):

每日节奏（v1.9）： 本篇纯阅读 ≈11 分钟，读完做当天作业 ≈10 分钟，总共 ≤25 分钟 不需要 Thonny——正文一个字都不用敲，作业时间才开编辑器 难度：⭐⭐⭐ · 本篇对应原 W07-L03~W08 的「逐块 + 测试」节奏（毕业周复用）

一、概念：搬家式的写法（2 分钟）

昨天骨架通电 + 第一块完工。今天接着搬剩下 2-3 块，节奏是铁打的四步循环：

填一块 → 运行 → 测一条路 → 再下一块

每块功能就这四步，块与块之间绝不连写。听起来慢——实际最快：报错永远只出在刚写的那块，两分钟定位；连写三块再测，报错藏在三块里翻半天。

二、示例：add_pet 这块怎么搬（5 分钟）

以图鉴 v2 的「加宠物」为例（你的项目对应你的功能）：

def add_pet(codex):
    """问名字和属性，安检后加进 codex"""
    name = input("Pet name: ").strip()
    if name == "":
        print("Name cannot be empty")
        return
    if name in codex:
        print(f"{name} already exists")
        return
    species = input("Species: ").strip()
    codex[name] = {"species": species, "skills": []}
    print(f"Added {name}!")

三层安检全是老朋友叠罗汉：空名检查——直接回车想混进来？拦住；重名检查——in codex 防整宠覆盖（W10-S5 的坑）；空技能列表先立着——数据结构一次到位，之后 add_skill 直接往里 append。

三、示例：show_pet 接着搬（3 分钟）

def show_pet(codex):
    """打印指定宠物全部档案"""
    name = input("Pet name: ").strip()
    if name not in codex:
        print(f"{name} not in codex")
        return
    pet = codex[name]
    print(f"=== {name} ({pet['species']}) ===")
    print(f"Skills: {', '.join(pet['skills']) or 'none'}")

or 'none' 小技巧：空列表 join 出空串，空串 or 'none' 取后者，屏幕显示 Skills: none 不干瞪眼——玩家感大不同。

别忘了把新函数接进菜单：菜单加一行 3. Show pet，while 里加 elif choice == "3": show_pet(codex)。功能做完不接菜单 = 搬了家具没开门。

四、卡住了怎么办（1 分钟）

逐块写一定会撞报错，三步自救（W12 毕业标准之一就是「报错自己修」）：读报错最后一行（错误类型 + 原因）→ 看报错行号（先怀疑刚写的那块）→ 印不出就 print（变量前后各 print 一次）。三步无解再求助 mentor——带上报错原文 + 你猜的原因。会猜错也比不猜强。

今日口诀： 填一块测一块、安检叠罗汉、功能必须接菜单。

一、程序一关，数据就没了？（3 分钟）

你的游戏、图鉴、对战记录——全住在内存里。程序一关，内存清空，一切归零。让数据活过关机的办法：写进文件。

scores = {"paw": 3, "win": 2}
file = open("save.txt", "w", encoding="utf-8")
file.write(str(scores))
file.close()
print("Saved!")

三步曲：open（开文件，"w" = 写模式）→ write（写入）→ close（关门）。忘了 close，数据可能还悬在半路——养成三步连写的肌肉记忆。

二、读回来：load（4 分钟）

file = open("save.txt", "r", encoding="utf-8")
text = file.read()
file.close()
print(text)

"r" = 读模式。读回来的永远是字符串——'{"paw": 3}' 长得像字典，其实是文本。要用 eval？新手期先不碰，直接把它当「存档展示」用就够了：游戏开场 print 出上次的战绩，仪式感拉满。

三、存什么、何时存（3 分钟）

设计你的存档点：

  • 存什么：玩家名、最高分、图鉴收集进度——「值得跨局记住的」
  • 何时存：一局结束、打败 Boss、退出前——「自然的停靠点」
  • 格式：一行一个 名字:值，或整个字典 str 存——新手期怎么简单怎么来

今日口诀： open、write、close 三连；读回是文本，别当字典用。
