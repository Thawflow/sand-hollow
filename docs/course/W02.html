一、概念：数据也有"种族"（3 分钟）

世界上的东西分种族：猫是猫、狗是狗。Python 世界的数据也分类型（type），最常用的三兄弟：

名字 装什么 例子
int 整数 42、2026、-3
float 小数 3.14、0.5、-1.0
str 文字（字符串） "ThawPaw"、"2026"（注意带引号！）

大坑预告： "2026" 和 2026 长得像双胞胎，其实是两个种族——一个 str 一个 int。这一周我们会反复跟这个坑作斗争。

二、type()：类型透视镜（4 分钟）

想知道一个数据是什么种族？用 type() 照一照：

type(2026)      # <class 'int'>    整数
type("2026")    # <class 'str'>    字符串（有引号）
type(3.14)      # <class 'float'>  小数
type("ThawPaw") # <class 'str'>

透视镜三大发现（先记住，作业会用到）：

  1. 引号是种族标志——有引号 = str，没引号 = 数字（int 或 float）
  2. 有没有小数点是 int 和 float 的分界线
  3. input() 收到的东西永远是 str——哪怕你输入的是数字！
age = input("你几岁？")
# 你输入 11，但 age 里装的是 "11"（字符串！）

这就是为什么 W01 的计算器要用 int(input(...))——先拿文字，再转成数字。

三、转换三兄弟：int() / float() / str()（5 分钟）

三兄弟可以互相转换（变身术）：

int("2026") + 1     # 2027 —— str 变 int，能做数学了
float("3.5") * 2    # 7.0 —— str 变 float
str(11) + " years"  # "11 years" —— int 变 str，能拼接了

转换翻车现场（读一遍就懂，不用跑）：

  • int("3.5") → ❌ ValueError：int 不收带小数点的字符串（要找 float）
  • int("你好") → ❌ ValueError：变不成数字
  • "10" * 3 → 101010（不是 30！）：字符串乘法是复读机

今日口诀： 要变数字找 int/float，要拼文字先 str，input 进来全是 str。

"ThawPaw" 想象成一条项链，每个字符是一颗珠子：

二、四招基本功（6 分钟）

name = "ThawPaw"

len(name)          # 7      —— 数珠子（长度）
name.upper()       # THAWPAW —— 全变大写
name.lower()       # thawpaw —— 全变小写

四招都是项链自带技能（专业说法叫「方法 method」）：数据.技能() 的句式——name.upper() 读作「name，变大声！」😼

一、索引：取单颗珠子（4 分钟）

name = "ThawPaw"

name[0]    # "T" —— 0 号珠子（第一颗！）
name[1]    # "h"
name[6]    # "w" —— 最后一颗

负数索引 = 从右往倒数：

name[-1]   # "w" —— 最后一颗
name[-2]   # "a" —— 倒数第二

[-1] 取最后一个，超常用，记住它。

二、切片：剪一段珠子（6 分钟）

name = "ThawPaw"

name[0:4]    # "Thaw" —— 取 0 到 3 号（4 号不算！）
name[4:]     # "Paw"  —— 从 4 号取到结尾
name[:3]     # "Tha"  —— 从头取到 2 号
name[-3:]    # "Paw"  —— 最后三颗

规则一句话： 起点:终点，含头不含尾（终点那颗不算）。这个规则全世界程序员都背过——今天你也是了。

为什么编号从 0 开始？ 因为 name[0:4] 的长度正好是 4-0=4 颗。从 0 开始，减法就是长度——这是设计者的私心 😼

一、拼接到底哪里痛（3 分钟）

W01 你用过 + 拼字符串：

print("认识你太开心了，" + name + "！")
print(name + " 喜欢 " + food + "，还爱玩 " + game + "。")

痛在三点：引号多到眼花、数字必须 str() 转一圈、忘了转就 TypeError（翻车现场见 S2）。

二、f-string 三步上手法（5 分钟）

引号前加个 f，花括号里直接放变量：

print(f"认识你太开心了，{name}！")
print(f"{name} 喜欢 {food}，还爱玩 {game}。")

三步：① 引号前写 f ② 要填空的地方写 {} ③ 花括号里放变量名。完事。

三、花括号 = 小型计算器（5 分钟）

花括号里不止能放变量，还能直接写算式：

a = 10
b = 3
print(f"{a} + {b} = {a + b}")       # 10 + 3 = 13
print(f"{a} 除以 {b} 约等于 {a / b:.2f}")   # 10 除以 3 约等于 3.33

{a + b} 会先算好再填进去。: .2f 是「保留两位小数」——账单神器。

这正是它的杀手锏：以前的写法要 str(a) + " + " + str(b) + " = " + str(a+b)，现在一行全包。

四、格式化魔法速览（2 分钟）

f"{3.14159:.1f}"    # "3.1"     —— 一位小数
f"{0.25:.0%}"       # "25%"     —— 百分比
f"{1234567:,}"      # "1,234,567" —— 千分位

今天作业用不到，但知道它们存在——将来做成绩单/账单时回来抄。

五、什么时候不用 f-string

  • 打印一个单独的变量：print(name) 就行，不必 print(f"{name}")
  • 拼接超长的纯文字（没变量）：普通字符串即可

口诀： 有变量/算式要填 → f-string；没有 → 普通引号。

二、项目 A：名字实验室（25 分钟）

📁 项目存 ~/sand-hollow/<你的学员ID>/homework/（与平日练习同目录，平铺不建周子目录）。

新建 name_lab.py。目标：用户输入姓和名，实验室把这个名字玩出花。

要求打印 6 行报告：

  1. 完整姓名（姓 + 名 拼接）
  2. 大写喊名（英文变大写；中文原样——没大小写）
  3. 名字长度（len）
  4. 名字首字（索引 [0]）
  5. 姓氏打星：完整姓名里把姓氏替换成 *（replace）
  6. 侦探判断：名字里是否含字母 a（in，输出 True / False）

最后再用 f-string 打一行居中的汇报卡（:^20）。

提示三条：

  • 先把 姓、名 装进两个变量，完整姓名 = 两个变量拼接，存第三个变量
  • 判断含 a 前，先 lower() 统一大小写（不然大写 A 会漏网）
  • 中文姓名照样能玩：长度、首字、替换、侦探全有效

参考代码（先自己写，卡住 10 分钟以上再看）：

family = input("Your family name? ")
given = input("Your given name? ")

full = family + given

print("Full name:", full)
print("SHOUT it out:", full.upper())
print("Name length:", len(full))
print("First letter:", full[0])
print("Family name starred:", full.replace(family, "*"))
print("Contains letter a:", "a" in full.lower())

title = "Name Lab Report Complete"
print(f"{title:^20}")

常见翻车点：

  • replace(family, "*") 换的是所有匹配到的姓氏——如果名字里恰好也有同字，会一起变星，正常现象
  • 中文字符也按 1 个字符计，汇报卡嫌窄就把 :^20 调成 :^30

玩性彩蛋（选玩）： 切片还能倒着切——full[::-1] 得到倒着念的名字，超纲招式，照抄体验一下就行，原理 W06 讲列表时回头见。

三、项目 B：单价订单计算器（20 分钟）

新建 order.py。这是 W01 计算器的进化版：一张像样的小票。

要求：

  1. 问两样商品：各问商品名、单价（float）、数量（int），共 6 个 input
  2. 每样一行明细：f-string + :.2f
  3. 合计一行：两样小计相加，用 :, 和 :.2f
  4. 问实付金额，最后打印找零一行

目标小票长相（数值自定）：

=== Family Corner Store ===
Cat food x 3 = 118.50 yuan
Cat treats x 10 = 45.00 yuan
Total: 163.50 yuan
Paid 200 yuan, change: 36.50 yuan

提示三条：

  • 明细行参考：print(f"{n1} x {c1} = {p1 * c1:.2f} yuan")
  • 合计 = 两个「单价 × 数量」相加，再进 f-string
  • 想看千位分隔出场，就把某样单价输大点（比如猫抓板 199 元，买 100 个）——数字越大，, 越好看
  • 实付不够时会打出负数找零——现在先不管，W03 学了 if 就能拦住它（好伏笔）
