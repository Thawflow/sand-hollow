一、for 的短板：不知道跑几次（3 分钟）

for 很棒，但有个前提：先知道跑几次。

场景 适合 for？
数 1 到 10 ✅ for i in range(1, 11)
画 9 行星星 ✅ for i in range(9)
猜数字猜到猜对为止 ❌ 谁知道要几次！

第三种「不知道几次」的活儿，交给今天的主角：while 循环 =「只要条件还成立，就一直跑」。什么时候停？看条件什么时候变假。

二、while 的样子（4 分钟）

看这段代码（今天只看不敲）：

n = 1
while n <= 5:
    print(n)
    n = n + 1
print("Done!")

运行打印 1 2 3 4 5，最后来一句 Done!。

部件 作用
n = 1 起手值
while n <= 5: 条件：成立就继续转
print(n) 手下活儿
n = n + 1 关键：让 n 长大，条件才会变假
print("Done!") 循环结束后才轮到它

跟 if 对比一下：if 问一次就完，while 问完接着再问，问到条件变假才放行后面的代码。

三、初见死循环（3 分钟）

把 n = n + 1 那行删掉会怎样？n 永远是 1，n <= 5 永远成立——程序永远打印 1，停不下来。这叫死循环。

死循环不可怕（明天教你三件套防它 + Ctrl + C 急停），今天先记住灵魂点：循环体里必须有让条件慢慢变假的动作。

今日口诀： while 看条件，条件假了才撒手；想让它撒手，就得喂它一个会变的条件。

W05-S2 · 条件更新：最常见的坑

每日节奏（v1.9）： 本篇纯阅读 ≈11 分钟，读完做当天作业 ≈10 分钟，总共 ≤25 分钟 不需要 Thonny——正文零打码，作业时间才开编辑器 难度：⭐⭐ · 本篇是原 W05-L01 的后半（死循环解剖 + 三件套 + 两大坑 + 实用 while）

一、死循环解剖（4 分钟）

昨天的死循环再看一眼：

n = 1
while n <= 5:
    print(n)
    # 忘了写 n += 1

程序疯狂打印 1 停不下来。急救键：Ctrl + C（Mac 也是它）强制停止。

病根只有一个：循环里没有任何动作让条件走向失败。条件永远真，循环永远转——就像猫追自己尾巴，永远差一口。

二、避免死循环三件套（3 分钟）

写 while 前自查三件事：

  1. 起手值有：循环变量先给起手（n = 1）
  2. 条件会变：循环体里有让条件慢慢变假的步骤（n += 1）
  3. 测试有上限：写完先跑 5 秒，看会不会自己停

三件套缺一件，程序就可能变成永动机。

三、另外两个坑（2 分钟）

坑①：条件一开始就是假。 n = 5 却写 while n < 0: → 一次都不跑。这不是 bug——while 跑 0 次也合法，别慌。

坑②：= 与 == 老朋友。

while guess = password:   # ❌ SyntaxError！

比较永远用两个等号 ==——W03 踩过一次，这里再踩一次更牢。

四、while 干正事：密码门卫（2 分钟）

password = "tiger"
guess = input("Password: ")
while guess != password:
    print("Wrong, try again")
    guess = input("Password: ")
print("Welcome!")

看懂了吗？guess 在循环里被重新赋值——这就是「条件更新」的活样例：错就一直问，对了条件变假，Welcome 登场。

今日口诀： 起手值、条件、更新，三件套防死循环；Ctrl + C 是最后的急停闸。

  • 我知道条件一开始为假时，while 一次都不跑（合法）
  • 我能看懂密码门卫：guess 在循环里更新，条件才会变假

W05-S3 · break：喊停的艺术

每日节奏（v1.9）： 本篇纯阅读 ≈12 分钟，读完做当天作业 ≈10 分钟，总共 ≤25 分钟 不需要 Thonny——正文零打码，作业时间才开编辑器 难度：⭐⭐ · 本篇是原 W05-L02 的精华（break / continue / while...else）

一、概念：条件还没失败，我就要停（2 分钟）

while 老老实实看条件。但有时候：密码对了何必再问？找到目标了何必再翻？

break = 喊停——立刻跳出循环，不管条件还成不成立。

二、break：立刻跳出（4 分钟）

for i in range(1, 11):
    if i == 6:
        print("Found 6, stop!")
        break
    print(i)

运行：1 2 3 4 5，然后 "Found 6, stop!"——6 没打印，7-10 全跳过。break 是循环的紧急出口，只跳出所在的那一层循环。

缩进警报： break 必须缩进在 if 手下。忘了缩进 → 第一轮就 break，循环一次活儿都没干。

三、continue：跳过这一轮（3 分钟）

跟 break 相反——continue = 这轮不玩了，下一轮继续：

for i in range(1, 11):
    if i == 6:
        continue
    print(i)

打印 1-10 但唯独没有 6。口诀：break 是全退，continue 是轮休。

四、while...else：没被 break 才执行（3 分钟）

password = "tiger"
tries = 0
while tries < 3:
    guess = input("Password: ")
    if guess == password:
        print("Welcome!")
        break
    tries += 1
    print(f"Wrong! {3 - tries} tries left")
else:
    print("Account locked")

这个 else 属于 while 不是 if：循环正常走完（没被 break）才执行它 → 三次全错，锁号。Python 独家语法，初见觉得怪，混个脸熟就好。

今日口诀： break 全退，continue 轮休；while 的 else，没被 break 才兑现。

  • 我知道 break 缩进错了会发生什么（第一轮就跑）
  • 我知道 while...else 是「没被 break 才执行」

一、为什么要限次数（2 分钟）

基础版可以无限猜——1 到 100 猜 100 次总能蒙中，游戏没了紧张感。真实游戏都有规则：限 5 次，猜不中就揭底。

二、第二版：限 5 次（4 分钟）

secret = random.randint(1, 100)
guess = 0
tries = 0
max_tries = 5

while guess != secret and tries < max_tries:
    guess = int(input(f"Tries {tries+1}/{max_tries} - guess: "))
    tries += 1
    if guess > secret:
        print("Too high!")
    elif guess < secret:
        print("Too low!")
    else:
        print(f"Correct! You got it in {tries} tries")
        break
else:
    if guess != secret:
        print(f"Game over! The answer was {secret}")

关键改动三条：条件用 and 组了两个维度（W03-S5 老朋友）；tries += 1 每轮记账；else 揭底——没被 break（5 次用完还没中）才执行。

三、第三版：再来一局（4 分钟）

外层再套一个 while，管「玩不玩下一局」：

play_again = "yes"
while play_again == "yes":
    secret = random.randint(1, 100)
    guess = 0
    tries = 0
    while guess != secret and tries < 5:
        # 内层跟第二版一模一样，整段搬进来
        pass
    play_again = input("Play again? (yes/no): ")
print("Thanks for playing!")

两个要点：嵌套循环（W04 学的内层外层，今天实战）；每局重置——secret / guess / tries 必须在外层循环里重新赋值，不然第二局带着上一局的旧账开打，直接翻车。

坑：else 缩进。 while 的 else 要跟 while 对齐，不是跟里面的 if 对齐——错了的现象是「猜对了也揭底」。

二、项目 A：完整计分版（30 分钟）

📁 项目存 ~/sand-hollow/<你的学员ID>/homework/，新建 guess_pro.py。

需求：

  • 电脑从 1-100 随机想一个数
  • 玩家最多猜 7 次
  • 猜中得分：100 - 10 * tries（最少 30 分）
  • 多局累加总分
  • 玩家可随时输入 quit 退出（中途退不算分）

参考实现：

import random

print("=== Pro Number Guess ===")

total_score = 0
games_played = 0

while True:
    secret = random.randint(1, 100)
    guess = None
    tries = 0
    max_tries = 7
    won = False

    while tries < max_tries:
        guess_raw = input(f"\nGame {games_played + 1} · Try {tries + 1}/{max_tries}: ")
        if guess_raw == "quit":
            break
        guess = int(guess_raw)
        tries += 1

        if guess > secret:
            print("Too high!")
        elif guess < secret:
            print("Too low!")
        else:
            score = max(30, 100 - 10 * tries)
            total_score += score
            won = True
            print(f"Correct in {tries} tries! +{score} points")
            break

    if not won and guess_raw != "quit":
        print(f"Out of tries. Answer: {secret}")

    if guess_raw == "quit":
        print(f"\nFinal score: {total_score} points in {games_played} games")
        break

    games_played += 1
    print(f"Total so far: {total_score} points")

    play = input("Play again? (yes/no): ")
    if play != "yes":
        print(f"\nFinal score: {total_score} points in {games_played} games")
        break

拆解

  • 三层循环：外层 while True（多局）、内层 while tries < max_tries（每局猜）、外层嵌套 play 询问
  • guess_raw == "quit"：两种「退出」要分清——一是「猜够 7 次」、二是「中途 quit」
  • won = True / False：内层循环退出后判断「赢了吗」，避免揭底谜语被误打
  • 计分公式：100 - 10 * tries，最少 30 分（猜 7 次还给 30 分安慰奖）

需求：每次游戏结束，结果追加写入 leaderboard.txt，读取历史前 5 名：

# Append result

print("\n=== Leaderboard ===")
with open("leaderboard.txt") as f:
    scores = []
    for line in f:
        parts = line.strip().split(",")
        scores.append((int(parts[1]), parts[0], parts[2]))
    scores.sort(reverse=True)
    for i, (s, g, t) in enumerate(scores[:5]):
        print(f"{i+1}. Game {g}: {s} points in {t} tries")

关键点

  • tuple 排序：scores.sort(reverse=True) 默认按 tuple 第一个元素排
