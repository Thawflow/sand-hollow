一、一个名字管一堆东西（4 分钟）

到目前为止，一个变量只能管一个东西：

name = "Kitty"
score = 95

但现实经常是「一堆」：班级 30 个学生、购物车 10 件商品、玩家背包 100 个道具——难道写 100 个变量？

列表（list）= 一个变量管一堆数据。 方括号包住、逗号隔开：

nums = [3, 1, 4, 1, 5, 9, 2, 6]
fruits = ["apple", "banana", "cherry"]
print(len(nums))

len(nums) 是 8——列表长度，有几个元素。

二、索引：从 0 开始数（4 分钟）

想拿列表里的某一个，用方括号 + 编号（索引）：

fruits = ["apple", "banana", "cherry"]
print(fruits[0])
print(fruits[1])
print(fruits[-1])

打印 apple / banana / cherry。规矩两条：

  • [0] 是第 1 个——Python 从 0 开始数，新手最容易懵的地方
  • 负数从尾巴数——[-1] 是最后一个，[-2] 倒数第二

三、越界会怎样（2 分钟）

列表只有 3 个水果，却写：

print(fruits[10])   # ❌ IndexError: list index out of range

报错： IndexError: list index out of range——门牌号不存在。3 个元素的合法门牌是 0、1、2，别越界敲门。

今日口诀： 方括号包一堆，从 0 开始数门牌；-1 是压尾，越界 IndexError。

二、append：排队加尾巴（4 分钟）

pets = ["cat", "dog"]
print("Start:", pets)

pets.append("rabbit")
print("After append:", pets)

pets.append("hamster")
print("After append 2:", pets)

运行：

Start: ['cat', 'dog']
After append: ['cat', 'dog', 'rabbit']
After append 2: ['cat', 'dog', 'rabbit', 'hamster']

append(x) 把 x 加到末尾——像排队，新来的站最后。

三、insert：插队（3 分钟）

pets.insert(1, "fish")
print("After insert at 1:", pets)
# ['cat', 'fish', 'dog', 'rabbit', 'hamster']

insert(i, x) 把 x 插到第 i 个位置，原来的元素往后挤一位——fish 插队站到 1 号位，dog 它们全体后移。

记忆：append 排尾巴，insert 会插队。

注意： append() 括号里必须传东西，忘了传会加进去一个空空如也的 None——列表看着没事，其实埋雷。

W07-S3 · 删与改：remove 与改值

每日节奏（v1.9）： 本篇纯阅读 ≈11 分钟，读完做当天作业 ≈10 分钟，总共 ≤25 分钟 不需要 Thonny——正文零打码，作业时间才开编辑器 难度：⭐⭐ · 本篇是原 W06-L02 的后半（remove / pop / clear + 索引改值）

一、remove：按值删第一个（4 分钟）

todos = ["homework", "gaming", "homework", "sleep"]
todos.remove("homework")
print(todos)     # ['gaming', 'homework', 'sleep']

remove(x) 删掉第一个等于 x 的元素——后面还有个 homework？它只删一个，剩下的不动。

大坑： 删一个不存在的值：

todos.remove("unicorn")   # ❌ ValueError: list.remove(x): x not in list

报错： ValueError。防御姿势——先 in 检查再删（if "x" in list 才 remove）。

二、pop 与 clear：按位置删、一锅端（4 分钟）

snacks = ["chip", "candy", "cookie", "juice"]
done = snacks.pop(1)
print(done, snacks)     # candy ['chip', 'cookie', 'juice']
snacks.pop()
print(snacks)           # ['chip', 'cookie']
  • pop(i)：删第 i 个，而且把它交还给你（可以接住用）
  • pop()：不写 i，删最后一个
  • clear()：全部清空，变 []

记忆：remove 按值删第一个，pop 按位置删还退货，clear 一锅端。

三、改：索引赋值（3 分钟）

scores = [85, 92, 78]
scores[1] = 95
print(scores)    # [85, 95, 78]

改 = 选中位置 = 赋值，一行搞定。老规矩：门牌号不能越界，改 [10] 照样 IndexError。

今日口诀： remove 认值，pop 认位置还退货；改值最简单，门牌号加等号。

W07-S4 · 遍历：for 的老朋友新用法

每日节奏（v1.9）： 本篇纯阅读 ≈11 分钟，读完做当天作业 ≈10 分钟，总共 ≤25 分钟 不需要 Thonny——正文零打码，作业时间才开编辑器 难度：⭐⭐ · 本篇是原 W06-L01 的后半（for 遍历列表 + enumerate）

一、for 直接拿元素（4 分钟）

W04 的 for 循环，最常见用法就是「把列表每个元素过一遍」（遍历）：

fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print("I like", fruit)

运行：I like apple / banana / cherry 各一行。

跟老写法对比——for i in range(3): 拿的是索引 0/1/2，还得再 fruits[i] 取货；for fruit in fruits: 直接拿元素，省一步，更地道。

起名小课： 循环变量叫 fruit 比 i 清楚十倍——名字即注释。

二、遍历做点有用的（4 分钟）

classmates = ["Alice", "Bob", "Charlie", "Diana"]
print("Class size:", len(classmates))
for name in classmates:
    print(f"- {name}")

len 数人数，for 打名单——这两招合起来就是「花名册打印器」。上周的 while 也能遍历，但 for 天生干这个，能 for 就 for。

三、enumerate：顺手带上门牌号（3 分钟）

想打印「Day 1: xxx」这种带编号的？enumerate 把门牌号和元素一起给你：

plans = ["drawing", "sports", "coding"]
for i, plan in enumerate(plans):
    print(f"Day {i+1}: {plan}")

i 是 0/1/2，加 1 变成 Day 1/2/3。两个变量用逗号接——i 接门牌，plan 接货。

今日口诀： for x in 列表，元素直接拿；要编号，找 enumerate。

W07-S5 · 统计四件套：max / min / sum / 平均

每日节奏（v1.9）： 本篇纯阅读 ≈11 分钟，读完做当天作业 ≈10 分钟，总共 ≤25 分钟 不需要 Thonny——正文零打码，作业时间才开编辑器 难度：⭐⭐⭐ · 本篇是原 W06-L03 的精华（统计 built-in + 过滤两板斧）

一、累加器复习：求和 + 平均（3 分钟）

W04 学的累加器，套上列表就是日常 80% 的数据处理：

scores = [85, 92, 78, 95, 88]
total = 0
for s in scores:
    total += s
print(f"Total: {total}, Average: {total / len(scores):.1f}")

二、built-in 三兄弟：直接抄近道（4 分钟）

上面的循环是教学版——实战直接用 Python 自带的（不用 import）：

nums = [12, 45, 7, 23, 56, 89, 34]
print(max(nums))
print(min(nums))
print(sum(nums))

89 / 7 / 266。max 最大、min 最小、sum 求和；平均没有自带，sum(nums) / len(nums) 一行拼出来。

两个雷： sum 只对数字列表——sum(["1", "2"]) 直接 TypeError；空列表问 max 报 ValueError。

三、过滤两板斧：计数 + 存新列表（4 分钟）

板斧一：数有几个达标的（循环 + if + 计数器）：

scores = [85, 92, 78, 95, 88, 90, 76, 91, 84, 89]
excellent = 0
for s in scores:
    if s >= 90:
        excellent += 1
print(f"Excellent: {excellent}")

板斧二：把达标的捞进新列表（循环 + if + append）：

excellent = []
for s in scores:
    if s >= 90:

二、项目 A：基础购物清单（25 分钟）

📁 项目存 ~/sand-hollow/<你的学员ID>/homework/，新建 shopping_list.py。

需求：

  • 空列表起步
  • 菜单循环：add / list / remove / quit
  • add：input 物品名，append 到列表
  • list：打印所有物品（带编号）
  • remove：input 物品名，remove 第一个匹配
  • quit：退出

参考实现：

print("=== Shopping List ===")

items = []

while True:
    action = input("\n(add/list/remove/quit): ").strip()

    if action == "add":
        name = input("Item name: ").strip()
        items.append(name)
        print(f"Added '{name}'")
    elif action == "list":
        if not items:
            print("List is empty")
        else:
            for i, item in enumerate(items):
                print(f"{i+1}. {item}")
    elif action == "remove":
        name = input("Item to remove: ").strip()
        if name in items:
            items.remove(name)
            print(f"Removed '{name}'")
        else:
            print(f"'{name}' not in list")
    elif action == "quit":
        print(f"\nFinal list ({len(items)} items):")
        for i, item in enumerate(items):
            print(f"{i+1}. {item}")
        break
    else:
        print("Unknown action, try again")

拆解

  • .strip()：去掉输入前后的空格（防止 "add " 输入被误判）
  • enumerate(items)：自动编号（i 从 0 开始，加 1 变 1-N）
  • 三层 if / elif / else：动作分发
  • if not items:：空列表判定（空 = falsy）

三、项目 B：价格 + 总价（25 分钟）

📁 同目录新建 shopping_with_prices.py。

需求：在 A 基础上，每个物品有「名字 + 价格」，最后打印总价。

参考实现：

print("=== Shopping List with Prices ===")

items = []  # Each item: [name, price]

while True:
    action = input("\n(add/list/remove/total/quit): ").strip()

    if action == "add":
        name = input("Item name: ").strip()
        price = float(input("Price: "))
        items.append([name, price])
        print(f"Added '{name}' at {price}")
    elif action == "list":
        if not items:
            print("List is empty")
        else:
            for i, (name, price) in enumerate(items):
                print(f"{i+1}. {name} - ${price:.2f}")
    elif action == "remove":
        idx = int(input("Item number to remove: ")) - 1
        if 0 <= idx < len(items):
            removed = items.pop(idx)
            print(f"Removed '{removed[0]}'")
        else:
            print("Invalid number")
    elif action == "total":
        total = sum(price for name, price in items)
        print(f"Total: ${total:.2f}")
    elif action == "quit":
        break
    else:
        print("Unknown action")

关键技巧

  • 嵌套列表 [[name, price], ...]：每个 item 是两元素列表
  • for i, (name, price) in enumerate(items):：元组拆包，直接拿到名字和价格
  • sum(price for name, price in items)：生成器 + sum，按价格累加
  • float(input("Price: "))：输入转浮点数（W02-L01 学的）
