一、列表的痛点（3 分钟）

W06 的列表用编号找东西：prey[0]、prey[2]。编号好使，但有痛点——

记住「猫武士档案里第 3 项是皮毛颜色」太难了。人类的记法是用名字：「皮毛颜色是什么？」「cat["color"]」。

字典（dict）= 名字 → 东西 的映射表，像查电话簿：翻到名字，直接拿到号码。W07 冒险岛你其实偷偷用过它存玩家状态，今天正式拜师。

二、字典的长相（4 分钟）

cat = {
    "name": "Whiskers",
    "age": 3,
    "color": "tabby",
    "is_indoor": True,
}

print(cat["name"])        # Whiskers
print(cat["age"])         # 3
print(cat["color"])       # tabby

逐字拆解：

部件 作用
{ } 花括号包住整个字典（列表是方括号 [ ]）
"name": "Whiskers" 一对键值对：名字 → 东西
键（key） 「名字」，通常是字符串，要加引号
值（value） 「东西」——字符串、数字、布尔，啥都行
cat["name"] 用键取值：报名字，拿东西

逗号隔开每一对，最后一对后面的逗号可写可不写（写了更方便以后加行）。

三、和列表长得像，规矩不同（2 分钟）

cat["name"] 和 prey[0] 都是方括号取东西——但方括号里装的不一样：

  • 列表：装位置编号（整数，从 0 开始）
  • 字典：装键（名字字符串）

所以 cat[0] 会报错：KeyError: 0——字典里没有叫 0 的键。KeyError 是字典世界的常客，意思是「查无此名」。

四、什么时候用字典（1 分钟）

场景 用谁
一周温度排排坐 列表（位置有意义）
猫档案：名字 / 年龄 / 毛色 字典（名字有意义）
通讯录：人名 → 电话 字典（按名查号）

判断口诀：位置重要用列表，名字重要用字典。

今日口诀： 花括号、冒号配对、键找值——电话簿思维。

一、四件套一次看全（5 分钟）

cat = {"name": "Whiskers", "age": 3}

cat["color"] = "tabby"     # 增：新键赋值
print(cat["name"])         # 查：键取值
cat["age"] = 4             # 改：老键重新赋值
del cat["color"]           # 删：del + 键
print(cat)
动作 写法 一句话
增 cat["color"] = "tabby" 键不存在 → 新添一对
查 cat["name"] 报名字，拿东西
改 cat["age"] = 4 键已存在 → 覆盖旧值
删 del cat["color"] 整对搬走

增和改是同一招：字典[键] = 值——键不存在就是增，存在就是改。Python 自己会看。

二、in：查岗再进门（3 分钟）

查一个不存在的键会 KeyError 摔门。礼貌的做法是先敲门：

contacts = {"Alice": "13800138001", "Bob": "13800138002"}

name = input("Name to look up: ")
if name in contacts:
    print(f"{name}'s number: {contacts[name]}")
else:
    print(f"{name} not in contacts")

in 检查键在不在，返回 True / False（W03 的布尔值又上岗了）。凡是查别人输入的键，先 in 后取——这是字典世界的安检门。

三、小坑两枚（2 分钟）

cat = {"name": "Whiskers", "age": 3}
cat = {}        # ❌ 这是「换了个新空字典」，不是清空原字典

cat = {} 是新建一个空字典贴上旧名字，原来的档案被整个扔掉（想清空原字典用 cat.clear()，混个脸熟）。

另一枚：改值写成 cat = {"age": 4} 以为「只改年龄」——错，这同样是整个换新。改一个键，用 cat["age"] = 4。

四、四件套手感表（1 分钟）

你想 你写

看一项 d["键"]（先 in 检查更稳）

今日口诀： 增改同招看键在不在，查先敲门（in），删用 del。

W13-S3 · 遍历：把字典抖出来

每日节奏（v1.9）： 本篇纯阅读 ≈12 分钟，读完做当天作业 ≈10 分钟，总共 ≤25 分钟 不需要 Thonny——正文一个字都不用敲，作业时间才开编辑器 难度：⭐⭐ · 本篇对应原字典第一课（文件名 W11-L01）的 for 遍历 + f-string 复习

一、for 遍历字典：默认发钥匙（3 分钟）

列表遍历给你元素，字典遍历给你键：

cat = {"name": "Whiskers", "age": 3, "color": "tabby"}

for key in cat:
    print(key)

输出三行：name、age、color——只发钥匙（键），不发东西。想要值？拿钥匙再开一次门：cat[key]。

二、键值一起拿（4 分钟）

f-string（W02 老朋友）和循环合体，档案表一行行打出来：

for key in cat:
    print(f"{key} -> {cat[key]}")

输出：

name -> Whiskers
age -> 3
color -> tabby

套路拆解：

  • for key in cat: → 钥匙一把把轮流传
  • cat[key] → 拿当前钥匙开当前门（key 是变量，不加引号）
  • f"{key} -> {cat[key]}" → 一行排版，箭头看着清爽

高频小坑： cat["key"]（手滑加引号）→ 找叫 "key" 的键 → KeyError。引号一加，变量变字符串——W02 的种族铁律又来了。

三、实战：全班点名器（4 分钟）

字典 + 遍历 + 判断（W03），三周武功合体：

scores = {"Alice": 92, "Bob": 78, "Cathy": 85}

for name in scores:
    score = scores[name]
    if score >= 90:
        mark = "A"
    elif score >= 80:
        mark = "B"
    else:
        mark = "C"
    print(f"{name}: {score} -> {mark}")

输出三行成绩单，每人自动定级。看懂这段 = 列表周学的「累加器 + 遍历」思想完整搬进了字典世界：遍历 → 每项加工 → 输出。

四、遍历顺序小知识（1 分钟）

字典不保证按键排序输出（Python 3.7+ 按插入顺序，混个脸熟即可）。要排序输出可以先把键排一遍——现在不用背，知道「顺序不是天生有序」就行。

今日口诀： for 发钥匙，取值靠 cat[key]，f-string 排版好。

每日节奏（v1.9）： 本篇纯阅读 ≈14 分钟，读完做当天作业 ≈10 分钟，总共 ≤25 分钟 不需要 Thonny——正文一个字都不用敲，作业时间才开编辑器 难度：⭐⭐⭐ · 本篇对应原字典第二课（文件名 W11-L02）——数据盖楼篇

一、值可以是任何东西（2 分钟）

S1 说过：值可以是字符串、数字、布尔。其实——值还可以是列表、甚至是另一个字典。

「字典里套字典 / 套列表」叫嵌套。现实数据全是嵌套：游戏角色有名字（字符串）、血量（数字）、背包（列表）、属性面板（字典）——一张档案装下一切。

二、字典套列表：背包（4 分钟）

player = {
    "name": "Paw",
    "hp": 100,
    "inventory": ["sword", "shield", "potion"],
}

print(player["inventory"])         # 整个列表
print(player["inventory"][0])      # sword——先键后索引
player["inventory"].append("key")  # 往背包塞新东西
print(player["inventory"])

两步取值： player["inventory"][0] = 先用键 "inventory" 拿到列表，再用索引 [0] 拿第 1 件——W06 的 append 照常能用，因为拿到的就是列表本尊。

三、字典套字典：属性面板（4 分钟）

cat = {
    "name": "Whiskers",
    "stats": {
        "hp": 50,
        "attack": 12,
        "defense": 5,
    },
}

print(cat["name"])            # Whiskers
print(cat["stats"]["hp"])     # 50——一层层下钻
cat["stats"]["hp"] += 10      # 嵌套改值
print(cat["stats"]["hp"])     # 60

读法像剥洋葱：cat["stats"] 剥出内层字典，["hp"] 再剥出数字。修改也是同一条路——寻址到哪层，就在哪层动手。

四、三层楼：班级花名册（3 分钟）

classes = {
    "Math": [
        {"name": "Alice", "score": 92},
        {"name": "Bob", "score": 78},
    ],
    "English": [
        {"name": "Alice", "score": 88},
    ],
}

for subject in classes:
    for student in classes[subject]:
        print(f"{subject}: {student['name']} got {student['score']}")

结构：外层字典（科目 → 列表）→ 列表（一个个学生）→ 每个学生又是字典。三层楼，每层都是学过的结构——嵌套不发明新东西，只是老朋友叠罗汉。

五、下钻心法（1 分钟）

嵌套读晕了就一层层 print：print(cat["stats"]) 先看内层长啥样，再往下钻。KeyError 套娃（"stat" 少个 s）十有八九靠这招现形。

今日口诀： 键开门、索引拿人、一层一层下钻。

完整代码

import json
import os

CODE_FILE = "pet_codex.json"

def load_codex():
    if os.path.exists(CODE_FILE):
        with open(CODE_FILE) as f:
            return json.load(f)
    return {}

def save_codex(codex):
    with open(CODE_FILE, "w") as f:
        json.dump(codex, f, indent=2)
    print("Saved!")

def show_pet(codex, name):
    if name not in codex:
        print(f"{name} not in codex")
        return
    pet = codex[name]
    print(f"\n=== {name} ===")
    print(f"Species: {pet['species']}")
    stats = pet["stats"]
    print(f"HP: {stats['hp']}  ATK: {stats['attack']}  DEF: {stats['defense']}")
    print(f"Skills: {', '.join(pet['skills']) if pet['skills'] else '(none)'}")

def add_pet(codex, name, species, hp, attack, defense):
    if name in codex:
        print(f"{name} already exists")
        return
    codex[name] = {
        "species": species,
        "stats": {"hp": hp, "attack": attack, "defense": defense},
        "skills": [],
    }
    print(f"Added {name}!")

def add_skill(codex, name, skill):
    if name not in codex:
        print(f"{name} not in codex")
        return
    if skill in codex[name]["skills"]:
        print(f"{name} already knows {skill}")
        return
    codex[name]["skills"].append(skill)
    print(f"{name} learned {skill}!")

def search_by_species(codex, species):
    print(f"\n=== {species}s ===")
    found = False
    for name in codex:
        if codex[name]["species"] == species:
            print(f"- {name}")
            found = True
    if not found:
        print("(none)")

def list_all(codex):
    print("\n=== All Pets ===")
    for name in codex:
        pet = codex[name]
        print(f"- {name} ({pet['species']}): HP {pet['stats']['hp']}")

def main():
    codex = load_codex()

    while True:
        print("\n(show/add/skill/search/list/save/quit)")
        action = input("> ").strip().lower()

        if action == "show":
            name = input("Pet name: ")
            show_pet(codex, name)
        elif action == "add":
            name = input("Name: ")
            species = input("Species: ")
            hp = int(input("HP: "))
            atk = int(input("Attack: "))
            df = int(input("Defense: "))
            add_pet(codex, name, species, hp, atk, df)
        elif action == "skill":
            name = input("Pet name: ")
            skill = input("Skill: ")
            add_skill(codex, name, skill)
        elif action == "search":
            species = input("Species to search: ")
            search_by_species(codex, species)
        elif action == "list":
            list_all(codex)
        elif action == "save":
            save_codex(codex)
        elif action == "quit":
            save_codex(codex)
            break
        else:
            print("Unknown action")

main()
