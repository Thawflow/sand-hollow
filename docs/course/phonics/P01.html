前元音入门：四个符号，四组你认识的词

P01-S1 · 前元音入门：四个符号，四组你认识的词

🔤 英语音标速成课 · 单元 P01 · 第 1 节 · 约 35 分钟

今天学什么

不学发音。你的 sheep、bed、cat 早就是标准英语，比很多大人准。

今天只做一件事：给四个前元音符号 /iː/ /ɪ/ /e/ /æ/ 贴词签。

符号 你早就认识的词 中文
/iː/ see eat green sheep 看见 / 吃 / 绿色的 / 绵羊
/ɪ/ sit big fish milk 坐 / 大的 / 鱼 / 牛奶
/e/ bed red ten egg 床 / 红色的 / 十 / 鸡蛋
/æ/ cat bag apple hat 猫 / 包 / 苹果 / 帽子

四个符号，十六个词，全是你会读、会背、知道意思的。 声音你早就有，今天只补名字。

一、你缺的不是声音，是名字

同一个音，书面可以有很多种拼法：sheep 里那个长「衣」写成 ee、ea、ie 都可能；city 里那个短「衣」只能写 i。

拼写有很多答案，音标只有一个答案。你要做的是：听到声音 → 说出它的名字。今天这四个名字叫 /iː/ /ɪ/ /e/ /æ/。

二、四组词签

  • /iː/ —— see eat green sheep：长长的一声「衣——」。
  • /ɪ/ —— sit big fish milk：短短的一声「衣」，几乎没出来就收住。
  • /e/ —— bed red ten egg：短短的一声「欸」。
  • /æ/ —— cat bag apple hat：短的一声「爱」，比 /e/ 更饱满。

前元音四兄弟，顺序固定：/iː/ → /ɪ/ → /e/ → /æ/。

三、拼读对照：左边拼法，右边符号

拼读对照：sheep → sh + ee + p → /ʃ/ + /iː/ + /p/ = /ʃiːp/ 拼读给你「读得出」，IPA 给你「说得准」

拼读对照：bag → b + a + g → /b/ + /æ/ + /g/ = /bæɡ/ 拼读给你「读得出」，IPA 给你「说得准」

看出规律了吗？ 字母 ee 在这里写作 /iː/，字母 a 在这里写作 /æ/。同一个字母在不同词里可以是不同符号——所以别背「字母 → 音」，要背「词 → 音」。

四、反向练：给词写符号

fish / eat / bed / hat / ten / milk / cat / see

逐个写出完整音标，写完念一遍：心里那一声对上你写的符号，就对了。

五、今天要练的

  1. 抄一遍词卡（纸笔）：四个符号，每个配三个你认识的词。
  2. 反向练：上面八个词逐个写出完整音标。
  3. 朗读：十六个词读三遍，每读一个就在脑子里喊它的符号。
  4. 找一找：在课外书里找三个含 /æ/ 的词抄下来。

六、今天不用管的

  • ❌ 不用改你的声音——读法一点都不用动，这节课只记符号。
  • ❌ 不用现在就会分长短（下一节专门打 /iː/ vs /ɪ/）。
  • ❌ 不用管音节划分和重音（P01-S4 才用）。
  • ❌ 不用背中文意思，写出来只是让你确认「我认识这个词」。

✅ 本节完成自查

  • 知道这节课练的是符号，不是声音
  • 四个符号 /iː/ /ɪ/ /e/ /æ/ 各自配出至少 3 个自己认识的词
  • 给 fish eat bed hat 写出完整音标
  • 说得清「同一个字母在不同词里可以是不同符号」
  • 知道前元音四兄弟的顺序 /iː/ → /ɪ/ → /e/ → /æ/
/iː/ vs /ɪ/：两个「衣」怎么分

P01-S2 · /iː/ vs /ɪ/：两个「衣」怎么分

🔤 英语音标速成课 · 单元 P01 · 第 2 节 · 约 35 分钟

今天学什么

同样是「衣」，英语里分两种：长的写作 /iː/，短的写作 /ɪ/。

你已经能分清哪个长哪个短了——今天要练的是看到符号不写错：长音那对两个点，可别漏掉。

符号 你早就认识的词 中文
/iː/ see meet eat green sheep 看见 / 遇见 / 吃 / 绿色的 / 绵羊
/ɪ/ sit big fish milk city 坐 / 大的 / 鱼 / 牛奶 / 城市

一、你早就分得出来了（最小对比）

下面每一对只差一个音，意思完全不同：

左边 音标 中文 右边 音标 中文
eat /iːt/ 吃 it /ɪt/ 它
feel /fiːl/ 感觉 fill /fɪl/ 装满
seat /siːt/ 座位 sit /sɪt/ 坐
sheep /ʃiːp/ 绵羊 ship /ʃɪp/ 轮船

你读这两边的时候差别清清楚楚，说明你的耳朵早就在工作。你要补的只是纸上的那一点：长的多写一个 ː。

二、符号长什么样

  • /iː/ —— i 后面跟两个点 ː（音标里叫长音符号）。写全了才是 /iː/，只写一个 i 是错的。
  • /ɪ/ —— 一个大写形式的小写 i，长得像 ɩ 的「小号」。短音，不带 ː。

所以看到 /iː/ 就知道是长长的那一声，看到 /ɪ/ 就知道是短短的那一声。

三、拼读对照：同样的字母，两种符号

拼读对照：meet → m + ee + t → /m/ + /iː/ + /t/ = /miːt/ 拼读给你「读得出」，IPA 给你「说得准」

拼读对照：city → c + i + t + y → /k/ + /ɪ/ + /t/ + /i/ = /ˈsɪti/ 拼读给你「读得出」，IPA 给你「说得准」

拼读对照：sheep → sh + ee + p → /ʃ/ + /iː/ + /p/ = /ʃiːp/ 拼读给你「读得出」，IPA 给你「说得准」

注意 city 前面的重音点 ˈ：多音节词里，重音落在哪个音节上，前面加一个小撇。city 的重音在第一个音节：/ˈsɪti/。

四、反向练：给词写符号

green / sit / fish / eat / milk / see / big / sheep

八个词里一半是 /iː/，一半是 /ɪ/。写完数一数：长音的两个点，你有没有漏？

五、今天要练的

  1. 抄符号：/iː/ 和 /ɪ/ 各抄 5 遍，重点是那个 ː 一定要写出来。
  2. 配对：从 /siːt/ /sɪt/ /miːt/ /bɪt/ 里给 sit meet seat bit（一点）配对。
  3. 朗读：eat it feel fill seat sit 各读三遍，听出那个长短的落差。
  4. 反向练：上面八个词逐个写音标。

六、今天不用管的

  • ❌ 不用改读法——你本来就把长短读对了。
  • ❌ 不用纠结为什么 city 结尾的 y 写 /i/（那是另一个单元的事）。
  • ❌ 不用管 /e/ 和 /æ/（下一节打它们）。
  • ❌ 不用背单词的中文意思，你早就会了。

✅ 本节完成自查

  • 看到 /iː/ 会想到 see meet eat green sheep
  • 看到 /ɪ/ 会想到 sit big fish milk city
  • 写 /iː/ 时不会漏掉长音符号 ː
  • 给 feel fill seat sit 写出正确音标
  • 知道多音节词要标重音点 ˈ（如 /ˈsɪti/）
/e/ vs /æ/：两个「欸」怎么分

P01-S3 · /e/ vs /æ/：两个「欸」怎么分

🔤 英语音标速成课 · 单元 P01 · 第 3 节 · 约 35 分钟

今天学什么

这一对是很多中国学生最常混的：/e/ 和 /æ/。但对你来说，它只是「两个符号，两个词签」。

符号 你早就认识的词 中文
/e/ bed red ten pen egg 床 / 红色的 / 十 / 钢笔 / 鸡蛋
/æ/ cat bag apple hat map 猫 / 包 / 苹果 / 帽子 / 地图

一、你早就分得出来

只差一个音的词对，意思完全不一样：

左边 音标 中文 右边 音标 中文
bed /bed/ 床 bad /bæd/ 坏的
pen /pen/ 钢笔 pan /pæn/ 平底锅
ten /ten/ 十 tan /tæn/ 棕褐色
head /hed/ 头 had /hæd/ 有（过去式）

念一遍你就听出来：/e/ 轻快，/æ/ 更沉、更拉长一点。 你的耳朵早就在做这件事了。

二、符号长什么样

  • /e/ —— 小写字母 e 本身就是符号。
  • /æ/ —— 拉丁字母 æ，像两个 a 黏在一起，也有人叫它「a 和 e 的合体」。

一眼就能分开：/e/ 是一个字母，/æ/ 是两个字母黏着。

三、拼读对照 + 一个大坑

拼读对照：bed → b + e + d → /b/ + /e/ + /d/ = /bed/ 拼读给你「读得出」，IPA 给你「说得准」

拼读对照：bag → b + a + g → /b/ + /æ/ + /g/ = /bæɡ/ 拼读给你「读得出」，IPA 给你「说得准」

拼读对照：map → m + a + p → /m/ + /æ/ + /p/ = /mæp/ 拼读给你「读得出」，IPA 给你「说得准」

大坑在这里：字母 ea 不一定是 /iː/！head /hed/、bread /bred/ 里的 ea 写作 /e/。所以看到 ea 别急着写 /iː/，先想词。

四、反向练：给词写符号

bed cat red hat pen bag egg map

逐个写出完整音标，写完念一遍核对。

五、今天要练的

  1. 抄词卡：两个符号，每个配四个词，写在符号旁边。
  2. 反向练：上面八个词逐个写音标。
  3. 朗读：bed bad pen pan ten tan 各读三遍，听出两个音的落差。
  4. 找一找：在课外书里找三个含 /æ/ 的词和一个含 /e/ 的词，抄下来。

六、今天不用管的

  • ❌ 不用改你的声音——/e/ 和 /æ/ 你早就分得清。
  • ❌ 不用研究中文的哪个音最像它（没意义，你要记的是符号）。
  • ❌ 不用管 ea 到底怎么来的（那是自然拼读的账，今天只记符号）。
  • ❌ 不用管 /iː/ 和 /ɪ/ 的长音点（上一节已经解决）。

✅ 本节完成自查

  • 看到 /e/ 会想到 bed red ten pen egg
  • 看到 /æ/ 会想到 cat bag apple hat map
  • 给 bed bad pen pan 写出正确音标
  • 知道 ea 在 head bread 里写作 /e/，不是 /iː/
  • 一眼能分开 /e/ 和 /æ/ 两个符号的字形
拼读对照实战：四步把单词变成音标

P01-S4 · 拼读对照实战：四步把单词变成音标

🔤 英语音标速成课 · 单元 P01 · 第 4 节 · 约 40 分钟

今天学什么

前三个符号都认识了，今天把整套动作跑通：一个英文单词 → 一串音标，四步，一步都不能少。

这四步你以后每个单词都能用，不是只对今天这四个符号有效。

一、四步法

  1. 圈元音：先找出这个词的元音（一个音节一个元音）。
  2. 配符号：给每个元音挑符号——今天只在 /iː/ /ɪ/ /e/ /æ/ 里挑。
  3. 配辅音：每个辅音配一个符号。
  4. 加外壳：前后加 /，多音节词再标重音 ˈ。

二、跑四个词

cat —— 圈元音：a 一个 → 配 /æ/ → 辅音 c→/k/、t→/t/ → 加外壳 → /kæt/

milk —— 圈元音：i 一个 → 配 /ɪ/ → 辅音 m→/m/、l→/l/、k→/k/ → /mɪlk/

bed —— 圈元音：e 一个 → 配 /e/ → 辅音 b→/b/、d→/d/ → /bed/

green —— 圈元音：ee 一个 → 配 /iː/ → 辅音 g→/ɡ/、r→/r/、n→/n/ → /ɡriːn/

apple —— 圈元音：a 一个（末尾的 e 不发音，不用配符号）→ /æ/ → 辅音 p→/p/、l→/l/ → 重音在第一音节 → /ˈæpl/

写不出来的音标，就是你还没配上的符号——回上一节查。

三、拼读对照：四步压成一行

拼读对照：cat → c + a + t → /k/ + /æ/ + /t/ = /kæt/ 拼读给你「读得出」，IPA 给你「说得准」

拼读对照：milk → m + i + l + k → /m/ + /ɪ/ + /l/ + /k/ = /mɪlk/ 拼读给你「读得出」，IPA 给你「说得准」

拼读对照：green → g + r + ee + n → /ɡ/ + /r/ + /iː/ + /n/ = /ɡriːn/ 拼读给你「读得出」，IPA 给你「说得准」

拼读对照：apple → a + p + p + l + e → /æ/ + /p/ + /p/ + /l/ = /ˈæpl/ 拼读给你「读得出」，IPA 给你「说得准」

四、批量实战

单词 你写的音标 答案
fish /fɪʃ/
ten /ten/
hat /hæt/
sit /sɪt/
bag /bæɡ/
sheep /ʃiːp/
egg /eɡ/
meet /miːt/

五、今天要练的

  1. 默写四步法：把「圈元音 → 配符号 → 配辅音 → 加外壳」抄在笔记本第一页，以后每课都用。
  2. 批量实战：上面八个词先自己写，再对答案。
  3. 加料：给 apple egg city 标出重音点 ˈ 在哪个音节。
  4. 出声核对：每个词写完念一遍，念的那一声和符号对不上就重配。

六、今天不用管的

  • ❌ 不用改你的声音——四步法只动笔。
  • ❌ 不用追求写得快，先写对。
  • ❌ 不用管辅音的分类（单元音才有这么多讲究）。
  • ❌ 不用管重音点以外的符号细节（下一节 P02 才用到更多元音）。

✅ 本节完成自查

  • 能背出四步法：圈元音 → 配符号 → 配辅音 → 加外壳
  • 独立写出 fish hat sit bag 的音标
  • 知道 apple 末尾的 e 不发音、不配符号
  • 知道多音节词要标重音点 ˈ
  • 知道符号写不出来时，是回去查符号表，而不是猜

今天学什么

单元收尾。今天做三件事：把四个前元音符号一口气过一遍，拆掉两个最常见的坑，然后自查。

一、16 词大考（先自己写，再对答案）

符号 词 音标
/iː/ see /siː/
/iː/ eat /iːt/
/iː/ green /ɡriːn/
/iː/ sheep /ʃiːp/
/ɪ/ sit /sɪt/
/ɪ/ big /bɪɡ/
/ɪ/ fish /fɪʃ/
/ɪ/ milk /mɪlk/
/e/ bed /bed/
/e/ red /red/
/e/ ten /ten/
/e/ egg /eɡ/
/æ/ cat /kæt/
/æ/ bag /bæɡ/
/æ/ apple /ˈæpl/
/æ/ hat /hæt/

二、两个坑

  • 坑 1：/iː/ 少写两个点。 写成 i 就不是 /iː/ 了。写完扫一遍每个长音。
  • 坑 2：ea 不一定是 /iː/。 head /hed/、bread /bred/ 里的 ea 写作 /e/。看到 ea 先想词，别直接写 /iː/。

三、最小对比：听不出来也要写得出来

左边 音标 中文 右边 音标 中文
eat /iːt/ 吃 it /ɪt/ 它
seat /siːt/ 座位 sit /sɪt/ 坐
bed /bed/ 床 bad /bæd/ 坏的
pen /pen/ 钢笔 pan /pæn/ 平底锅
feel /fiːl/ 感觉 fill /fɪl/ 装满

每一对都只差一个音标符号。 这就是音标存在的意义：把你的耳朵锁死在一个个具体的符号上。

四、拼读对照：符号 → 词

反过来也练一次：给你符号，你去找词。

拼读对照：milk → m + i + l + k → /m/ + /ɪ/ + /l/ + /k/ = /mɪlk/ 拼读给你「读得出」，IPA 给你「说得准」

拼读对照：bag → b + a + g → /b/ + /æ/ + /g/ = /bæɡ/ 拼读给你「读得出」，IPA 给你「说得准」

拼读对照：egg → e + gg → /e/ + /ɡ/ = /eɡ/ 拼读给你「读得出」，IPA 给你「说得准」

再玩一次：给 /iː/ /ɪ/ /e/ /æ/ 各写一个你自己的词（从上面十六个里挑，或写你生活里的词）。

五、今天要练的

  1. 闭卷默写：十六个词的音标，一口气写完，再对答案。
  2. 最小对比朗读：五对各读三遍，每读一个词，喊出它用的是哪个符号。
  3. 反向练：给你一个符号，5 秒内说出一个配它的词。
  4. 查漏：错的每一个，抄在旁边写上正确的那个。

六、今天不用管的

  • ❌ 不用改你的声音——这一整个单元你没改过一个音。
  • ❌ 不用扩展到别的元音（P02 开始是 /ɜː/ /ə/ /ʌ/）。
  • ❌ 不用追求百分百不写错，写错能查回来就算过关。
  • ❌ 不用背中文意思。

✅ 本节完成自查

  • 四个符号 /iː/ /ɪ/ /e/ /æ/ 都能秒配出至少 3 个词
  • 十六个锚点词的音标能闭卷写出一半以上
  • 写 /iː/ 时两个点不会漏
  • 知道 ea 在 head bread 里写作 /e/
  • 能背出四步法：圈元音 → 配符号 → 配辅音 → 加外壳
  • 知道这整个单元你练的是符号，不是声音
