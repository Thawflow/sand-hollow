后元音入门：圆唇与非圆唇的位置

P03-S1 · 后元音入门：圆唇与非圆唇的位置

🔤 英语音标速成课 · 单元 P03 · 第 1 节 · 约 35 分钟

今天学什么

后元音的共同点是舌根往后退，抬向软腭，舌尖完全不参与。 这一节只干一件事：把五个后元音 /ɑː/ /ɒ/ /ɔː/ /uː/ /ʊ/ 按「圆唇 / 不圆唇」和「长 / 短」两条线摆好。

一、不圆唇派：/ɑː/ 和 /ɒ/

1️⃣ /ɑː/ —— 嘴最大，唇不圆

  • 写法：/ɑː/，大写 a + 冒号 ː（长音）
  • 要领：嘴大大张开说「啊——」，但嘴唇完全不噘，嘴角向两边拉开
  • 例词：car /kɑː/、park /pɑːk/、heart /hɑːt/

拼读对照：car → c + ar → /k/ + /ɑː/ + /r/ = /kɑː/ 那个 ar 是嘴大、唇不圆的 /ɑː/，不是随便一声「啊」

2️⃣ /ɒ/ —— 嘴大，唇稍收

  • 写法：/ɒ/，大写 o，没有冒号（短音）
  • 要领：嘴同样张得很大，但嘴唇往回收一点；音短促
  • 例词：hot /hɒt/、dog /dɒɡ/、box /bɒks/

拼读对照：hot → h + o + t → /h/ + /ɒ/ + /t/ = /hɒt/ 拼读表里的「短元音 o」不是 /ɑː/ 的短版 —— 唇型收一点，音也短得多

二、圆唇派：/ɔː/ /uː/ /ʊ/

3️⃣ /ɔː/ —— 吹小喇叭

  • 要领：双唇用力收圆并向前突，舌头后部抬高；声音从圆唇缝送出
  • 例词：walk /wɔːk/、talk /tɔːk/、short /ʃɔːt/

4️⃣ /uː/ —— 收得最小最圆

  • 要领：嘴唇比 /ɔː/ 收得更圆更小，几乎挤成小圆孔；舌根抬到最高
  • 例词：food /fuːd/、moon /muːn/、school /skuːl/

拼读对照：food → f + oo + d → /f/ + /uː/ + /d/ = /fuːd/ 拼读给你「读得出」，IPA 给你「说得准」—— 那个 oo 要把嘴唇收到多小，才算 /uː/

5️⃣ /ʊ/ —— 喇叭放松了

  • 要领：嘴唇只是松松地圆一下，不前突；开口比 /uː/ 大一点，音懒洋洋的
  • 例词：book /bʊk/、good /ɡʊd/、look /lʊk/

拼读对照：book → b + oo + k → /b/ + /ʊ/ + /k/ = /bʊk/ 同样是 oo，这里嘴没收到 /uː/ 那么小 —— 下一节 fool / full 就讲这个

五音速查表

音 时长 嘴唇
/ɑː/ 长 不圆，嘴角拉开
/ɒ/ 短 稍收一点
/ɔː/ 长 用力圆唇前突
/ʊ/ 短 松松地圆
/uː/ 长 收到最小最圆

开口从大到小：/ɑː/ → /ɒ/ → /ɔː/ → /ʊ/ → /uː/。

三、今天要练的

  2. 照镜子：依次说 car → hot → walk → food → book，盯嘴唇看变化
  3. 贴标签：给 park dog talk moon good 写出完整音标

四、今天不用管的

  • ❌ 不用管这五个音具体怎么互相分（第二节、第三节专讲）
  • ❌ 不用管嘴唇要圆到多标准，先做到「圆 / 不圆」两派分清
  • ❌ 不用管英音美音差别，本单元统一用英音口径

/uː/ vs /ʊ/：长音与短音（fool / full）

P03-S2 · /uː/ vs /ʊ/：长音与短音（fool / full）

🔤 英语音标速成课 · 单元 P03 · 第 2 节 · 约 40 分钟

今天学什么

后元音里最容易被中文拖垮的一对，就是 /uː/ 和 /ʊ/。 它们舌位几乎一样，差别只在嘴唇收多紧、时间拖多长 —— 这两点恰好是中文没有的。 今天把这一对钉死：fool / full 说得不一样，这两个音就算过关。

一、核心差别：紧长 vs 松短

/uː/ /ʊ/
时长 长，拖足两拍 短，一拍收住
嘴唇 收得又圆又小，向前突 松松地圆，不前突
开口 几乎挤成小孔 比 /uː/ 略开

一句话：/uː/ 是用力吹出的悠长小喇叭，/ʊ/ 是喇叭一松手。

最小对立对：只差一个音，意思全变

词 音标 词 音标
fool /fuːl/ full /fʊl/
pool /puːl/ pull /pʊl/
food /fuːd/ foot /fʊt/

fool（傻瓜）vs full（满的）、pool（水池）vs pull（拉）—— 听错一个音，意思就反了。

1️⃣ /uː/ —— 绷住，往前送

  • 要领：双唇收圆前突，舌根高抬，气流从窄缝里稳稳拖长
  • 例词：fool /fuːl/、food /fuːd/、school /skuːl/

拼读对照：fool → f + oo + l → /f/ + /uː/ + /l/ = /fuːl/ 拼读给你「读得出」，IPA 给你「说得准」—— 这个 oo 是嘴唇收到最小、拖满两拍的那个

2️⃣ /ʊ/ —— 松一下，快收

  • 要领：嘴唇只做「圆一下」的动作，不往前突；音节干脆收尾
  • 例词：full /fʊl/、book /bʊk/、good /ɡʊd/、put /pʊt/

拼读对照：full → f + u + ll → /f/ + /ʊ/ + /l/ = /fʊl/ 拼读里那个 u 是「短元音 u」，它就是 /ʊ/ —— 嘴不用力圆，声音一出来就收

二、中文会怎么坑你

中文的「u」（书、苏、路）其实是不圆唇的 /ʊ/。最常见的两种失误：

  1. 读 /uː/ 时忘记圆唇，像中文的「乌」—— food 会读成「福德」
  2. 读 /ʊ/ 时又圆过头，跟 /uː/ 撞在一起，book 和 booth 混作一团

破解办法：先只练嘴唇动作 —— 读 fool 时挤成小圆孔，读 full 时放松。

拼读对照：moon → m + oo + n → /m/ + /uː/ + /n/ = /muːn/ oo 有两副面孔：moon food school 是 /uː/，book look good foot 是 /ʊ/ 拼读分不出来的时候 —— 这正是 IPA 出手的时刻

三、今天要练的

  1. 朗读：fool/full pool/pull food/foot 每对读 5 遍
  2. 录音自查：录下这几对词，回放比时长
  3. 手写辨析：写出 /uː/ 和 /ʊ/ 各三个例词，标出音标

四、今天不用管的

  • ❌ 不用管 /əʊ/（go home 里那个音，另一单元讲）
  • ❌ 不用纠结口音「够不够标准」，先做到圆 / 不圆分得开
  • ❌ 不用管英音美音差别，本单元统一用英音口径

✅ 本节完成自查

  • 手写出了 /uː/ 和 /ʊ/ 两个符号
  • 能用「绷住长音 vs 松开短音」说清两者差别
  • fool/full pool/pull food/foot 三组读得出差别
  • 知道 oo 在 book 里是 /ʊ/、在 food 里是 /uː/
  • 录音回放时听得出自己的长音确实更长
/ɑː/ /ʌ/ /ɒ/ /ɔː/：四个后元音的分辨

P03-S3 · /ɑː/ /ʌ/ /ɒ/ /ɔː/：四个后元音的分辨

🔤 英语音标速成课 · 单元 P03 · 第 3 节 · 约 40 分钟

今天学什么

上一节搞定了圆唇那一对。这一节把四个「嘴张得大」的音摆到同一张桌子上比： /ɑː/ 不圆唇、/ɒ/ 稍圆、/ɔː/ 用力圆、/ʌ/ 压根不靠后。

一、座位表：四个音一起看

音 时长 嘴唇 开口度 例词
/ɑː/ 长 不圆，嘴角拉开 最大 car /kɑː/、park /pɑːk/
/ɒ/ 短 稍收一点 大 hot /hɒt/、cost /kɒst/
/ɔː/ 长 用力圆唇前突 中 walk /wɔːk/、short /ʃɔːt/
/ʌ/ 短 不圆 中 cup /kʌp/、bus /bʌs/

开口从 /ɑː/ 往 /uː/ 逐级变小，嘴唇越往后越收圆。 /ʌ/ 是例外 —— 它是中元音（P02 学过），只是常被拿来跟 /ɑː/ 比。

拼读对照：hot → h + o + t → /h/ + /ɒ/ + /t/ = /hɒt/ 那个 o 不是 /ɔː/ 的短版，是另一个位置

拼读对照：walk → w + al + k → /w/ + /ɔː/ + /k/ = /wɔːk/ 拼读表里的 al 就是 /ɔː/ —— 嘴要收圆前突才算读对，读成「瓦克」就露馅了

二、最小对立对：一次只差一个音

对 左边 右边 差别在哪
heart / hut /hɑːt/ /hʌt/ 长 / 短 + 开口度
hot / hut /hɒt/ /hʌt/ /ɒ/ 嘴大唇稍圆 vs /ʌ/ 嘴小唇不圆
cot / caught /kɒt/ /kɔːt/ /ɒ/ 大嘴 vs /ɔː/ 用力圆唇 + 长
cart / caught /kɑːt/ /kɔːt/ /ɑː/ 唇不圆 vs /ɔː/ 唇圆到发紧

中国学生最常见的三个坑

  1. /ɒ/ 读成 /ɔː/：hot 读成「hout」→ 嘴唇收太狠
  2. /ɔː/ 读成 /ɑː/：walk 读成「瓦克」→ 嘴唇没收圆
  3. /ʌ/ 读成 /ɑː/：cup 读成「卡普」→ 嘴张太大、拖太长

拼读对照：car → c + ar → /k/ + /ɑː/ + /r/ = /kɑː/ 同一个 ar，在 heart 里还是 /ɑː/（h + ear + t → /h/ + /ɑː/ + /t/ = /hɑːt/）， 可在 warm 里却是 /ɔː/（w + arm → /w/ + /ɔː/ + /m/ = /wɔːm/） 拼读给的是「大概」，IPA 给的是「每个词的准确答案」

三、今天要练的

  1. 听辨：请人随机念 cart cut cot caught hot hut，你只写拼写不看字
  2. 口型表：对镜说 cart cut cot caught，每次都先摆口型再出声
  3. 贴标签：给 star short money cost daughter 写出完整音标
  4. 自查：录下「hot / hut / caught / cart」四连读，回放听唇型差别

四、今天不用管的

  • ❌ 不用管这四个音在哪个位置出现（第四节专门做拼读推读音）
  • ❌ 不用纠结 /ɑː/ 和 /ʌ/ 的舌位差几毫米（先从唇型和时长分）
  • ❌ 不用管英音美音差别，本单元统一用英音口径

✅ 本节完成自查

  • 能不看表说出四个音的「唇 + 时长」区别
  • cart/cut hot/hut cot/caught 三组听得出来
  • 给 star short money cost daughter 写出了完整音标
  • 知道自己有没有把 /ɒ/ 读成 /ɔː/、把 /ʌ/ 读成 /ɑː/
  • 明白 ar 在 car 和 warm 里读法不同
拼读对照实战：拼读推读音 + IPA 标注

P03-S4 · 拼读对照实战：拼读推读音 + IPA 标注

🔤 英语音标速成课 · 单元 P03 · 第 4 节 · 约 40 分钟

今天学什么

这一节是双系统合流：左边是拼读（你早就会的地基），右边是音标（这几天学的）。 三步走：① 用拼读推读音 → ② 写完整 IPA → ③ 圈出每个后元音。 推的时候大胆推 —— 对不上的地方正是例外词，那才是 IPA 真正派上用场的地方。

一、三步法演示：warm

第 1 步 · 拼读推读音 w-a-rm → /w/ + /ɔː/ + /r/ + /m/？（你大概率会推成 /wɑːrm/）

第 2 步 · 写完整 IPA warm /wɔːm/

第 3 步 · 圈后元音 一个：/w**ɔː**m/ —— 而且是圆唇的长音。

对不上的地方：ar 在 car 里是 /ɑː/，在 warm 里是 /ɔː/。 拼读给你「大概」，IPA 给你「答案」。

二、实战词表 + 例外词

单词 拼读推读音（自己先推） 完整 IPA
car c + ar /kɑː/
hot h + o + t /hɒt/
walk w + al + k /wɔːk/
food f + oo + d /fuːd/
book b + oo + k /bʊk/
shop sh + o + p /ʃɒp/
moon m + oo + n /muːn/
warm w + ar + m /wɔːm/

三个观察：

  1. oo 两副面孔：food moon 是 /uː/，book 是 /ʊ/ —— 拼读表不告诉你哪个
  2. o 也是：hot shop 是 /ɒ/，door 是 /ɔː/ —— 单个 o 几乎都是 /ɒ/
  3. ar al 两副面孔：car 是 /ɑː/，walk warm 是 /ɔː/

拼读会推错的三个词

单词 大概会推成 真实 IPA 差别在哪
sugar /ˈʃuːɡə/ /ˈʃʊɡə/ u 是短音 /ʊ/
blood /bluːd/ /blʌd/ oo 变成 /ʌ/ —— 完全例外
heart /hɔːt/ /hɑːt/ ear 不是 /ɔː/ 是 /ɑː/

blood 是后元音里最狠的例外：拼读推 /uː/，真音 /ʌ/，差了两个位置。

拼读对照：sugar → s + u + g + ar → /ʃ/ + /ʊ/ + /ɡ/ + /ə/ = /ˈʃʊɡə/ 拼读给你「读得出」，IPA 给你「说得准」—— u 明明写着，读出来却不是 /uː/

拼读对照：pool → p + oo + l → /p/ + /uː/ + /l/ = /puːl/ 跟 pull /pʊl/ 只差一个冒号 —— 拼读看 oo u 分不清，IPA 一眼定长短

三、今天要练的

  1. 遮住右栏：只看单词，先用拼读推读音写出来，再对答案
  2. 圈后元音：把词表 8 个词的后元音全圈出来，数一数共几个
  3. 自己加词：再加 5 个含后元音的常用词（提示：ar or oo al）
  4. 找例外：给 sugar blood heart 各写一句「拼读会推错在哪」

四、今天不用管的

  • ❌ 不用追求每个词都标对 —— 先分清哪个后元音、圆不圆、长不长
  • ❌ 不用管例外词该怎么解释（那是词典的工作）
  • ❌ 不用管英音美音差别，本单元统一用英音口径

✅ 本节完成自查

  • 8 个词都走完了「推读音 → 标 IPA → 圈后元音」
  • 圈出了全部后元音
  • 至少找出 3 个「拼读推不准」的词
  • 自己加了 5 个含后元音的词
  • 能说清拼读负责「大概」，IPA 负责「答案」

二、拼读互验：「拼读会推错」的词

单词 大概会推成 真实 IPA 差别在哪
warm /wɑːm/ /wɔːm/ ar 读圆唇
blood /bluːd/ /blʌd/ oo 变成 /ʌ/
sugar /ˈʃuːɡə/ /ˈʃʊɡə/ u 是短音 /ʊ/

规律：拼读管「常见情况」，IPA 管「所有情况」。 推不动的词就是拼读的边界 —— 查音标。

拼读对照：football → f + oo + t + b + all → /f/ + /ʊ/ + /t/ + /b/ + /ɔː/ + /l/ = /ˈfʊtbɔːl/ 一个词里同时住着 /ʊ/ 和 /ɔː/ —— 拼读只给你两个字母群，IPA 给你确切答案

拼读对照：talk → t + al + k → /t/ + /ɔː/ + /k/ = /tɔːk/ 别被 al 骗成 /æl/ —— al 在 talk walk 里都是圆唇的 /ɔː/

三、今天要练的

  1. 限时 10 分钟：练习 A + B 全做完，不查资料
  2. 对答案：错的词抄进「我的错题本」，标上错在哪一步
  3. 朗读：练习 C 那句话读 5 遍，每遍数一遍后元音的个数
  4. 总结：用一句话写下你对这五个后元音的判断口诀

四、今天不用管的

  • ❌ 不用追求一次全对，错题本比分数有用
  • ❌ 不用管下一单元的双元音，那是新故事
