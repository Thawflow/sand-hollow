为什么要「站在拼读上」？

自然拼读给「读陌生词」的能力（约 70–80% 的规则词）， IPA 给「精确标注、查词、纠音」的能力（100%）。 它们不是两门课，是同一件事的两个视角。

  • 拼读读不准时 → 用 IPA 标出来，定位到底哪个音错了
  • IPA 不熟时 → 用拼读推出来，先有个大致读音
  • 两者对不上时 → 那是例外词（one island colonel）⇒ 这正是 IPA 存在的意义

P00 · 地基回顾：自然拼读地图 + 48 音标全景

你会学到：你的拼读能力长什么样（20+ 个字母组合）、48 个音标分几类、五张发音部位地图 你要会做：看到 cat 能说出音标 /k/ /æ/ /t/；能报出 20 元音 + 28 辅音的分类

P01 · 前元音：/iː/ /ɪ/ /e/ /æ/

你会学到：四个前元音的口型舌位，长音与短音的对立 你要会做：拼读对比 sheep / ship、bed / bad —— 分清 /iː/-/ɪ/、/e/-/æ/

P02 · 中元音：/ɜː/ /ə/ /ʌ/

你会学到：中元音口型，重点是最高频的弱读 /ə/ 你要会做：听出 about teacher 里的 /ə/；分清 /ɜː/-/ə/-/ʌ/

P03 · 后元音：/ɑː/ /ɒ/ /ɔː/ /uː/ /ʊ/

你会学到：圆唇后元音，长短对立 你要会做：分清 /ɑː/-/ʌ/、/uː/-/ʊ/（fool / full 是经典对）

P04 · 双元音（一）：/eɪ/ /aɪ/ /ɔɪ/

你会学到：合口双元音的滑动 —— 一个音滑向另一个，不是两个独立音 你要会做：读准 name time boy；看出 a_e 拼读规则和 /eɪ/ 的对应

P05 · 双元音（二）：/ɪə/ /eə/ /ʊə/ /aʊ/ /əʊ/

你会学到：集中双元音（口型由开变合）；重点 /əʊ/（no go home） 你要会做：读准 here hair tour now go

P06 · 爆破音与摩擦音：/p b t d k g/ + /f v s z θ ð ʃ ʒ h r/

你会学到：清浊成对（手摸喉咙感受声带震动）、咬舌音 /θ/ /ð/ 你要会做：分清 7 组清浊对；读准中国学生最常错的 /θ/ /ð/（think this）

P07 · 破擦音·鼻音·舌侧音·半元音：/ts dz tʃ dʒ tr dr/ + /m n ŋ/ + /l/ + /w j/

你会学到：收尾音、后鼻音 /ŋ/、半元音滑动 你要会做：读准 /ŋ/（sing 不读成 sin）、/tʃ/ /dʒ/（chair jam）

P08 · 双系统实战：拼读 × 音标互验

你会学到：用两套系统互相验证 —— 拼读推读音、IPA 精确标注、例外词识别 你要会做：① 拼读推读音 → ② IPA 标注 → ③ 对不上的词 = 例外词，单独成表；给多音节词标重音

音标总表（20 元音 + 28 辅音）

元音 20

  • 单元音 12：/iː/ /ɪ/ /e/ /æ/ /ɜː/ /ə/ /ʌ/ /ɑː/ /ɒ/ /ɔː/ /uː/ /ʊ/
  • 双元音 8：/eɪ/ /aɪ/ /ɔɪ/ /ɪə/ /eə/ /ʊə/ /aʊ/ /əʊ/

辅音 28

  • 爆破音 6：/p/ /b/ /t/ /d/ /k/ /g/
  • 摩擦音 10：/f/ /v/ /s/ /z/ /θ/ /ð/ /ʃ/ /ʒ/ /h/ /r/
  • 破擦音 6：/ts/ /dz/ /tʃ/ /dʒ/ /tr/ /dr/
  • 鼻音 3：/m/ /n/ /ŋ/
  • 舌侧音 1：/l/
  • 半元音 2：/w/ /j/

国内教材口径：爆破 6 + 摩擦 10 + 破擦 6 + 鼻音 3 + 舌侧 1 + 半元音 2 = 28（/tr/ /dr/ 计入破擦音）。

五个必掌握技能

  1. 发音部位分类 —— 双唇 / 齿间 / 齿龈 / 舌面 / 舌根
  2. 口型与舌位 —— 长音拉长、短音短促、双元音滑动
  3. 清浊对照 —— 7 组对（手摸喉咙感受声带震动）
  4. 音节与重音 —— 元音是音节核心；重音错了词就读错
  5. 连读 / 失去爆破 / 弱读 —— 贴合真实听力与朗读

学习节奏建议

每天 1 个单元（30–40 分钟），周末做 P08 实战。每天固定三步：

  1. 手写本单元的音标符号（纸笔 —— 符号类内容光看不算会）
  2. 跟读例词：先拼读推读音，再看 IPA 对不对
  3. 5 题小测：本单元的音标 + 一个近音辨析

第 3 天起每天加「近音辨析 3 组」（最容易混的：/iː/-/ɪ/ /æ/-/e/ /θ/-/s/）
