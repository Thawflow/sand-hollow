什么是双元音：滑动的概念

P04-S1 · 什么是双元音：滑动的概念

🔤 英语音标速成课 · 单元 P04 · 第 1 节 · 约 30 分钟

今天学什么

从这一节开始学「双元音」—— 一个音节里塞进两个元音，一口气滑过去。 今天先搞懂滑动这件事：为什么 name 只算一个音节、为什么它跟「n + e + m」听起来完全不同。 同时跟本单元的三个主角 /eɪ/ /aɪ/ /ɔɪ/ 混个脸熟。拼读那块儿你已经会了，这里只给地基上的音贴一张「会滑动」的标签 ✨

一、双元音 = 一次滑动，两个落点

单元音：口型、舌位从头到尾不变，一口气发完。

双元音：两个元音连着滑，中间不停顿、不换气，整体只算一个音节。

单元音 双元音
口型 全程不变 从一个口型滑到另一个
音节数 1 1（不是 2！）
感觉 一口说到底 「诶——伊」，叹着气滑过去
轻重 一样 前半重，后半轻

发音要领（三步）：① 先冲到第一个音，发实、发亮 ② 嘴不闭、气不断，顺势滑过去 ③ 第二个音轻收住，别吞掉、别变成独立音节

拼读对照：name → n + a_e + m → /n/ + /eɪ/ + /m/ = /neɪm/ 一个音节 neɪm，中间的 /eɪ/ 是滑出来的，不是 e 加 a 两个音。 拼读给你「读得出」，IPA 给你「说得准」

二、本单元的三个主角：/eɪ/ /aɪ/ /ɔɪ/

三个都是合口双元音：起点口型开着，终点口型合拢收住。

音标 起点 → 终点 口型动作 例词
/eɪ/ /e/ → /ɪ/ 嘴半开，舌前部抬起 name /neɪm/ cake /keɪk/
/aɪ/ /a/ → /ɪ/ 嘴大张，舌位低平 time /taɪm/ light /laɪt/
/ɔɪ/ /ɔ/ → /ɪ/ 双唇撅圆前突 boy /bɔɪ/ coin /kɔɪn/

诀窍：三个音的终点都是 /ɪ/（那个「伊」），只有起点不同。 分不清的时候先判断起点：半开的是 /eɪ/，大张的是 /aɪ/，撅圆的是 /ɔɪ/。

拼读对照：light → l + i + gh → /l/ + /aɪ/ + /t/ = /laɪt/ gh 在这里既不发音也不发 /g/，拼读时你会直接跳过它 —— IPA 让你写得出来。 拼读给你「读得出」，IPA 给你「说得准」

剩下五个双元音是下一单元的事，今天只认脸。

三、今天要练的

  1. 手写：把 /eɪ/ /aɪ/ /ɔɪ/ 三个符号纸笔手抄三遍（光看不算会）
  2. 划滑线：念 name cake time light boy，用手画出滑动方向
  3. 贴标签：给 cat /kæt/、cake /keɪk/ 写音标，说出差在哪
  4. 记起点：写张小卡片 —— /eɪ/ 半开、/aɪ/ 大张、/ɔɪ/ 撅圆

四、今天不用管的

  • ❌ 不用背例词表（下一节开始配）
  • ❌ 不用练拼读规则（那是你的地基，不是新课）
  • ❌ 不用追求发音完美（先把「滑动」装进去就行）

✅ 本节完成自查

  • 手写了 /eɪ/ /aɪ/ /ɔɪ/ 三个符号
  • 能说清「双元音只算一个音节」为什么
  • 知道三个音起点不同、终点都是 /ɪ/
  • 给 name 和 light 写出了完整音标
  • 知道 IPA 值得学：拼读给你「读得出」，IPA 给你「说得准 + 查得到」
/eɪ/：a_e 拼读规则与 /eɪ/ 的对应

P04-S2 · /eɪ/：a_e 拼读规则与 /eɪ/ 的对应

🔤 英语音标速成课 · 单元 P04 · 第 2 节 · 约 35 分钟

今天学什么

这一节专攻 /eɪ/ —— 它跟你早就会的 a_e 拼读规则完全对得上。 你会学会：/eɪ/ 到底怎么滑、哪些词走 a_e 这条路、哪些词是「不听话」的例外。 写下来 + 读出来，你就同时拿到了拼读和 IPA 两份答案 🔥

一、/eɪ/ 到底怎么滑

写法：/eɪ/ —— 就是 e 和 ɪ 两个符号并排：前面标起点口型，后面标滑向哪里。

滑动方向：/e/ → /ɪ/

阶段 舌位 口型 感觉
起点 /e/ 舌前部抬起、略高于 /æ/ 半开，嘴角微展 「诶」
终点 /ɪ/ 舌前部再抬一点 微微收窄 「伊」

三步走：① 嘴张开一半，舌抬高发 /e/ ② 嘴不闭、气不断，向右滑 ③ 到 /ɪ/ 收住，别滑成「诶—衣」两个音节。前半重、后半轻。

拼读对照：name → n + a_e + m → /n/ + /eɪ/ + /m/ = /neɪm/ 拼读表的 a_e 就是 /eɪ/ 的另一种写法 —— 你早就在用它，只是今天给它起名字。 拼读给你「读得出」，IPA 给你「说得准」

二、a_e → /eɪ/：规则与它的例外

规则：元音 a + 辅音 + e（结尾的 e 不发音，只负责「拉长前面的元音」）。

拼读 单词 IPA
a_e cake /keɪk/
a_e name /neɪm/
a_e face /feɪs/
a_e late /leɪt/
a_e game /geɪm/

对照着看差异（这才是重点）：

单词 拼读 IPA
cap a（短） /kæp/
cape a_e /keɪp/
mad a（短） /mæd/
made a_e /meɪd/

拼读对照：made → m + a_e + d → /m/ + /eɪ/ + /d/ = /meɪd/ mad → m + a + d → /m/ + /æ/ + /d/ = /mæd/ 同一个字母 a，加个 e 就从「阿」变成「诶—伊」，差别全在滑不滑。

不听话的例外（先认识，不必现在记全）

规则有用，但不是铁律。碰到对不上的，以 IPA 为准：

单词 你可能拼成 实际是 说明
have /heɪv/ /hæv/ 读 /æ/，不读 /eɪ/
give /ɡaɪv/ /ɡɪv/ 读 /ɪ/
are /eɪr/ /ɑː/ 读 /ɑː/，不是 /eɪ/
says /seɪz/ /sez/ 读 /e/

遇到对不上 = 例外词，单独抄到一个小表里 —— 这正是学 IPA 的价值 🔍

三、今天要练的

  1. 手写 /eɪ/ 三遍 + 写一句话：起点是什么、终点是什么
  2. 配对：写音标 —— cake cap late hat name map
  3. 滑读：读 cake name face game，每读一个用手比一次滑动
  4. 找例外：写 3 个「结尾有 e 也不读 /eɪ/」的词（have give says 就是答案）

四、今天不用管的

  • ❌ 不用管 a_e 之外的规则（下一节来）
  • ❌ 不用把例外词全背下来（先认识 4 个就够）
  • ❌ 不用练精确时长（滑对方向比时长重要）

✅ 本节完成自查

  • 手写了 /eɪ/，能说出 /e/ → /ɪ/ 的滑动方向
  • 会用 a_e 规则推出 cake / name / late 的读音
  • 给 cap 和 cake 分别写出了 /kæp/ 和 /keɪk/
  • 认识 4 个例外词，知道对不上时以 IPA 为准
  • 拼读给你「读得出」，IPA 给你「说得准」
/aɪ/ 与 /ɔɪ/：i_e 和 oi 拼读

P04-S3 · /aɪ/ 与 /ɔɪ/：i_e 和 oi 拼读

🔤 英语音标速成课 · 单元 P04 · 第 3 节 · 约 35 分钟

今天学什么

上节课拿下了 /eɪ/，今天一次拿下它的两个兄弟：/aɪ/ 和 /ɔɪ/。 它们跟你拼读表里的 i_e 和 oi 直接挂钩 —— 学会读法，也学会怎么判断哪个词走哪条路。 重点：/ɔɪ/ 看着像 /ɔː/ 加 /ɪ/，但它不是，它是一个滑动整体 🎯

一、/aɪ/ 与 /ɔɪ/：两个兄弟，两种起点

/aɪ/ —— 嘴大张，滑向「伊」

写法：/aɪ/ —— a 和 ɪ 并排：前面标起点口型，后面标滑向哪里。滑动方向：/a/ → /ɪ/

  • 起点 /a/：嘴张到最大，舌位低平靠后，像看医生说「啊——」
  • 终点 /ɪ/：嘴微微收窄，舌前部抬起
  • 易错：起点不够开，听起来像 /eɪ/。记住「张大嘴」
拼读 单词 IPA
i_e time /taɪm/
i_e light /laɪt/
i_e kite /kaɪt/
i_e nice /naɪs/
i_e five /faɪv/

拼读对照：time → t + i_e + m → /t/ + /aɪ/ + /m/ = /taɪm/ tim（去掉 e）读 /tɪm/ —— 那个 e 就是「拉开嘴、启动滑动」的那张开关。 拼读给你「读得出」，IPA 给你「说得准」

/ɔɪ/ —— 撅圆嘴，滑向「伊」

写法：/ɔɪ/ —— o 和 ɪ 并排。滑动方向：/ɔ/ → /ɪ/

  • 起点 /ɔ/：双唇撅圆前突，像吹 /ɔː/，但别噘太久
  • 终点 /ɪ/：唇立刻放开，舌前抬起
  • 易错：起点不圆唇 → 像 /aɪ/。圆唇是 /ɔɪ/ 的身份证
拼读 单词 IPA
oi oil /ɔɪl/
oi coin /kɔɪn/
oi boil /bɔɪl/
oy boy /bɔɪ/
oy toy /tɔɪ/

拼读对照：coin → c + oi + n → /k/ + /ɔɪ/ + /n/ = /kɔɪn/ oy 是 oi 的变体（多在词尾），都读 /ɔɪ/。 拼读给你「读得出」，IPA 给你「说得准」

二、三个音怎么分？

/eɪ/ /aɪ/ /ɔɪ/
起点 /e/ 半开 /a/ 大张 /ɔ/ 撅圆
终点 /ɪ/ /ɪ/ /ɪ/
拼读线索 a_e i_e oi / oy
例词 name time boy

秒判法：先看起点 —— 半开 /eɪ/，大张 /aɪ/，撅圆 /ɔɪ/。三个都收在同一个 /ɪ/ 上。

词 IPA 注意
boy /bɔɪ/ 不是 /bɔ/ + /ɪ/ 两个音，是一个滑动
boil /bɔɪl/ 词尾那个 l 单独读 /l/，别带出多余音

三、今天要练的

  1. 手写 /aɪ/ /ɔɪ/ 各三遍，标注起点→终点
  2. 配对：写音标 —— light like oil joy time
  3. 对比读：把 name / time / boy 连读三遍，用手指区分「半开 / 大张 / 撅圆」
  4. 找规则：写 3 个走 i_e 的词 + 3 个走 oi/oy 的词

四、今天不用管的

  • ❌ 不用管 igh 里 gh 的历史（拼读会跳就行）
  • ❌ 不用管其他双元音（下一单元）
  • ❌ 不用纠结多音节例外的细节（后面再说）

✅ 本节完成自查

  • 手写了 /aɪ/ 和 /ɔɪ/，知道起点口型不同、终点都是 /ɪ/
  • 会用 i_e 推出 time / light，用 oi/oy 推出 coin / boy
  • 给 light 和 coin 写出了完整音标
  • 读 name / time / boy 时口型差别明显
  • 拼读给你「读得出」，IPA 给你「说得准」
拼读对照实战：拼读推读音 + IPA 标注

P04-S4 · 拼读对照实战：拼读推读音 + IPA 标注

🔤 英语音标速成课 · 单元 P04 · 第 4 节 · 约 35 分钟

今天学什么

前面三节都是「认识」，今天开始「干活」。 你要练的是一套两段式流程：第一步用拼读推读音，第二步用 IPA 写下来，再对答案。 这套流程在 P08 会变成完整武器，今天先把它用顺手 💪

一、两段式工作法

Step 1 · 拼读推读音（你已有的技能）：拆成拼读组合 → 读出来，先不管符号。 Step 2 · IPA 标注（今天的新技能）：给刚才那个音贴标签 —— 哪段是 /eɪ/、/aɪ/、/ɔɪ/。 Step 3 · 对答案（最有价值的一步）：对不上 = 例外词，抄进例外表；对上了 = 这词彻底拿下。

二、实战演练（先自己做，再看答案）

练习 1 · cake

  • 拼读：c + a_e + k → 「k-诶-k」
  • 你的 IPA：______
  • 答案：/keɪk/　→ ✅ 对上了，c = /k/，a_e = /eɪ/

练习 2 · light

  • 拼读：l + i + gh → 「l-大张嘴-伊-t」
  • 你的 IPA：______
  • 答案：/laɪt/　→ ✅ gh 不发音，直接跳过

练习 3 · boy

  • 拼读：b + oy → 「b-哦伊」
  • 你的 IPA：______
  • 答案：/bɔɪ/　→ ✅ 起点是圆唇的 /ɔ/

练习 4 · plate

  • 拼读：p + l + a_e + t → 「p-l-诶-t」
  • 你的 IPA：______
  • 答案：/pleɪt/　→ ✅ 一个音节，不是两个

练习 5 · oil

  • 拼读：o + i + l → 「哦-伊-l」
  • 你的 IPA：______
  • 答案：/ɔɪl/　→ ✅ 起点仍是 /ɔ/，因为拼读组合是 oi

练习 6 · height（例外警报 ⚠️）

  • 拼读：h + ei + gh + t → 你可能读成 /heɪt/
  • 你的 IPA：______
  • 答案：/haɪt/　→ ❌ 对不上！ 起点是 /a/ 不是 /e/
  • 处理：抄进例外表。遇到 ei 结尾的词别默认 /eɪ/，去查 IPA

拼读对照：height → h + ei + gh + t → /h/ + /aɪ/ + /t/ = /haɪt/ 拼读推的是 /eɪ/，IPA 说 /aɪ/ —— 拼读给你「读得出」，IPA 给你「说得准 + 查得到」

例外表长这样

单词 拼读会推成 实际是 为什么
height /heɪt/ /haɪt/ ei 不总是 /eɪ/
said /seɪd/ /sed/ ai 读 /e/
have /heɪv/ /hæv/ a_e 不总是 /eɪ/

这张表会越攒越长 —— 它是你的「拼读盲区地图」，比背 100 个单词都有用 🗺️

三、今天要练的

  1. 完整走一遍 6 个练习：拼读 → 标 IPA → 对答案，抄下错的那个
  2. 自己出题：写 6 个含 /eɪ/ /aɪ/ /ɔɪ/ 的词，各标一个音标
  3. 建例外表：把今天对不上的词写成一栏一行的表（至少 2 个）
  4. 朗读：把练习词连读一遍，注意滑动

四、今天不用管的

  • ❌ 不用一次标完所有长单词（先把含本单元三音的词标好）
  • ❌ 不用纠结多音节重音（P08 才练）
  • ❌ 不用追求一次全对（错的那几个才是今天的收获）

✅ 本节完成自查

  • 会说清「拼读推读音 → IPA 标注 → 对答案」三步
  • 6 个练习里至少 5 个标对
  • 认出了 height 是例外词，并抄进了例外表
  • 给 cake / light / boy 写出了 /keɪk/ / /laɪt/ / /bɔɪ/
  • 拼读给你「读得出」，IPA 给你「说得准 + 查得到」
双元音（一）综合练习 + 自查

P04-S5 · 双元音（一）综合练习 + 自查

🔤 英语音标速成课 · 单元 P04 · 第 5 节 · 约 40 分钟

今天学什么

单元收尾。今天把 /eɪ/ /aɪ/ /ɔɪ/ 三个音串起来练：认音、标词、辨混淆、认例外。 把这三天学的东西用一遍，看看哪些已经变成你自己的了。 最后有一张单元自查表，照着打勾就行 ✅

一、认音热身 + 三组辨析

看符号，念出来（30 秒）：

/eɪ/　/aɪ/　/ɔɪ/　/eɪ/　/ɔɪ/　/aɪ/

窍门：全部收在 /ɪ/，只有起点不同 —— 半开 / 大张 / 撅圆。

对比 IPA 差别在哪
cap / cape /kæp/ / /keɪp/ 短 a（单元音） vs a_e（滑动）
bay / boy /beɪ/ / /bɔɪ/ 起点半开 vs 撅圆
tie / toy /taɪ/ / /tɔɪ/ 起点大张 vs 撅圆

拼读对照：cap → c + a + p → /k/ + /æ/ + /p/ = /kæp/ cape → c + a_e + p → /k/ + /eɪ/ + /p/ = /keɪp/ 同一个 a，加一个 e 就从「单元音」变成「滑动音」 —— 这就是 a_e 规则的全部秘密。 拼读给你「读得出」，IPA 给你「说得准」

二、标注冲刺 + 例外词清扫

标出每个词里双元音的那一段：

单词 完整 IPA 目标音
name /neɪm/ /eɪ/
kite /kaɪt/ /aɪ/
boil /bɔɪl/ /ɔɪ/
face /feɪs/ /eɪ/
night /naɪt/ /aɪ/
joy /dʒɔɪ/ /ɔɪ/
plate /pleɪt/ /eɪ/
spoil /spɔɪl/ /ɔɪ/

规律：a_e → /eɪ/ ｜ i_e、igh → /aɪ/ ｜ oi、oy → /ɔɪ/

例外词（对不上的都算收获）：

单词 拼读会推成 实际是
height /heɪt/ /haɪt/
said /seɪd/ /sed/
have /heɪv/ /hæv/
give /ɡaɪv/ /ɡɪv/
friend /friːnd/ /frend/
says /seɪz/ /sez/

拼读对照：give → g + i + v + e → 你会推成 /ɡ/ + /aɪ/ + /v/ = /ɡaɪv/ 实际是 /ɡɪv/。对不上的那一刻，就是 IPA 存在的理由 —— 拼读给你「读得出」，IPA 给你「说得准」

六条全部不按拼读走 —— 这就是为什么光会拼读不够，IPA 是纠错工具 🔍

三、今天要练的

  1. 朗读：第二节 8 个 + 例外 6 个，每个音都念准口型
  2. 默写三音：纸笔写出 /eɪ/ /aɪ/ /ɔɪ/ + 各自的起点口型说明
  3. 做 10 道自测：自己找 10 个含本单元三音的词，标 IPA 再核对
  4. 整理例外表：把这单元的例外词并到一张总表里（后面 P05 还会加）
  5. 回头看地基：写一句话总结 —— 拼读给了我什么，IPA 补了我什么

四、今天不用管的

  • ❌ 不用背例外词的拼写（记住「不按拼读走」就行）
  • ❌ 不用提前学下一单元那五个双元音
  • ❌ 不用追求发音跟英国人一样（口型方向对了就过关）
