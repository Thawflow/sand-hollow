今天学什么

这一节不学新音——你的发音已经比大多数人都准了。你缺的是一样东西：

你读得出，但你写不出来。

今天就干这一件事：给 48 个音标，每个配一个你早就认识的单词。 以后你看到任何生词，脑子里自动弹出这个音该写哪个符号。

一、为什么你的英语已经够用了

你说得出 cat 是什么音（/k/ /æ/ /t/），也知道 think 里那个 th 念什么。 但如果现在要你写下来，你会写成：

你读到的 你能写出的 你缺的
cat 里的 /k/ k、c、ck 都能表示 它写作 /k/
think 里的 th th、t、h 都有可能 它写作 /θ/
sheep 里的 ee e、ea、ee 都可能 它写作 /iː/

同一个音可以有很多种拼法，但音标只有一个。 音标就是给声音发的唯一身份证。

这就是为什么补音标是最高效的那一步：

  • 你已经会读 ⇒ 不用学发音
  • 你已经认识 5000 个词 ⇒ 每个词都是一个现成的练习题
  • 你要学的只是「这个声音对应哪个符号」这一张对照表

三、这些词你都会 —— 所以这节课才是速成

看上面这张表：48 个词，没有一个是你不认识的。

这就是速成课和从头学音标的区别：

从头学音标 这门课
前提 什么都不会 你已经会读、认识 5000 词
要做的事 听 → 模仿 → 练发音 → 记住 看词 → 认出符号 → 贴标签

你不是要学会一个新技能，是要给已有的技能装一个索引。

              └─ 双元音 8 ── 合口 5（集中 3）

记住两件事就够：

  1. 元音 20 个 = 声音的主体（每个音节里必须有一个）
  2. 辅音 28 个 = 音节的框架（/m/ /n/ /l/ 结尾时可以自己成音节）

五、拼读对照：左边字母怎么拼，右边符号怎么写

这套课的核心动作就一个：同一个词，左边看字母、右边看符号。

拼读对照：sheep → sh + ee + p → /ʃ/ + /iː/ + /p/ = /ʃiːp/ 拼读给你「读得出」，IPA 给你「说得准」

你早就会 sh 读 /ʃ/、ee 读 /iː/。现在多做的只有一件事： 把「sh」这个字母组合，换成「/ʃ/」这个符号。

拼读对照：think → th + i + nk → /θ/ + /ɪ/ + /ŋ/ + /k/ = /θɪŋk/ 拼读给你「读得出」，IPA 给你「说得准」

th 你会念（不然 think 就读错了），nk 里的 n 写作 /ŋ/、不写作 /n/。 换成符号：/θ/ /ɪ/ /ŋ/ /k/ —— 四个符号，四个音，一步到位。

拼读对照：chair → ch + air → /tʃ/ + /eə/ + /r/ = /tʃeər/ 拼读给你「读得出」，IPA 给你「说得准」

ch 一个字母组合 = 一个符号 /tʃ/；air = /eə/ + /r/。 这种「一个字母组合对应一个符号」的地方，正是音标比拼读精确的地方。

六、今天要练的

  1. 读一遍上面的表：看到符号就念出来那个词（出声）。念不出来说明这个符号还没绑上词。
  2. 反向练（更重要）：盖住右边，看到 sheep cat think chair sing water —— 立刻写出里面每个音的符号。
  3. 挑 10 个你觉得最容易混的（比如 /ɪ/ vs /iː/、/æ/ vs /e/），在表旁边写上你的例词。

七、今天不用管的

  • ❌ 不用练发音（你的发音已经够标准了，这门课练的是符号）
  • ❌ 不用记每个例词的中文意思（意思你早就会，写出来只是为了让你确认「我认识这个词」）
  • ❌ 不用今天就背全 48 个（先有印象，后面 8 个单元一个一个来）

✅ 本节完成自查

  • 知道这门课练的是符号不是发音
  • 知道为什么「同一个音有很多拼法，但音标只有一个」
  • 48 个锚点词全部都认识（能说出中文意思）
  • 能反向写出 sheep cat think chair sing water 这 6 个词的完整音标
  • 知道元音 20 个 / 辅音 28 个是怎么分的
  • 想清楚了：你的英语底子够用，缺的是符号这张索引表
