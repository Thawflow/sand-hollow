中元音入门：三个中元音的口型位置

P02-S1 · 中元音入门：三个中元音的口型位置

🔤 英语音标速成课 · 单元 P02 · 第 1 节 · 约 35 分钟

今天学什么

中元音就是「嘴半开、舌平躺、不噘嘴」的一组音，本单元有三个：/ɜː/ /ə/ /ʌ/。 这一节只干一件事 —— 把三个音的口型位置立起来，像立三块积木。 bird about cup 你早就读得出来，今天只是给这几个声音贴上标签。

一、三个中元音的口型位置

共同点：嘴唇不圆不噘，舌头平放口腔中间，舌尖轻触下齿。

1. /ɜː/ —— 端着说

  • 写法：/ɜː/，冒号 ː 表示「拉长」
  • 要领：舌位居中不动，舌根别抬起来，嘴角向两边微拉；声音在喉咙中间带共鸣
  • 时长：长，拖足两拍，通常落在重读音节上
  • 例词：bird /bɜːd/、work /wɜːk/、nurse /nɜːs/、girl /ɡɜːl/、thirsty /ˈθɜːsti/

拼读对照：bird → b + ir + d → /b/ + /ɜː/ + /d/ = /bɜːd/ 拼读告诉你「b-i-r-d 怎么拼」，IPA 告诉你「那个 ir 其实不是 /ɪ/，是 /ɜː/」

2. /ə/ —— 瘫着说

  • 写法：/ə/，叫 schwa，「省电音」
  • 要领：整个人松下来，嘴唇和舌头都不用力；像被人轻轻撞一下发出的「呃」
  • 时长：极短；基本只出现在非重读音节
  • 例词：about /əˈbaʊt/、teacher /ˈtiːtʃə/、sofa /ˈsəʊfə/、banana /bəˈnɑːnə/

拼读对照：teacher → t + each + r → /t/ + /iː/ + /tʃ/ + /ə/ + /r/ = /ˈtiːtʃə(r)/ 拼读里那个 r 是拼出来的，IPA 告诉你：结尾其实是 /ə(r)/，舌头根本没抬

3. /ʌ/ —— 愣着说

  • 写法：/ʌ/
  • 要领：嘴张得比 /ə/ 大，像被看喉咙时发「啊」但又短又闷；舌尖抵下齿
  • 时长：短促有力
  • 例词：cup /kʌp/、bus /bʌs/、sun /sʌn/、money /ˈmʌni/、Monday /ˈmʌndeɪ/

拼读对照：cup → c + u + p → /k/ + /ʌ/ + /p/ = /kʌp/ 你拼读表里的「短元音 u」就是 /ʌ/ —— 它不是中文的「乌」，嘴要开得多

二、三个音摆在一起看

音 时长 松紧 嘴型 一句话记
/ɜː/ 长 居中 中等，保持不变 端着
/ə/ 短 最松 不管形状 瘫着
/ʌ/ 短 有点力 比前两个开 愣着

先别纠结它们像不像 —— 中元音本来就是三个「模糊邻居」。 先记住口型和时长，第二节教你怎么在真实句子里抓 /ə/。

三、今天要练的

  1. 手写：把 /ɜː/ /ə/ /ʌ/ 三个符号纸笔手写十遍
  2. 照镜子：对着镜子依次说 bird → about → cup，看嘴型差别
  3. 贴标签：给 work / sofa / bus 写出完整音标
  4. 找货：在自己读过的课文里找出 3 个含 /ə/ 的词，抄下来

四、今天不用管的

  • ❌ 不用管 /ə/ 具体躲在哪些位置（第二节专讲）
  • ❌ 不用纠结 /ɜː/ /ə/ /ʌ/ 的细微差别（第三节对比）
  • ❌ 不用管重音符号怎么标（先认准音本身）

✅ 本节完成自查

  • 手写了三个符号，纸笔
  • 说得出中元音的共同口型（不圆嘴、舌平放）
  • 能用「端着 / 瘫着 / 愣着」区分三个音
  • 给 work / sofa / bus 写出了完整音标
  • 知道这一单元的主角是 /ə/
/ə/ 弱读：最高频的音（about / teacher / banana）

P02-S2 · /ə/ 弱读：最高频的音（about / teacher / banana）

🔤 英语音标速成课 · 单元 P02 · 第 2 节 · 约 35 分钟

今天学什么

/ə/ 是整门课里出现最多的音 —— 一句普通英语里能有好几个。 今天搞懂三件事：什么是弱读、/ə/ 躲在哪些位置、怎么把它读得又短又懒。 读完这节，about teacher banana 里那几个 /ə/ 你自己就能听出来。

一、弱读：重音的背面

一个单词里，重读音节读重、读长、读清，弱读音节读轻、读短、读糊。

重读音节 弱读音节
音量 大 小
时长 长 短
元音 常常是长元音 / 双元音 退化成 /ə/

/ə/ 就是弱读音节的默认元音。 音节一被弱读，元音就懒得展开，缩成轻轻一个 /ə/。

二、/ə/ 的三张面孔

1️⃣ 词尾 -er / -or —— 最常见的产地

teacher /ˈtiːtʃə/、water /ˈwɔːtə/、sister /ˈsɪstə/、doctor /ˈdɒktə/、dinner /ˈdɪnə/、computer /kəmˈpjuːtə/

2️⃣ 非重读音节里 —— 一个词两个 /ə/

banana /bəˈnɑːnə/（头尾都弱）、camera /ˈkæmərə/、problem /ˈprɒbləm/、about /əˈbaʊt/

3️⃣ 小词读成 /ə/ —— 满嘴都是

a → /ə/、the → /ðə/、of → /əv/、for → /fə/、and → /ənd/、are → /ə/

例：a banana /ə bəˈnɑːnə/、the teacher /ðə ˈtiːtʃə/

拼读对照：about → a + b + ou + t → /ə/ + /b/ + /aʊ/ + /t/ = /əˈbaʊt/ 拼读给你「拼得出 a-b-ou-t」，IPA 告诉你「开头那个 a 其实不读 /æ/，读 /ə/」

拼读对照：banana → b + a + n + a + n + a → /b/ + /ə/ + /n/ + /ɑː/ + /n/ + /ə/ = /bəˈnɑːnə/ 拼读给你「三个 a」，IPA 告诉你「三个 a 只发作一个」—— 这就是弱读

⚠️ /ə/ 不是「随便读」，它是一个固定音，口型固定 —— 只是短、懒、不用力。 你把 teacher 的结尾读成又厚又重的「儿」，那是 /ər/ 没读出来。

三、今天要练的

  1. 数一数：读 about teacher banana computer camera water，每读一个就数出里面有几个 /ə/
  2. 圈小词：一段课文里的 a the of and for 全部圈出来，改读成 /ə/
  3. 拼读对照：给 sister doctor problem 写出完整音标
  4. 录音自查：录下自己读 banana 的语音，回放，听有没有把 /ə/ 读饱满

四、今天不用管的

  • ❌ 不用管 /ə/ 和 /ɜː/ /ʌ/ 的区别（第三节专门对比）
  • ❌ 不用追求每句都标准，先把 /ə/ 一个不漏地找出来
  • ❌ 不用纠结多音节词的重音标在哪（先认音）

✅ 本节完成自查

  • 能用一句话说清「弱读」是什么（读轻读短，元音退化）
  • 听得出 about teacher banana 里的 /ə/
  • 知道 -er / -or 结尾最常出 /ə/
  • 知道 a the of and 口语里读 /ə/
  • 给 sister doctor problem 写出了完整音标
/ɜː/ vs /ə/ vs /ʌ/：三者的区别与例词

P02-S3 · /ɜː/ vs /ə/ vs /ʌ/：三者的区别与例词

🔤 英语音标速成课 · 单元 P02 · 第 3 节 · 约 35 分钟

今天学什么

三个音都是中元音，长得像、听着近，最容易混。 今天用三条硬规则把它们分开：看长短、看重不重、看好嘴大小。 然后练最小对立词（只差一个音的那两个词），耳朵和嘴巴一起记。

一、三条硬规则

规则 /ɜː/ /ə/ /ʌ/
长度 长，拖足 极短 短促
重音 必在重读音节 必在非重读音节 两边都可能出现
嘴型 中等，保持不变 松，不成形 张开一点
拼写线索 重读的 -ir / -ur / -er 轻读的 -er / -or u / oo / o
感觉 端着 瘫着 愣着

一句话：/ɜː/ 是「被重读的 -er」，/ə/ 是「被弱读的 -er」，/ʌ/ 是「短促的 u」。

二、最小对立词：只差一个音

/ɜː/ ↔ /ʌ/ —— 一个拖长，一个短促

/ɜː/ /ʌ/ 意思
bird /bɜːd/ bud /bʌd/ 鸟 / 芽
fur /fɜː/ fun /fʌn/ 毛皮 / 乐趣
nurse /nɜːs/ nuts /nʌts/ 护士 / 坚果

拼读对照：nurse → n + ur + s + e → /n/ + /ɜː/ + /s/ = /nɜːs/ 拼读给你「n-u-r-s-e 怎么拼」，IPA 告诉你「这个 u 是 /ɜː/，不是 /ʌ/」

/ə/ ↔ /ʌ/ —— 一个瘫，一个愣

/ə/ /ʌ/ 意思
sofa /ˈsəʊfə/ supper /ˈsʌpə/ 沙发 / 晚餐
banana /bəˈnɑːnə/ bun /bʌn/ 香蕉 / 小面包

拼读对照：supper → s + u + pp + er → /s/ + /ʌ/ + /p/ + /ə/ = /ˈsʌpə/ 一个词里同时住着 /ʌ/ 和 /ə/ —— 前面那个重读、嘴张开；后面那个弱读、松掉

/ɜː/ ↔ /ə/ —— 同一个词，看它重不重

强读 弱读 例句
her /hɜː/ her /hə/ She's her best friend. / Give her the book.

规则：-er 拼写的词，被重读就读 /ɜː/，被弱读就读 /ə/。

三、今天要练的

  1. 最小对立：把上面 8 组词各读 5 遍，闭眼只靠耳朵分辨
  2. 同词两读：读 her water teacher work 时，故意一会儿重读一会儿弱读
  3. 标注：给 purple hurry worry money sun 写出完整音标
  4. 造句：用 bird bud 各造一个句子，读出来

四、今天不用管的

  • ❌ 不用管 /ɜː/ 和 /ɔː/ 的区别（下一单元的后元音）
  • ❌ 不用管英音美音差别
  • ❌ 不用追求「标准口音」，先把三个音分开

✅ 本节完成自查

  • 能用「长短 / 重不重 / 嘴大小」三条规则区分三个音
  • 听得出 bird vs bud、sofa vs supper
  • 知道 -er 重读是 /ɜː/、弱读是 /ə/
  • 给 purple hurry worry money sun 写出了完整音标
  • 一个词里能同时装下 /ʌ/ 和 /ə/（如 supper）
拼读对照实战：拼读推读音 + IPA 标注 + 找出词里的 /ə/

P02-S4 · 拼读对照实战：拼读推读音 + IPA 标注 + 找出词里的 /ə/

🔤 英语音标速成课 · 单元 P02 · 第 4 节 · 约 40 分钟

今天学什么

这一节是双系统合流：左边是拼读（你早就会的地基），右边是音标（这几天学的）。 三步走：① 用拼读推读音 → ② 写完整 IPA → ③ 圈出每个 /ə/。 推的时候大胆推 —— 对不上的地方正是例外词，那才是 IPA 真正派上用场的地方。

一、三步法演示：comfortable

第 1 步 · 拼读推读音 c-o-m-f-or-ta-ble → /k/ + /ʌ/ + /m/ + /f/ + /ɔː/ + /t/ + /ə/ + /b/ + /l/？

第 2 步 · 写完整 IPA comfortable /ˈkʌmfərtəbl/

第 3 步 · 圈 /ə/ 两个：/ˈkʌmf**ə**rt**ə**bl/ —— 一个在 for 后面，一个在 ta 后面。

对不上的地方：or 在这里既不是 /ɔː/ 也不是 /ɜː/，而是 /ər/，因为它不重读。 这就是为什么你需要 IPA：拼读给你「大概」，IPA 给你「答案」。

二、实战词表（8 个词）

单词 拼读推读音（自己先推） 完整 IPA
sister s + i + s + ter /ˈsɪstə/
doctor d + o + c + tor /ˈdɒktə/
water w + a + ter /ˈwɔːtə/
sugar s + u + g + ar /ˈʃʊɡə/
hungry h + u + n + gr + y /ˈhʌŋɡri/
number n + u + m + ber /ˈnʌmbə/
tomorrow t + o + m + or + row /təˈmɒrəʊ/
machine m + a + ch + in + e /məˈʃiːn/

三个观察：

  1. -er 结尾几乎都是 /ə/（sister / doctor / water / number）
  2. 第一个音节常常弱化：sugar /ˈʃʊɡə/、machine /məˈʃiːn/、tomorrow /təˈmɒrəʊ/
  3. ar 不总是 /ɑː/ —— sugar 是 /ʃʊɡə/，car 才是 /kɑː/。这就是例外词

拼读对照：sister → s + i + s + ter → /s/ + /ɪ/ + /s/ + /t/ + /ə/ = /ˈsɪstə/ 拼读给你「s-i-s-ter」，IPA 告诉你「er 是 /ə/，不是 /ɜː/」

拼读对照：hungry → h + u + n + gr + y → /h/ + /ʌ/ + /ŋ/ + /ɡ/ + /ri/ = /ˈhʌŋɡri/ 拼读给你「短元音 u」，IPA 告诉你「是 /ʌ/；而且 n 后面多了一个 /ŋ/」

拼读对照：machine → m + a + ch + in + e → /m/ + /ə/ + /ʃ/ + /iː/ + /n/ = /məˈʃiːn/ 拼读给你「m-a-ch-i-n-e」，IPA 告诉你「a 读 /ə/、结尾 e 不发音」

三、今天要练的

  1. 遮住右栏：只看单词，先用拼读推读音写出来，再对答案
  2. 圈 /ə/：把上表 8 个词的 /ə/ 全圈出来，数一数一共几个
  3. 自己加词：再加 5 个含 /ə/ 的常用词（提示：-er / -or / -ion / a / the / of）
  4. 找例外：给 sugar water comfortable 各写一句「拼读会推错在哪」

四、今天不用管的

  • ❌ 不用追求每个词都标对 —— 先分清重读 /ə/ 和弱读 /ə/
  • ❌ 不用管例外的元音该怎么解释（那是词典的工作）
  • ❌ 不用管英音美音差别，本单元统一用英音口径

✅ 本节完成自查

  • 8 个词都走完了「推读音 → 标 IPA → 圈 /ə/」
  • 圈出了全部 /ə/
  • 至少找出 2 个「拼读推不准」的词
  • 自己加了 5 个含 /ə/ 的词
  • 能说清拼读负责「大概」，IPA 负责「答案」

二、拼读互验：三个「拼读会推错」的词

单词 拼读大概会推成 真实 IPA 差别在哪
comfortable /ˈkʌmfɔːrtəbl/ /ˈkʌmfərtəbl/ or 轻读成 /ər/
hour /haʊər/ /ˈaʊə/ h 不发音
chocolate /ˈtʃɒkleɪt/ /ˈtʃɒklət/ 结尾 e 不发音

规律：拼读管「常见情况」，IPA 管「所有情况」。 推不动的词就是拼读的边界 —— 查音标。

拼读对照：mother → m + o + th + er → /m/ + /ʌ/ + /ð/ + /ə/ = /ˈmʌðə/ 拼读说「o 读 /ɒ/ 或 /ɔː/」，IPA 说「这里是 /ʌ/，er 是 /ə/」

拼读对照：together → t + o + geth + er → /t/ + /ə/ + /ɡ/ + /e/ + /ð/ + /ə/ = /təˈɡeðə/ 拼读说「t-o-g-e-t-h-e-r」，IPA 说「头尾都是 /ə/」
