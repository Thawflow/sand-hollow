P02-S1 · 中元音入门：三个符号，三组你认识的词

🔤 英语音标速成课 · 单元 P02 · 第 1 节 · 约 35 分钟

今天学什么

不学发音。你的 cup、bird、about 读得比很多大人准。

今天只做一件事：给三个中元音符号 /ɜː/ /ə/ /ʌ/ 贴词签。

符号 你早就认识的词 中文
/ɜː/ bird girl work nurse turn 鸟 / 女孩 / 工作 / 护士 / 转弯
/ə/ about teacher banana sister problem 关于 / 老师 / 香蕉 / 姐妹 / 问题
/ʌ/ cup bus sun run mother 杯子 / 公交车 / 太阳 / 跑 / 妈妈

十五个词，全是你会读、会背、知道意思的。今天只加名字，不加声音。

一、为什么这三个要一起学

它们有一个共同点：声音都是从嘴巴中间出来的，不像前元音那样靠前，也不像后元音那样靠后。

所以英式 44 音标把它们三个放在一起，叫中元音。

前元音那一单元你用的是「前」，这一单元用的是「中」——这是分类方式变了，不是你的读法变了。

二、三组词签

  • /ɜː/ —— bird 鸟、girl 女孩、work 工作、nurse 护士、turn 转弯：长长的、稳稳的一声。
  • /ə/ —— about 关于、teacher 老师、banana 香蕉、sister 姐妹、problem 问题：轻轻的、短短的一声，英语里出现得最多的音。
  • /ʌ/ —— cup 杯子、bus 公交车、sun 太阳、run 跑、mother 妈妈：短短的一声，往上兜一下。

三个符号，长的、弱的、兜的，各有各的词签。

三、拼读对照：左边拼法，右边符号

拼读对照：bird → b + ir + d → /b/ + /ɜː/ + /d/ = /bɜːd/ 拼读给你「读得出」，IPA 给你「说得准」

拼读对照：cup → c + u + p → /k/ + /ʌ/ + /p/ = /kʌp/ 拼读给你「读得出」，IPA 给你「说得准」

拼读对照：sister → s + i + s + t + er → /s/ + /ɪ/ + /s/ + /t/ + /ə/ = /ˈsɪstə/ 拼读给你「读得出」，IPA 给你「说得准」

发现了吗？ sister 结尾的 er 写作 /ə/，bird 中间的 ir 却写作 /ɜː/。拼写相似，符号不同——这就是必须记符号的理由。

四、反向练：给词写符号

cup girl bus teacher sun work mother sister

逐个写出完整音标，写完念一遍核对。

五、今天要练的

  1. 抄词卡：三个符号，每个配四个词，写在符号旁边。
  2. 反向练：上面八个词逐个写音标。
  3. 朗读：十五个词读三遍，每个词读的时候在脑子里喊它的符号。
  4. 找一找：在课外书里找三个含 /ə/ 的词，抄下来。

六、今天不用管的

  • ❌ 不用改你的声音——这节课只记符号。
  • ❌ 不用现在就会分清三个（下一节专门打 /ə/，再下一节三个一起比）。
  • ❌ 不用管音节划分和重音（P02-S4 才用得上）。
  • ❌ 不用背中文意思，你早就会了。

✅ 本节完成自查

  • 知道这节课练的是符号，不是声音
  • 三个符号 /ɜː/ /ə/ /ʌ/ 各自至少配出 3 个自己认识的词
  • 给 cup girl bus teacher 写出完整音标
  • 说得清「中元音」是按声音位置分的类
  • 知道 sister 的 er 写 /ə/，而 bird 的 ir 写 /ɜː/
/ə/ 弱读：英语里出现最多的那个音

P02-S2 · /ə/ 弱读：英语里出现最多的那个音

🔤 英语音标速成课 · 单元 P02 · 第 2 节 · 约 35 分钟

今天学什么

/ə/ 是 44 个符号里出现频率最高的一个。你说英语时，一句话里它要出现好几次。

今天要搞清一件事：什么时候那个音写成 /ə/，什么时候写成别的符号。

符号 你早就认识的词 中文
/ə/ about teacher banana sister problem 关于 / 老师 / 香蕉 / 姐妹 / 问题
/ɜː/ bird girl work nurse turn 鸟 / 女孩 / 工作 / 护士 / 转弯

一、弱读的意思

一个单词里，重音所在的那个音节，符号写得具体；不重音的那个音节，元音就写成 /ə/。

看 teacher /ˈtiːtʃə/：

  • tea 这一半在重音上 → 元音写作 /iː/（具体）
  • cher 这一半不在重音上 → 元音写作 /ə/（弱读）

再看 sister /ˈsɪstə/：前半 /ɪ/，后半 /ə/。再看 problem /ˈprɒbləm/：前半 /ɒ/，后半 /ə/。

规则一句话：不重音的音节，元音写成 /ə/。

二、/ə/ 在单音节词里

about /əˈbaʊt/：a 不在重音上 → 写作 /ə/。

这一点最容易错。很多人看到 about 就写 /a/，其实它写的是 /ə/。因为 about 是介词，重音落在后面的 bout 上。

三、拼读对照

拼读对照：teacher → t + ea + ch + er → /t/ + /iː/ + /tʃ/ + /ə/ = /ˈtiːtʃə/ 拼读给你「读得出」，IPA 给你「说得准」

拼读对照：banana → b + a + n + a + n + a → /b/ + /ə/ + /n/ + /ɑː/ + /n/ + /ə/ = /bəˈnɑːnə/ 拼读给你「读得出」，IPA 给你「说得准」

拼读对照：about → a + b + ou + t → /ə/ + /b/ + /aʊ/ + /t/ = /əˈbaʊt/ 拼读给你「读得出」，IPA 给你「说得准」

banana 一口气三个元音：/ə/、/ɑː/、/ə/。头尾两个都是弱读，中间那个重读 —— 这就是「弱读」的最好例子。

四、反向练

problem sister teacher about banana work girl bird

其中五个词里藏着 /ə/，三个没有（work girl bird）。写完音标，数一数你一共写了几个 /ə/。

五、今天要练的

  1. 抄规则：「不重音的音节，元音写成 /ə/」写进笔记本。
  2. 反向练：上面八个词逐个写音标，数出 /ə/ 的个数。
  3. 朗读：teacher sister problem banana about 各读三遍，每读一个词就指出哪个音节是弱读。
  4. 找一找：在课外书里找三个弱读的 /ə/，抄下来。

六、今天不用管的

  • ❌ 不用改你的声音——你说话时弱读本来就做得很对。
  • ❌ 不用管 /ɑː/ /aʊ/ 这些具体符号（别的单元才正式学）。
  • ❌ 不用研究为什么弱读会这样（那是语音学的事，你只要会标）。
  • ❌ 不用纠结多音节词的连读。

✅ 本节完成自查

  • 背得出规则：不重音的音节，元音写成 /ə/
  • 给 teacher sister problem about 写出音标
  • 知道 about 开头写 /ə/ 而不是 /a/
  • 知道 banana 里有三个元音符号：/ə/ /ɑː/ /ə/
  • 知道 /ə/ 是 44 个符号里出现频率最高的一个
/ɜː/ vs /ə/ vs /ʌ/：三个一起比

P02-S3 · /ɜː/ vs /ə/ vs /ʌ/：三个一起比

🔤 英语音标速成课 · 单元 P02 · 第 3 节 · 约 35 分钟

今天学什么

三个符号摆在一起最容易混。今天把三者的分工说清，再靠词签锁死。

符号 你早就认识的词 中文
/ɜː/ bird girl work nurse turn 鸟 / 女孩 / 工作 / 护士 / 转弯
/ə/ about teacher banana sister problem 关于 / 老师 / 香蕉 / 姐妹 / 问题
/ʌ/ cup bus sun run mother 杯子 / 公交车 / 太阳 / 跑 / 妈妈

一、三句话分工

  1. /ɜː/ —— 一个词里最能被强调的那一半，元音写 /ɜː/。work /wɜːk/、bird /bɜːd/。
  2. /ə/ —— 一个词里不被强调的那一半，元音写 /ə/。sister /ˈsɪstə/ 的后半。
  3. /ʌ/ —— 一个独立的、内容饱满的音节，元音写 /ʌ/。cup /kʌp/、sun /sʌn/。

mother /ˈmʌðə/ 最妙：前一半 /ʌ/（内容饱满），后一半 /ə/（弱读）。 一个词里同时住着两个。

二、最小对比：只差一个音

左边 音标 中文 右边 音标 中文
burn /bɜːn/ 烧 bun /bʌn/ 小圆面包
work /wɜːk/ 工作 walk /wɔːk/ 走路
bird /bɜːd/ 鸟 bud /bʌd/ 花苞

burn 和 bun 只差一个音标符号，意思完全不同。你读得出来——说明你的耳朵没问题，缺的只是纸上的名字。

三、/ə/ 和 /ɜː/ 的分界

同一个词的两种元音，最能说明问题：

单词 音标 前半 后半
teacher /ˈtiːtʃə/ /iː/ /ə/
sister /ˈsɪstə/ /ɪ/ /ə/
worker /ˈwɜːkə/ /ɜː/ /ə/
problem /ˈprɒbləm/ /ɒ/ /ə/

重音在前的音节，元音写得具体；后面那一截写 /ə/。

四、拼读对照

拼读对照：cup → c + u + p → /k/ + /ʌ/ + /p/ = /kʌp/ 拼读给你「读得出」，IPA 给你「说得准」

拼读对照：mother → m + o + th + er → /m/ + /ʌ/ + /ð/ + /ə/ = /ˈmʌðə/ 拼读给你「读得出」，IPA 给你「说得准」

拼读对照：work → w + or + k → /w/ + /ɜː/ + /k/ = /wɜːk/ 拼读给你「读得出」，IPA 给你「说得准」

注意 or 在这里写 /ɜː/——英式音标里，工作这个 or 就是 /ɜː/。

五、今天要练的

  1. 抄词卡：三个符号，每个配四个词。
  2. 反向练：给 burn bun mother worker sun turn banana nurse 写音标。
  3. 朗读：burn bun work walk 各读三遍，每读一个词喊出符号。
  4. 找一找：在课外书里找三个含 /ɜː/ 的词抄下来。

六、今天不用管的

  • ❌ 不用改你的声音——burn 和 bun 你分得比谁都清。
  • ❌ 不用研究 /ɔː/（后面单元）。
  • ❌ 不用纠结 or 为什么这样标（记住结果就行）。
  • ❌ 不用背每个词的重音位置，重音点 ˈ 在 P02-S4 系统练。

✅ 本节完成自查

  • 三个符号 /ɜː/ /ə/ /ʌ/ 各自至少配出 3 个自己认识的词
  • 给 burn bun mother worker 写出音标
  • 能用一句话说出三者的分工
  • 知道 mother /ˈmʌðə/ 里同时有 /ʌ/ 和 /ə/
  • 知道重音在前的音节元音写得具体，后面写 /ə/
拼读对照实战：四步跑中元音

P02-S4 · 拼读对照实战：四步跑中元音

🔤 英语音标速成课 · 单元 P02 · 第 4 节 · 约 40 分钟

今天学什么

今天把前元音学过的四步法升级：同样的四步，换上中元音的符号。

  1. 圈元音：一个音节一个元音。
  2. 配符号：前元音那套不够用了，今天从 /ɜː/ /ə/ /ʌ/ 里挑。
  3. 配辅音。
  4. 加外壳：前后加 /，多音节词标重音 ˈ。

二、跑五个词

cup —— 元音 u → /ʌ/ → c→/k/、p→/p/ → /kʌp/

work —— 元音 or → /ɜː/ → w→/w/、k→/k/ → /wɜːk/

sun —— 元音 u → /ʌ/ → s→/s/、n→/n/ → /sʌn/

teacher —— 元音两个：ea 重读 → /iː/，er 弱读 → /ə/ → t→/t/、ch→/tʃ/ → 重音在第一音节 → /ˈtiːtʃə/

problem —— 元音两个：o 重读 → /ɒ/，e 弱读 → /ə/ → /ˈprɒbləm/

写不出来的音标，就是还没配上的符号——回 P02-S3 查。

三、拼读对照：四步压成一行

拼读对照：sun → s + u + n → /s/ + /ʌ/ + /n/ = /sʌn/ 拼读给你「读得出」，IPA 给你「说得准」

拼读对照：work → w + or + k → /w/ + /ɜː/ + /k/ = /wɜːk/ 拼读给你「读得出」，IPA 给你「说得准」

拼读对照：teacher → t + ea + ch + er → /t/ + /iː/ + /tʃ/ + /ə/ = /ˈtiːtʃə/ 拼读给你「读得出」，IPA 给你「说得准」

拼读对照：problem → pr + o + bl + e + m → /p/ + /r/ + /ɒ/ + /b/ + /l/ + /ə/ + /m/ = /ˈprɒbləm/ 拼读给你「读得出」，IPA 给你「说得准」

四、批量实战

单词 你写的音标 答案
bus /bʌs/
bird /bɜːd/
sister /ˈsɪstə/
run /rʌn/
girl /ɡɜːl/
about /əˈbaʊt/
banana /bəˈnɑːnə/
turn /tɜːn/

五、今天要练的

  1. 默写四步法：圈元音 → 配符号 → 配辅音 → 加外壳。
  2. 批量实战：上面八个词先自己写，再对答案。
  3. 数一数：八个词里，一共有几个 /ə/？
  4. 出声核对：每个词写完念一遍，念的那一声和符号对不上就重配。

六、今天不用管的

  • ❌ 不用改你的声音——四步法只动笔。
  • ❌ 不用追求写得快，先写对。
  • ❌ 不用管 /ɑː/ /aʊ/ 这些还没正式学的符号。
  • ❌ 不用管连读和失爆（很高级的东西，等符号熟了再说）。

✅ 本节完成自查

  • 能背出四步法：圈元音 → 配符号 → 配辅音 → 加外壳
  • 独立写出 bus bird sister run 的音标
  • 知道 teacher 里两个元音是 /iː/ 和 /ə/
  • 知道 problem 里两个元音是 /ɒ/ 和 /ə/
  • 知道符号写不出来时回去查表，而不是猜

今天学什么

单元收尾。今天把三个中元音符号一口气过一遍，拆掉一个最常见的坑，然后自查。

一、15 词大考（先自己写，再对答案）

符号 词 音标
/ɜː/ bird /bɜːd/
/ɜː/ girl /ɡɜːl/
/ɜː/ work /wɜːk/
/ɜː/ nurse /nɜːs/
/ɜː/ turn /tɜːn/
/ə/ about /əˈbaʊt/
/ə/ teacher /ˈtiːtʃə/

二、一个大坑：/a/ 不等于 /æ/，也不等于 /ʌ/

mother 里的 o 写作 /ʌ/，about 里的 a 写作 /ə/，banana 中间的 a 写作 /ɑː/。

同一个元音字母，在不同词里可以是三个不同的符号。 所以永远不要背「字母 = 音标」，要背「词 = 音标」。

三、最小对比：听不出来也要写得出来

左边 音标 中文 右边 音标 中文
burn /bɜːn/ 烧 bun /bʌn/ 小圆面包
work /wɜːk/ 工作 walk /wɔːk/ 走路
bird /bɜːd/ 鸟 bud /bʌd/ 花苞
sit /sɪt/ 坐 seat /siːt/ 座位

每一对都只差一个音标符号。 这就是音标存在的意义：把你的耳朵锁死在一个个具体的符号上。

四、拼读对照：符号 → 词

反过来也练一次：给你符号，你去找词。

拼读对照：bus → b + u + s → /b/ + /ʌ/ + /s/ = /bʌs/ 拼读给你「读得出」，IPA 给你「说得准」

拼读对照：girl → g + ir + l → /ɡ/ + /ɜː/ + /l/ = /ɡɜːl/ 拼读给你「读得出」，IPA 给你「说得准」

拼读对照：mother → m + o + th + er → /m/ + /ʌ/ + /ð/ + /ə/ = /ˈmʌðə/ 拼读给你「读得出」，IPA 给你「说得准」

再玩一次：给 /ɜː/ /ə/ /ʌ/ 各写一个你自己的词（从上面十五个里挑，或写你生活里的词）。

五、今天要练的

  1. 闭卷默写：十五个词的音标，一口气写完，再对答案。
  2. 最小对比朗读：四对各读三遍，每读一个词，喊出它用的是哪个符号。
  3. 反向练：给你一个符号，5 秒内说出一个配它的词。
  4. 查漏：错的每一个，抄在旁边写上正确的那个。

六、今天不用管的

  • ❌ 不用改你的声音——这一整个单元你没改过一个音。
  • ❌ 不用扩展到后元音（P03 开始是 /ɑː/ /ɒ/ /ɔː/）。
  • ❌ 不用追求百分百不写错，写错能查回来就算过关。
  • ❌ 不用背中文意思。

✅ 本节完成自查

  • 三个符号 /ɜː/ /ə/ /ʌ/ 都能秒配出至少 3 个词
  • 十五个锚点词的音标能闭卷写出一半以上
  • 说得清「不重音的音节，元音写成 /ə/」
  • 知道 burn /bɜːn/ 和 bun /bʌn/ 只差一个符号
  • 知道 mother /ˈmʌðə/ 里同时有 /ʌ/ 和 /ə/
  • 知道这整个单元你练的是符号，不是声音
