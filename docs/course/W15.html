一、概念：程序要有「运气」（3 分钟）

到上周为止，所有程序都是「确定」的——同样的输入，永远给同样的输出。但有些事天生带运气：

  • 游戏：敌人随机出现、宝物随机掉落
  • 抽奖：从候选名单里抽一个幸运儿
  • 密码：随机拼一串谁也猜不到的字符

Python 的 random 模块专门管「运气」。今天认识它的三招主力。

二、三招主力 + 两位替补（5 分钟）

用之前先请它进门：

import random
招式 作用 例子
random.randint(a, b) a 到 b 的整数（含两头） randint(1, 6) 掷骰子
random.choice(列表) 从列表里随机抽一个 choice(fruits)
random.shuffle(列表) 把列表顺序打乱 洗牌

两位替补混个脸熟：random.random() 给 0.0~1.0 的随机小数；random.sample(列表, n) 抽 n 个不重复的。

import random

fruits = ["apple", "banana", "cherry"]
cards = [1, 2, 3, 4, 5]

print(random.randint(1, 6))
print(random.choice(fruits))
random.shuffle(cards)
print(cards)

同一个文件多 Run 几次——每次输出都不一样，这就是随机。

三、必看的坑：randint 含两头（3 分钟）

random.randint(1, 10)   # 1 到 10，10 也可能抽到
range(1, 10)            # 1 到 9，10 永远不来

randint 两头都含，range 不含尾巴——老朋友 range 的规矩在 randint 这里不适用，混了就差一个数。

另外两个小坑：忘了 import random 会报 NameError；shuffle 直接改原列表、没有返回值（想留原版先 copy()）。

今日口诀： randint 两头含，choice 抽一个，shuffle 原地洗。

三、判定逻辑拆开看（4 分钟）

elif 那长串其实是三个「赢」的条件用 or 连起来：

win = (player == "rock" and computer == "scissors") \
   or (player == "scissors" and computer == "paper") \
   or (player == "paper" and computer == "rock")
  • 每个小括号 = 一种「刚好克制」的组合
  • 括号之间用 or：满足任意一种就是赢

判断顺序也有讲究：先排除平局（==），再判赢，剩下的自然判负——平局不先排掉，赢的条件永远轮不到细看。

昨天的石头剪刀布只打一局就结束——真实对战是「三局两胜」「五局三胜」：单局有运气，打满多局才见真功夫。

升级三件事：

  • 一局 → 五局（for 循环，W04 老朋友）
  • 加两个计分器（变量，每局赢的那方 +1）
  • 打完宣布总冠军

二、计分器：先建空盒子（4 分钟）

player_score = 0
computer_score = 0

计分器就是普通变量——开局建两个 0，谁赢一局就 += 1。在循环外建、循环里加：建在循环外才能一路累加；建在循环里，每局都会被清零重开（W04 累加器思想）。

三、五局制完整骨架（4 分钟）

只读不敲，眼睛走一遍：

import random

choices = ["rock", "paper", "scissors"]
player_score = 0
computer_score = 0

for round in range(1, 6):
    print(f"--- Round {round} ---")
    player = input("Your choice: ").strip().lower()
    computer = random.choice(choices)
    print(f"You: {player}, Computer: {computer}")

    if player == computer:
        print("Tie!")
    elif (player == "rock" and computer == "scissors") or \
         (player == "scissors" and computer == "paper") or \
         (player == "paper" and computer == "rock"):
        print("You win this round!")
        player_score += 1
    else:
        print("Computer wins this round!")
        computer_score += 1

print(f"Final: You {player_score} - Computer {computer_score}")

逐段对账：

部件 作用
for round in range(1, 6) 1 到 5——五局；round 是局号（range 不含尾巴，W04 铁律）
player_score += 1 只在赢的分支加——平局谁都不得分
最后一行 循环外宣布总分（缩进 0 格，不归 for 管）

四、宣布总冠军（2 分钟）

总分出来后再加一段（循环外、紧跟 print）：

if player_score > computer_score:
    print("You won the match!")
elif player_score < computer_score:
    print("Computer won the match!")
else:
    print("It's a tie overall!")

三元老朋友：> 赢、< 输、== 冠军（else 兜底）——注意这是赛后总评，和循环里「每局判定」是两套判断，别混进同一个缩进层。

今日口诀： 循环外建分、循环里加分、循环外宣布冠军。

W15-S4 · beats 字典重构 + emoji

每日节奏（v1.9）： 本篇纯阅读 ≈11 分钟，读完做当天作业 ≈10 分钟，总共 ≤25 分钟 不需要 Thonny——正文一个字都不用敲，作业时间才开编辑器 难度：⭐⭐⭐ · 本篇对应原 W12-L02 的「第三版字典判定 + 第四版 emoji」部分

一、概念：规则也是数据（3 分钟）

昨天的判定长串（三个 or 的 elif）能跑，但——游戏规则本身写成了一堆 if，改一条规则要翻半天代码。

换思路：石头剪刀布的规则是一张「谁克谁」对照表——对照表 = 字典（W10 全程都在练这个）。

beats = {
    "rock": "scissors",
    "scissors": "paper",
    "paper": "rock",
}

读法：键克值——rock 克 scissors、scissors 克 paper、paper 克 rock。规则装进字典，判定就变成查表。

二、一行撂倒长判定（4 分钟）

if player == computer:
    result = "tie"
elif beats[player] == computer:
    result = "win"
else:
    result = "lose"

beats[player] 存的是 player 能打败的对手——所以「beats[player] == computer」成立时，computer 正好是 player 的手下败将，player 赢。

三行读完整个逻辑：先排平局、再查表判赢、剩下判负——和昨天那串 or 的结果一模一样，但读起来像一句话。这就是「重构」：功能不变，代码换更顺的写法。

三、前提：输入必须合法（2 分钟）

查表前有个前提——beats[player] 里的 player 必须是三个键之一。玩家手滑输入 "rockkk" 会怎样？KeyError 摔门（W10-S2 的老坑）。

昨天作业已经练过安检门，今天把它焊在查表前面：

if player not in choices:
    print("Invalid choice!")
    continue

continue = 跳过这局直接进下一局（W04/W05 见过）。先安检、后查表，永远。

四、emoji 输出（2 分钟）

给三种拳配上 emoji 字典，输出瞬间有画面：

emojis = {

\U0001FAA8 这种是 emoji 的转义写法（Unicode 编号）——比直接粘 emoji 进代码稳，不会被编辑器悄悄换成别的字符。

今日口诀： 规则进字典，判定变查表；查表先安检，输出配 emoji。

三、伤害公式带随机（3 分钟）

def calc_dmg(attacker_atk, defender_def):
    base = attacker_atk - defender_def
    return max(1, base + random.randint(-2, 3))
  • 攻击减防御 = 基础伤害，再 ±随机浮动——每刀不一样，战斗才有心跳
  • max(1, ...)：保底 1 点，防御太高也不至于「打不动」死循环

四、战斗回合循环（3 分钟）

def battle(player, enemy):
    while enemy["hp"] > 0 and player["hp"] > 0:
        action = input("(attack/run): ").strip().lower()
        if action == "run":
            return "ran"
        dmg = calc_dmg(player["attack"], enemy["defense"])
        enemy["hp"] -= dmg
        print(f"You hit {enemy['name']} for {dmg}! HP left: {enemy['hp']}")
        if enemy["hp"] <= 0:
            player["exp"] += enemy["exp"]
            return "won"
        dmg = calc_dmg(enemy["attack"], player["defense"])
        player["hp"] -= dmg
        print(f"{enemy['name']} hits you for {dmg}! HP left: {player['hp']}")
    return "lost"

三个看点：while 双条件——两边都活着才继续打；return 三种结局——won / lost / ran；你一刀我一刀 = 一个回合，循环自动转下一回合。

五、升级的甜头（3 分钟）

def check_levelup(player):
    if player["exp"] >= player["level"] * 50:
        player["level"] += 1
        player["hp"] += 20
        print(f"*** LEVEL UP! Lv{player['level']} ***")

经验够等级×50 就升级：涨血、回满。字典传进函数、函数直接改它的键——改的是本体，不是复印件。

第 2 步 · 战斗循环（15 分钟）

def battle(player, enemy):
    """战斗循环：双方轮流扣血，返回赢家"""
    print(f"\n⚔️ {player['name']} VS {enemy['name']}!")
    while player["hp"] > 0 and enemy["hp"] > 0:
        # 玩家攻击
        dmg = random.randint(player["atk"] - 3, player["atk"] + 3)
        enemy["hp"] -= dmg
        print(f"  {player['name']} 攻击 → {enemy['name']} 扣 {dmg} HP (剩 {enemy['hp']})")
        if enemy["hp"] <= 0:
            break
        # 敌人攻击
        dmg = random.randint(enemy["atk"] - 2, enemy["atk"] + 2)
        player["hp"] -= dmg
        print(f"  {enemy['name']} 攻击 → {player['name']} 扣 {dmg} HP (剩 {player['hp']})")
    if player["hp"] > 0:
        print(f"  🎉 {player['name']} 胜利！获得 {enemy['gold']} gold")
        player["gold"] += enemy["gold"]
        return "win"
    else:
        print(f"  💀 {player['name']} 战败...")
        return "lose"

第 3 步 · 主循环 + 升级 + 商店（15 分钟）

def shop(player):
    """升级系统：用 gold 买 HP / ATK"""
    print(f"\n🏪 商店 (你有 {player['gold']} gold)")
    print("  1. 补血 30HP → 10 gold")
    print("  2. 加攻击 +5 → 20 gold")
    choice = input("  选 [1/2/0=离开]: ")
    if choice == "1" and player["gold"] >= 10:
        player["hp"] += 30
        player["gold"] -= 10
        print("  ✓ HP+30")
    elif choice == "2" and player["gold"] >= 20:
        player["atk"] += 5
        player["gold"] -= 20
        print("  ✓ ATK+5")

def main():
    player = new_player()
    level = 1
    while player["hp"] > 0:
        print(f"\n=== 关卡 {level} ===")
        enemy = new_enemy(level)
        result = battle(player, enemy)
        if result == "lose":
            print("\n游戏结束！")
            break
        # 战后：补血 + 商店
        player["hp"] = min(100, player["hp"] + 20)
        shop(player)
        level += 1
    print(f"\n最终等级：{level - 1} | 总 gold：{player['gold']}")

if __name__ == "__main__":
    main()
