三、设计图（15 分钟）

打开草稿纸，画出作品的结构：

必须包含

  1. 功能清单：3-5 个核心功能（每个功能 1-2 句描述）
  2. 数据结构：用什么字典 / 列表存数据
  3. 函数清单：拆成几个函数（每个函数做什么）
  4. 菜单/界面：用户怎么用（菜单？命令？参数？）

Example: Class Grade Analyzer

Features:

  1. Input N student records (name + score)
  2. Show average, highest, lowest
  3. Show pass rate (>= 60)
  4. Show distribution (0-59, 60-79, 80-100)

Data structures:

  • students = [{"name": ..., "score": ...}, ...]
  • brackets = {"0-59": 0, "60-79": 0, "80-100": 0}

Functions:

  • add_student() - add one student
  • show_stats() - show statistics
  • show_distribution() - show distribution
  • main() - main menu

Interface (pseudo-ASCII example):

=== Grade Analyzer ===
1. Add student
2. Show stats
3. Show distribution
4. Quit

students = []

def add_student():

跑一遍：选 1，输入名字分数，看到「Added ...」。

第二块：show_stats

def show_stats():
    if not students:
        print("No students yet")
        return
    scores = [s["score"] for s in students]
    avg = sum(scores) / len(scores)
    print(f"Count: {len(students)}")
    print(f"Average: {avg:.1f}")
    print(f"Highest: {max(scores)}")
    print(f"Lowest: {min(scores)}")

跑：先 add 几个学生，再 show_stats，看到统计。

第三块：show_distribution

def show_distribution():
    brackets = {"0-59": 0, "60-79": 0, "80-100": 0}
    for s in students:
        sc = s["score"]
        if sc < 60:
            brackets["0-59"] += 1
        elif sc < 80:
            brackets["60-79"] += 1
        else:
            brackets["80-100"] += 1
    for b, count in brackets.items():
        print(f"{b}: {count}")

跑：add 几个学生（涵盖三个分数段），看分布。

第四块：保存到文件

import json
import os

DATA_FILE = "students.json"

def save_data():
    with open(DATA_FILE, "w") as f:
        json.dump(students, f)
    print("Saved!")

def load_data():
    global students
    if os.path.exists(DATA_FILE):
        with open(DATA_FILE) as f:
            students = json.load(f)
        print(f"Loaded {len(students)} students")

# Call load_data() at start of main

跑：add 几个学生 → quit → 重启 → 看 loaded。

四、⚠️ 新手三大坑（5 分钟）

  1. 一次写完再跑：写了一堆代码发现错在哪。每块写完就跑

  3. global 变量混乱：函数间传数据用 global（可行但乱）。优先用返回值 + 参数
