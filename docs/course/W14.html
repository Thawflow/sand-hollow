一、核心想法（3 分钟）

镜子里有镜子——镜子里还有镜子，无穷无尽。

递归 = 程序版的"镜子里有镜子"。函数调用自己，再调用自己，直到某个出口。

def count_down(n):
    '''Print n, n-1, n-2, ..., 0, then 'Go!'.'''
    if n < 0:                  # exit condition (base case)
        return
    print(n)
    count_down(n - 1)          # call self with smaller n

两个关键：

  1. 出口条件：n < 0 时停止
  2. 自调 + 缩小：count_down(n - 1) 调自己，n 每次减 1

三、阶乘：经典例子（5 分钟）

5! = 5 × 4 × 3 × 2 × 1 = 120

递归定义：

  • 0! = 1（出口）
  • n! = n × (n-1)!
def factorial(n):
    '''Return n! using recursion.'''
    if n == 0:                 # base case
        return 1
    return n * factorial(n - 1)   # recursive case

调用栈（自顶向下展开，从底向上收）：

factorial(5)
  = 5 * factorial(4)
       = 4 * factorial(3)
            = 3 * factorial(2)
                 = 2 * factorial(1)
                      = 1 * factorial(0)
                           = 1
                      = 1 * 1 = 1
                 = 2 * 1 = 2
            = 3 * 2 = 6
       = 4 * 6 = 24
  = 5 * 24 = 120

def fib(n):
    '''Return the nth Fibonacci number.'''
    if n == 0 or n == 1:   # base case

五、深入了解：递归的历史八卦（3 分钟）

递归 1958 年由 John McCarthy 在 LISP 里提出——他也是 AI 概念的发明人（"人工智能"这个词就是他 1956 年达特茅斯会议造的）。

LISP = List Processing——列表处理语言，递归是核心。Python 的 list 操作深受 LISP 影响。

AI 工程师为什么爱递归：

  • 树结构：决策树、搜索树、语法树——天然分形
  • 图算法：DFS（深度优先搜索）就是递归
  • 分治：大问题拆同款小问题（快排、归并）

没学递归的 AI 工程师 = 内功缺一半。

六、何时用：递归 vs 迭代（3 分钟）

  • 树/图问题 = 递归（清晰胜过性能）
  • 大数据 = 迭代（性能胜过清晰）

三、记忆化：算一次存起来（5 分钟）

def fib_memo(n, memo=None):
    '''Fibonacci with memoization.'''
    if memo is None:
        memo = {}
    if n in memo:                 # cache hit
        return memo[n]
    if n == 0 or n == 1:          # base case
        memo[n] = n
        return memo[n]
    memo[n] = fib_memo(n - 1, memo) + fib_memo(n - 2, memo)
    return memo[n]

关键：算过的存 memo[n]，下次直接拿。

四、对比：朴素 vs 记忆化（5 分钟）

import time

def fib_naive(n):
    if n == 0 or n == 1: return n
    return fib_naive(n - 1) + fib_naive(n - 2)

def fib_memo(n, memo=None):
    if memo is None: memo = {}
    if n in memo: return memo[n]
    if n == 0 or n == 1:
        memo[n] = n
        return n
    memo[n] = fib_memo(n - 1, memo) + fib_memo(n - 2, memo)
    return memo[n]

# Test: fib(35)
n = 35
start = time.time(); fib_naive(n); t1 = time.time() - start
start = time.time(); fib_memo(n); t2 = time.time() - start
print(f'fib_naive({n}): {t1:.2f}s')
print(f'fib_memo({n}): {t2:.4f}s')
print(f'Memo is {t1/t2:.0f}x faster')

六、何时用：加缓存 vs 不加（3 分钟）

场景 加缓存 不加
重复子问题（递归树） ✓ 必加 太慢
一次性计算 ✗ 浪费内存 ✓
输入空间大 ✓（dict 索引 O(1)） ✗ 重新算
内存紧张 ✗（占空间） ✓

Python 内置：functools.lru_cache —— 一行加缓存：

from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    if n == 0 or n == 1: return n
    return fib(n - 1) + fib(n - 2)

比手动 memo dict 更简洁。

一、3 种 fib 实现（5 分钟）

import time
from functools import lru_cache

# 1. Naive (O(2^n))
def fib_naive(n):
    if n < 2:
        return n
    return fib_naive(n - 1) + fib_naive(n - 2)

# 2. Manual memo (O(n))
def fib_memo(n, memo={}):
    if n in memo:
        return memo[n]
    if n < 2:
        return n
    memo[n] = fib_memo(n - 1, memo) + fib_memo(n - 2, memo)
    return memo[n]

# 3. @lru_cache (O(n), 1-line)
@lru_cache(maxsize=None)
def fib_cache(n):
    if n < 2:
        return n

二、递归解迷宫（5 分钟）

def solve_maze(maze, x, y, end_x, end_y, path=None):
    '''Recursive DFS. Returns path or None.'''
    if path is None:
        path = []

    # boundary check
    rows, cols = len(maze), len(maze[0])
    if not (0 <= x < rows and 0 <= y < cols):
        return None
    # hit wall or visited
    if maze[x][y] == 1 or (x, y) in path:
        return None
    # reach exit
    if x == end_x and y == end_y:
        return path + [(x, y)]

    # mark visited
    path.append((x, y))

    # try 4 directions: up, right, down, left
    for dx, dy in [(-1, 0), (0, 1), (1, 0), (0, -1)]:
        result = solve_maze(maze, x + dx, y + dy, end_x, end_y, path)
        if result:
            return result

    # backtrack on dead end
    path.pop()
    return None

三、斐波那契(10 分钟)

def fib_recursive(n, memo={}):
    if n in memo: return memo[n]
    if n == 0 or n == 1: return n
    memo[n] = fib_recursive(n - 1, memo) + fib_recursive(n - 2, memo)
    return memo[n]

def fib_iterative(n):
    if n == 0 or n == 1: return n
    a, b = 0, 1
    for _ in range(n - 1):
        a, b = b, a + b
    return b

print(fib_recursive(20))   # 6765
print(fib_iterative(20))   # 6765

关键: 迭代版用两个变量滚动, O(N) 时间 O(1) 空间.

五、深入了解: 尾递归优化(3 分钟)

尾递归: 递归调用是函数的最后一个操作.

# Normal recursion (factorial(5) = 5 * factorial(4), last op is multiply)
def factorial(n):
    if n == 0: return 1
    return n * factorial(n - 1)

# Tail recursion (recursive call is the last op)
def factorial_tail(n, acc=1):
    if n == 0: return acc
    return factorial_tail(n - 1, n * acc)

优势: 编译器可以把尾递归转成循环(不爆栈).

Python 不支持: CPython 没做尾递归优化, 所以尾递归还是会爆栈.

Scala/Haskell/Erlang 等函数式语言都支持——这是为什么它们爱递归.

👀 C++ 认脸时刻(1 分钟 · 只看不敲)

int fib_iterative(int n) {
    if (n == 0 || n == 1) return n;
    int a = 0, b = 1;
    for (int i = 2; i <= n; i++) {
        int c = a + b;
        a = b;
        b = c;
    }
    return b;
}

三个认脸:

  • C++ 变量要 int 声明
  • int c = a + b; a = b; b = c; 三个变量滚动(Python 用 a, b = b, a + b 一行)
  • for (int i = 2; i <= n; i++) = for i in range(2, n + 1)
