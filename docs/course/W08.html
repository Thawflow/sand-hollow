三、地图长什么样（2 分钟）

每张地图 = 房间（方块）+ 连线（能走的路）。一张 6 房间示例：

[ 神社 Shrine ] —— 起点，玩家从这里出发

[ 树林 Forest ]   [ 河边 RiverBank ]

                    |
              [ 独木桥 Bridge ]
                    |
              [ 巨鹰巢穴 BossNest ] —— 终点，打败巨鹰通关

规矩：没有线的房间，玩家走不到。 画图时每条线都要双向考虑——从 A 能去 B，那从 B 也得能回 A。

二、主循环的样子（4 分钟）

发动机是一个 while 循环（W05 老朋友）：

print("=== Cat Adventure ===")
print("You are a young cat warrior. Find your way to the top!")

room = "shrine"

while room != "quit":
    if room == "shrine":
        print("\n--- Cat Shrine ---")
        print("You stand at the old shrine. Paths lead north and east.")
        choice = input("> ")
        if choice == "north":
            room = "forest"
        elif choice == "east":
            room == "riverbank"

逐行看懂：

  • room = "shrine"：从神社出发，room 记住「我在哪」
  • while room != "quit"：不是 "quit" 就一直转
  • if room == "shrine"：站神社放神社剧情
  • choice = input("> ")：问走哪边
  • room = "forest"：换新值，下一圈进树林分支

房间 = 一个 if 分支：每圈先看 room，再放对应剧情。

三、补完另外两个房间（3 分钟）

在 while 里接着写 elif：

while room != "quit":

    elif room == "forest":

三个分支拼起来，shrine ↔ forest、shrine ↔ riverbank 通了。每条连线都要双向走通。

狼不是「怪物」，它只是另一个字典——跟 player 一个模子：

enemies = {
    "wolf": {"name": "Gray Wolf", "hp": 30, "attack": 8, "defense": 2},

}

enemies["wolf"] 拿到狼的整张卡片。游戏世界的本质：把万物都变成数据，再写规则去改数据。

二、伤害公式：攻击减防御（3 分钟）

打一下掉多少血？

dmg = max(1, player["attack"] - enemy["defense"])
enemy["hp"] -= dmg

攻击 10 - 防御 2 = 掉 8 血。为什么套 max(1, ...)？防御 12 的铁罐头碰上攻击 10——不能加血也不能零伤害，至少刮 1 点。max(1, x) 就是「x 和 1 里取大的」，保底 1。

三、battle 函数：一场架的完整剧本（5 分钟）

def battle(player, enemy):
    print(f"A wild {enemy['name']} appears!")
    while enemy["hp"] > 0 and player["hp"] > 0:
        action = input("(attack/run): ").strip()
        if action == "run":
            print("You escaped!")
            return True
        dmg = max(1, player["attack"] - enemy["defense"])
        enemy["hp"] -= dmg
        print(f"You hit for {dmg}. Enemy HP: {enemy['hp']}")
        if enemy["hp"] <= 0:
            print("You won!")
            return True
        dmg = max(1, enemy["attack"] - player["defense"])
        player["hp"] -= dmg
        print(f"Enemy hits for {dmg}. Your HP: {player['hp']}")
    return player["hp"] > 0

逐层拆：

  • def battle(...)：函数——把一场架打包成一块积木，W08 会亲手学做，今天先用
  • while 双方都活着：回合循环，W05 的 while 长在这里
  • return True/False：打完告诉调用处「玩家赢没赢活没活」
  • 玩家先动手 → 敌人反击，一回合结束，回到 while 判断

四、三个分支，三个结局（2 分钟）

battle 只有三种出口：打赢（enemy HP ≤ 0）、打输（player HP ≤ 0）、跑掉。写游戏逻辑时先数清楚出口数——三个出口少写一个，玩家就会卡死在循环里。

今日口诀： 敌人是卡片，伤害减防御；胜负数出口，打赢打输跑。
